# REACTOR — 在 BPM 之上演奏
## 一套可控的现场视觉工程 / BPM System for Live Visual Performance

在 REACTOR 的现场，我把 Resolume Arena 当作演奏工具，而不只是视频播放列表。

我的工程分成三个不同的时间尺度：底部是一段可以长时间持续的视觉，中间是跟随 BPM 运行的动画和闪烁，上层才是手动触发的瞬时重音。每一层独立运行，也能在几秒内重新组合。这样就不必替音乐的每一下节奏预先剪好视频；现场留下的操作空间，正好用来处理 DJ 临时出现的碎拍、停顿和转折。

## 三种时间

### 01 · 持续的画面

最底层是一段能够独立成立的循环影像。即使上面什么也不操作，现场也不会因为失去触发而突然变成错误的黑屏。它可以是预制视频，也可以是 TouchDesigner、Processing 或网页实时程序送入 Arena 的画面。

对我来说，Arena 的作用是把这些来源放进同一套播控逻辑：管理层、混合模式、效果、亮度和最终输出，而不是要求所有视觉都在一个软件里生成。

### 02 · 跟随节拍的动画

第二层有明确的 BPM。它不是一段已经剪死的节奏视频，而是几组可以长期运行的动画参数。

我通常会准备四到五种差异明显的状态：较慢的呼吸、规则的脉冲、更密的细分、短促的强调，以及为高能段落保留的连续变化。每一组还可以使用不同的实时动画曲线：快速亮起并快速收束、突然出现后缓慢衰减，或者在一段节拍中逐渐扩展。

这几组动画可以共享 BPM，但不必拥有相同的速度、相位和视觉密度。现场演奏时，我只需要切换状态或推移亮度，而不需要实时重新制作动画。

### 03 · 人的重音

最高层保留给手动操作。

我使用类似钢琴的 Piano Trigger：按下时出现，松开便结束。它适合捕捉突然的军鼓、碎拍、短促的切分以及 DJ 没有预先告诉我的变化。

这层不负责替代 BPM。恰恰相反，稳定的节拍已经由第二层承担，手动触发才可以从“拼命追拍子”变成真正有选择的强调。

一个动作也可以只是把画面拿掉。音乐进入空白、停顿或转场时，把光和图像一起收回，往往比再增加一层效果更有力。

## 把 BPM 跟上

如果 DJ 的设备或软件提供可信的节拍信息，我会优先让 Arena 跟随同一个时钟。在能够使用 Ableton Link 的条件下，Link 负责保持节拍速度与相位的一致；如果没有自动同步，就直接听音乐，使用 Tap 估计 BPM，再在合适的小节开头用 Resync 重新对齐。

这里有两个不同的信息来源，不应该混淆：**BPM / Link 给出时间基准，DJ 的波形和现场声音帮助我判断内容与能量。** Link 不是自动识别低频、高频或下一次 Drop 的系统。

我会观察 DJ 软件中波形的密度、频段颜色以及即将到来的段落，但这些颜色的意义要以具体 DJ 软件的显示设置为准。低频段落可以让画面更厚、更暗，高频碎拍可以交给手动强调；真正是否增加亮度、是否突然归零，最后仍然根据正在听到的声音决定。

## 四个脚踏与手上的控制

脚踏解决的是身体分工：眼睛留给波形、DJ 和大屏，双手可以继续调整推子，脚则负责明确、简短的操作。

我的四踏板方案里，可以确认的基本动作包括：Tap BPM、Resync / 重新对齐节拍，以及用于瞬时强调的触发。其他踏板的最终映射会随着演出工程变化，不必为了画一张整齐的控制表而虚构一个固定功能。

手上的推子主要管理层级：底层内容多亮，BPM 动画占多大比重，上层强调是否进入画面。触发键则切换动画或片段状态。这个分工让系统既能持续运行，也能随时打断、重新进入或回到安全的基础画面。

## 从暗处开始

Club 里的画面不需要一开始就把所有细节摊开。我常从较暗、较窄的颜色范围起步：例如限制在单色红，压低画面的整体亮度和对比，再随着音乐展开更亮、更宽的画面。

当音乐持续推进，我会增加 BPM 层的密度；到了重音，加入手动触发；在气口和明显的断点处，则迅速收掉。这个过程不是一个自动的“能量条”。一首音乐可能在高频很密的时候仍然需要克制，也可能在低频很重的时候只需要一次明确的视觉重音。

对于公开演出中的高频闪烁，还需要与场地灯光及安全要求协调，避免把持续强频闪当成默认演出状态。

## 同一工程，更多来源

REACTOR 的 Arena 工程可以直接装入既有预制影像，也能接入 ENTROPY 中使用过的网页实时画面，或通过 Syphon、Spout 等方式接收其他软件的实时输出。工程内部保留统一的时间、层级和切换方式，因此可以逐场修改视觉内容，而不必每次重新发明控制系统。

这套经验也将进入 **Live Show Copilot / 现场副驾**：在 AI Agent 的帮助下快速整理工程、控制器映射和测试，再由演出者在现场完成判断与演奏。它仍是后续工作坊的开发方向，不代表课程已经完成。
