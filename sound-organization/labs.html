在 Live 中重建这次编排

  1. 新建空白 Live Set，设为80 BPM、4/4，切换到 Arrangement。监听音量先保持较低。
  2. 解压材料包。分别把 01_body.wav、02_field.wav、03_events.wav、04_space.wav 放进四条音频轨，全部从 1.1.1 开始。
  3. 选中四个片段，在 Clip View 中关闭 Warp。保持片段增益和轨道推子为0 dB，声像居中；先不添加设备或发送效果。
  4. 从开头播放。四轨相加形成参考录音。分别独奏每一轨，再恢复全部播放，辨认低频、声场、短事件与空间尾音的不同作用。
  5. 另存为自己的工程，执行 Collect All and Save，把使用的采样一起保存。此时已有一个可继续编辑的起点。

用同一份录音演奏读取位置

  1. 新建一条MIDI轨，放入 Granulator III，将 source.wav 拖入波形区。
  2. 创建一个长MIDI音符。保持音高不动，先听默认模式，再选择 Cloud。
  3. 颗粒长度先取约100—200 ms，密度保持适中，音高随机变化先关闭。缓慢移动 Position，从起音走到尾部，寻找可以停留的纹理。
  4. 固定读取位置，再单独改变颗粒长度。一个参数一次变化，听局部是更容易分辨，还是逐渐连成持续声音。
  5. 把读取位置的移动录成自动化，再录一份音频。前者保存演奏动作，后者保存这一遍的声音。

上面的颗粒录音由随包脚本制作。Live 实践使用相同材料理解读取、重叠和移动；声音会随所用设备的窗口、密度和包络改变。

重复、扩散与处理次序

清楚的重复使声音像得到回应；更密集的反射把事件延伸成空间。先把干声留在前景，再少量加入处理层，比较新的尾音是在连接两个事件，还是遮住下一次进入。

建立一个共用空间

  1. 在原声轨上先不插混响。新增返回轨，放入 Reverb 或 Hybrid Reverb，返回轨的 Dry/Wet 设为100%。
  2. 从较短尾音开始，缓慢增加原声轨的发送量。听干声的起音是否仍能辨认，再改变衰减长度。
  3. 让另一条短事件轨送入同一返回轨。保持各自音量不变，只调发送量，比较它们像在同一空间，还是远近过于接近。
  4. 停止新的声音，听返回轨什么时候结束。将这个实际尾音长度纳入下一段的进入安排。

把一次发现留下来

移动读取位置时，可能出现一段原先没有计划的声音。把它录下来，便可以停止控制，转而编辑它怎样开始、持续与结束。

  1. 新建音频轨，在输入位置选择要记录的轨道；记录包含效果的声音时，选择该轨道的后效果信号。
  2. 新轨的监听设为 Off，避免重复监听。启用录音待命，从一段安静处开始录音，然后演奏读取位置或发送量。
  3. 停止演奏后继续录下尾音。结束录音，关闭源轨，单独播放结果。
  4. 保留一段真正需要的变化，在两端加短淡化。把这段录音复制到编排中，比较它作为开头、转折和结尾时的作用。

录音输入可采用单轨路由；选择 Resampling 时会记录主输出，需先确认哪些轨道正在发声。路由说明 · 阅读第十三章

同一个动机，换一个背景

材料包的 motif_fixed.mid 与 motif_variant.mid 都为四小节。固定版有五次主要发声，变式只增加两次较轻的事件。音符数量的差别很小，周围的空白却随之变化。

从局部关系走到96秒

示范的段落长度可以在编排里直接看到。下表是这件短作的安排；它把既有材料放到不同位置，而非要求所有音乐都采用相同结构。

小节时间发生的事
1—80—24秒建立声场，低频间歇出现。
9—1624—48秒短动机加入，事件之间形成回应。
17—2048—60秒暂停新的激发，让余音消散。
21—2860—84秒熟悉材料回来，声场重新展开。
29—3284—96秒减少材料，结束后再保留6秒尾音。

先只改变一处段落长度。将中间的空白延长，再听回返是否仍有必要；将回返提前，再听前一段是否已经结束。声源与效果没有改变，作品的时间感已经开始变化。

让四个声部彼此让位

重新打开四条分轨，把推子恢复到0 dB。从这个已知起点出发，一次只改变一项关系。

  1. 关闭空间轨，听起音与低频是否清楚。再恢复空间轨，注意它连接了哪些事件。
  2. 将声场轨降低少量，比较短动机是否更容易被听见。再回到原值，判断变化是否改善了整段，而非只改善独奏。
  3. 把主输出监听降低，检查重要事件是否仍然成立。使用不同播放条件时，先做音量相近的比较。
  4. 记录自己的版本，并与参考录音交替回听。保留有明确作用的修改，不要求结果与参考完全相同。

四份分轨从同一起点导出。保持原始增益相加，可以还原参考录音，16-bit量化会留下极小数值差异。相同起点让每次修改都有可以返回的位置。

将一段已经完成的时间重新打开

先保留一份 Arrangement 原版，再建立 Session 副本。第一次只开放段落的进入与停留，不同时改写全部声音。

  1. 把四条分轨按上表的段落边界切开，放入 Session 的对应轨道和场景。不要移动各段内部声部之间的相对位置。
  2. 第一轮关闭片段循环，让五个场景按原长度播放，确认片段起点、停止行为与尾音都与编排相符。
  3. 选择一段接缝自然、适合停留的声场，另制成循环片段。其他只需出现一次的事件仍保持单次播放。
  4. 将启动量化设为适合当前材料的边界，例如1小节。先练习进入和退出，再决定哪些触发需要立即响应。
  5. 把一遍 Session 演奏录进 Arrangement，同时保留音频录音。回听哪里停留得太久，哪里本来需要更多空间。

只开放一个决定也能成为演奏。熟悉的材料提供依据，进入时刻与持续长度则开始回应这一遍的聆听。
