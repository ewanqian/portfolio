作品简介

Work Statement

《无需进一步输入》围绕自动化与人类判断之间的关系展开。当前 V0 已把艺术家选择的视觉模块、持续时间范围与状态转移关系写进一个能够自行运行的浏览器系统。

当持续操作减少以后，人的判断并未随之消失：它已经存在于被保留的 visual behaviours、规则、参数与初始转移权重中。让系统根据长期操作记录自行修改权重仍是研究假设，尚未进入当前实现。

Direction update / 2026.08.15

当前方向进一步从“关于自动化的一条影像”发展为“一套能够实际运行的生成式音画系统，以及由该系统产生的单通道影像与现场版本”。概念需要进入真实运行机制，而不只停留在作品说明中。

AI 的位置

AI as Production Relation

AI 当前不被设定为最终画面的唯一生成器。更重要的角色发生在代码协作、视觉算法候选、状态逻辑和系统结构的形成过程中。

AI 可以扩大艺术家能够迅速测试的形式可能性；艺术家负责筛选、删减、修改、决定持续时间与空间关系，并判断哪些结果真正进入作品。最终的系统保存的是这些经过判断后留下来的结构。

AI 生成可能性，人形成判断，系统继续携带这些判断运行。

运行结构

Runtime Structure

Visual Vocabulary

当前 V0 包含约束机构、索引场、高维投影、信号层、量化记忆与递归装配 6 个独立生成系统。每个状态拥有不同算法骨架，并共享纯黑白的线、网格、矩阵与模块语言。

Implemented / V0

State Machine

当前状态机使用每个状态独立的 duration range 与加权 transition graph 组织时间；状态不再通过普通 crossfade 切换，而经过拆解、校准与重组的机械遮板过程。

Implemented / V0

Audio Structure

麦克风与本地音频文件已可接入，麦克风授权后可选择具体输入设备；分析结果提供 low / mid / high、onset 与 8-beat phrase gate。当前映射已运行，phrase 与现场音乐结构的准确性仍需调校。

Implemented V0 / Tuning

Human Control

NEXT、HOLD 与 AUTO 已成为主要控制，并支持 N / H / A 键盘操作。HOLD 覆盖自动转移；NEXT 仍允许人工决定关键切换时刻。

Implemented / V0

Preference History

当前只在内存中保留本次运行的操作事件，既不跨会话保存，也不用于修改 duration 或 transition weight。偏好历史仍属于下一阶段研究。

Research hypothesis / Not implemented

Artwork Framework

技术 / Technology

候选方向包括 Web Canvas / WebGL / Processing / p5.js、WebAudio、实时声音分析、状态机与 AI-assisted coding。最终技术栈尚未锁定，技术选择服从视觉语言与现场稳定性。

Developing

媒介与形式 / Medium & Form

生成式音画系统、单通道影像与现场表演系统共同构成作品。时间从固定剪辑进一步转向由状态、转移与运行过程共同组织。

Defined / Developing

艺术语言 / Artistic Language

进入、停留、回返、退出；重复中的偏差；修正后的残留；已经消失的输入继续改变当前结构。作品需要避免沦为普通“漂亮生成动画”。

Developing

艺术问题 / Artistic Inquiry

当人的经验、修正与偏好已经进入系统，一个看似自主运行的系统中还保存着多少人的判断？当操作停止以后，作者是否真的离开了作品？

Active Inquiry

当前问题

Questions in Development
当 AI 让大量形式可以被快速实现，艺术家的工作会不会更多落在选择、删减、组织和判断上？
当这些判断被写回软件结构，系统是否开始携带一个创作者过去的判断历史？
一件作品能否同时是一段影像、一套乐器和一套持续演化的运行规则？
“无需进一步输入”究竟意味着系统自主，还是意味着人的判断已经被提前吸收？

边界

What This Work Should Avoid
不复制 touch:waves 的视觉皮肤；不把 AI 使用本身当作主题；不让“自主”只存在于文案；不把随机等同于生成；不让画面退化为高级 screensaver；在 preference history 真正实现之前，不宣称系统已经“学会了艺术家”。
