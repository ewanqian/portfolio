# 28 天日程｜Stage Casting × Drop Flow × TIMER

**期限：2026-11-06（周五）—2026-12-03（周四），共 28 天**  
**演出目标日：2026-12-04（周五）**  
**状态：已拟定工作计划，非已完成记录；只作为每日任务领取与验收依据。**

## 0. 范围与授权

- **动捕**：创作者本人于 2026-11-06 明确确认：杭州双年展 Drop Flow 动作捕捉素材可以用于本次延续创作。取消“等待动捕再利用授权”的项目阻塞。保持原作者、表演者与版本署名；公开许可证状态与项目内部复用许可分别记录。
- 其他合作音乐、外部摄影/视频、AI 生成素材的可公开/商业使用范围单独审计，不因动捕许可自动放行。
- **P0 仅一条**：Stage Casting 04 真实演出控制链路与可靠的备用输入。Drop Flow / TIMER 是给这条链路供给可识别视觉内容的两件作品，不再新建通用引擎。
- **目标精简**：Drop Flow 三段 shot + 一个 Light 候选；TIMER 两段 shot + 一项逆转/残留交互实验；整场 10–15 分钟可连续演奏的短篇；6–8 个精挑视觉桥段，不等于 6–8 个新程序。
- **硬停机线**：11/16 形式筛选；11/24 首次完整连续排练；11/29 视觉功能冻结；12/01 输出冻结；12/02 全流程模拟/彩排；12/03 仅验收与备份。
- **总时长不是强制**：日程建议 1×90 分钟主创作 + 1×60 分钟技术/整理 + 15–20 分钟记录。现场条件影响时保留最小可验证的成果；休息日或身体状态不佳，只做当天的“最低交付”即可，不以补做所有漏项来破坏主线。

## 3. 四个验收关卡

- **11/09 P0 控制链路门槛**：至少一次输入→声音和图像动作被真实记录，若无头显必须明示模拟模式。
- **11/16 视觉门槛**：Drop Flow 的动作残留可感知，TIMER 的逆转与记忆实验有清晰分镜；多余镜头可以删。
- **11/24 第一次完整演出门槛**：短篇连续运行、有人实际操作，镜头再精致也不能代替。
- **12/02 冻结后验收门槛**：主路径、降级路径、恢复步骤、音频/视频输出、离线备份均已测试或明确未测试。

## 4. 优先级冲突与延期规则

1. P0 链路未贯通时，Drop Flow / TIMER 只做可脱离软件运行的短镜头与内容资产，不为它们开新的复杂工程。
2. 11/19 仍无法把实时粒子安全放进演出时，改成固定镜头 + 可控混合/速度/遮罩的 Light 方案；不能因此推迟 Stage Casting 彩排。
3. 11/24 前不得继续增加没有进入成片或演出结构的“好看但无用途”视觉模块。
4. 11/29 后新增建议仅记录为后续项目；12/03 的唯一目标是第二天能稳定演出，而不是达到技术上最先进的状态。
5. 每天实际完成不足时，顺延的只能是低优先级素材，不得动摇冻结与排练日。
