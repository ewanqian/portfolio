# Performance Control Model — 2026-08-24 / Round 04

## ACTIVE RESEARCH TASK

Expand the successful prepared-capsule idea into a continuous editable performance system, then test the same logic as a spatial controller on Vision Pro.

## USER FEEDBACK THAT TRIGGERED THIS ROUND

- D5 had begun to form a reliable structure and should become the main research object.
- the weakness was continued dependence on manual triggering;
- each visual/audio family needed deeper internal behaviour rather than one finite effect;
- the desired next step was `Touch-like prepared capsule → editable sequencer → gradual evolution`;
- each of the 8 established languages should contain 8 sub-states / variations;
- each variation should expose a real sequence rather than hide all details behind one button;
- D2 / D3 were not distinct or musically convincing enough and should stop consuming attention;
- Vision Pro should become the 3D version of the successful Live Set rather than a separate interaction toy.

## D5 v2 — Capsule → Sequence Matrix

### Canonical hierarchy

```text
8 FAMILY
×
8 VARIATION
×
8–20 EDITABLE STEPS
```

Families:

```text
A ROUTE
S FIELD
D ORBIT
F REWIND
J CELLS
K PARTITION
L SCAN
; DROP
```

Each Family still supports immediate prepared-capsule triggering, preserving the useful Touch-like interaction.

Each Family now expands into V1–V8:

```text
SPARSE
SHIFT
SPLIT
BROKEN
DRIFT
DENSE
BURST
LONG
```

Each Variation exposes:

- sequence length: 8–20 steps;
- editable step grid;
- HITS;
- ROTATE;
- probability;
- cycle length in bars;
- mutate / regenerate / clear;
- LANE continuous playback;
- EVOLVE V1 → V2 → ... → V8.

The main conceptual change is:

```text
one input
→ prepared 4 s phrase
```

can now expand into:

```text
Family
→ Variation
→ Step Pattern
→ Continuous Lane
→ Evolution over bars
```

without losing the immediate one-button entry point.

## Audio direction

D5 v2 remains pure browser Web Audio synthesis.

No external audio samples are required.

The palette has been pushed toward sharper / more experimental electronic material through:

- FM-like plucks;
- metallic upper-register events;
- band-pass noise clicks;
- saw glissandi;
- short digital chord blocks;
- spectral scan sweeps;
- sub / impact events;
- restrained continuous kick / click / low ground.

The shared clock, pitch region and output budget continue to protect arbitrary combination.

## Visual direction

The eight established visual languages are now persistent/generative behaviours rather than single flashes.

Variation index affects parameters such as:

- number of route branches;
- field line count and phase;
- orbit hierarchy;
- rewind depth;
- cell grid dimensions;
- partition count and activation;
- scan count/direction;
- drop ring/particle density.

Active Lanes continue generating visuals even when the performer stops clicking.

## D4 v3 — Vision Pro 8×8 Capsule Sequencer Field

D4 now uses the same conceptual hierarchy as D5.

### Spatial model

```text
8 large nodes
= Family

near one Family
↓
expand 8 small nodes
= V1–V8
```

Interactions:

```text
pinch Family
→ Lane ON / OFF

pinch child Variation
→ select V1–V8
→ trigger prepared capsule

proximity to Family
→ lane probability

hand velocity
→ spectral sharpness / gesture energy

two-hand distance
→ SPACE

both hands pinch
→ RECENTER
```

The control field recenters about 0.70 m in front of the viewer.

Hand trails and a hand-to-target link line were added so spatial motion itself is visually legible.

D4 implementation was split into:

```text
d4-visionpro-spatial-adapter.html
d4-visionpro-spatial-adapter.js
```

so later spatial interaction work can be maintained without rewriting one monolithic HTML file.

## NEXT GATE

Do not add a ninth Family or more XR gestures yet.

Test whether:

1. a Family can be entered instantly by one button but also sustain a long performance through Lane + EVOLVE;
2. V1–V8 actually sound and look meaningfully different rather than only denser;
3. editing LENGTH / HITS / ROTATE produces musically legible gradual change;
4. active visual languages continue generating structure without constant triggering;
5. Vision Pro Family → Variation expansion is understandable in space;
6. Lane ON/OFF and Variation selection are reliable with pinch;
7. spatial input produces a better performance decision surface than the desktop matrix, rather than simply becoming a 3D copy of buttons.
