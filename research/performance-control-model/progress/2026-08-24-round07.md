# Performance Control Model — 2026-08-24 / Round 07

## ACTIVE RESEARCH TASK

Keep the Round 06 control model unchanged and improve **musical/visual content density without increasing front-stage control complexity**.

## USER FEEDBACK

The D5 v4 control model is sufficient:

- one visible sequencer;
- live-editable cells;
- explicit RANDOM;
- TRIGGER / LATCH;
- HOLD / CYCLE / RANDOM;
- compressed A–; performance input.

The remaining weakness was content quality:

- default patterns were too generic;
- different lanes could feel mechanically similar;
- 15/20-step phrases did not yet read as intentionally composed structures;
- randomisation could create collisions rather than controlled variation.

## RESEARCH INPUT

Reference principles reviewed from current Ableton sequencer documentation and examples:

- Euclidean sequencing: distribute a limited number of events across a fixed number of steps, then use rotation to move the relationship to the downbeat;
- per-step velocity/accent and chance should be independently controllable;
- controlled randomisation works best as variation around a prepared role, rather than completely unconstrained rewriting;
- independent phrase length / condition / probability can create long evolving structures from relatively small patterns;
- high-frequency probabilistic material benefits from sparseness and off-beat placement, while low/long events require stricter density budgets.

## D5 v5 — CURATED PERFORMANCE SEQUENCER

### Lane roles

```text
A ROUTE      anchor / pulse
S FIELD      low pressure / space
D ORBIT      high cyclic motion
F REWIND     descending memory
J CELLS      micro percussion
K PARTITION  mid chord blocks
L SCAN       spectral sweep
; DROP       structural impact
```

The lanes are deliberately not equal.

The arrangement rule is:

```text
low frequency = sparse / structural
mid frequency = blocks / support
high frequency = motion / off-beat detail
noise / scan   = fill gaps
DROP           = punctuation only
```

### Four curated pattern states

Every lane now has four coordinated pattern slots:

```text
P1 OPEN
P2 BUILD
P3 PEAK
P4 BREAK
```

These are not separate songs or sequencers. They are four stored rows for the same lane, prepared so that AUTO CYCLE produces an intelligible long-form arc.

### 15-step design

The first 15 steps of every preset are composed as a complete phrase.

The default global accent structure treats the 15-step loop approximately as:

```text
4 + 4 + 4 + 3
```

This produces a clear recurring anchor while allowing the phrase ending to arrive early and drift against a regular 16-step expectation.

### 20-step design

The final five steps are treated as an additional tail / extension area rather than duplicated material.

Default accent structure:

```text
5 groups × 4 steps
```

The 16–20 area is used for delayed ORBIT/CELLS/SCAN motion, phrase-tail REWIND behaviour and rare DROP punctuation.

### Spectral / density separation

- ROUTE owns primary pulse anchors.
- FIELD uses long low-frequency events and therefore remains sparse.
- ORBIT mostly occupies off-beats and high register.
- REWIND is placed inside/toward the tail of phrases.
- CELLS may be dense but its events remain short and mostly weak.
- PARTITION avoids simultaneous strong FIELD attacks where possible.
- SCAN is rare and sits in spectral/time gaps.
- DROP is intentionally not a drum lane; it appears only at structural points.

## RANDOMISATION UPDATE

`RANDOM LANE` is now role-aware.

Each lane has a different density, strong-event probability and preferred temporal region.

Examples:

```text
ROUTE      prefers beat anchors
ORBIT      prefers off-beats
CELLS      prefers off-beats with low strong-event rate
REWIND     prefers phrase tails
SCAN       prefers gaps
DROP       extremely low density / high structural weight
```

`RANDOM ALL` additionally performs collision limiting:

- no more than two strong events should dominate one step;
- FIELD/PARTITION low-mid collisions are demoted;
- dense ORBIT/SCAN/CELLS stacks are reduced;
- DROP and ROUTE retain priority when a structural accent is required.

The goal is not automatic composition quality. It is to make RANDOM produce useful starting material more often than destructive noise.

## SOUND / VISUAL DIFFERENTIATION

The four presets also alter synthesis/visual behaviour per lane.

Examples:

- ROUTE changes attack sharpness/filter range;
- FIELD changes duration and register pressure;
- ORBIT changes interval/high-frequency motion;
- REWIND changes descent depth and persistence;
- CELLS changes transient density/filter position;
- PARTITION expands chord content at PEAK;
- SCAN changes brightness/trailing width;
- DROP changes impact/residue scale.

Visual output now reads `lane + step + preset`, not only `lane`.

This makes one Lane capable of multiple temporal visual substates while retaining one recognizable visual language.
