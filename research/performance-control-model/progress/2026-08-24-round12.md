# Performance Control Model — 2026-08-24 / Round 12

## ACTIVE TASK

Turn the Clip-first prototype into a more stage-ready control surface by increasing automatic structural control and suppressing invalid or musically destructive input.

## CORRECTION

The performer should not be responsible for making every combination safe.

The runtime should actively protect the musical field:

```text
RAW INPUT
→ DEBOUNCE
→ ROLE / SPECTRAL OCCUPANCY CHECK
→ MAX ACTIVE BUDGET
→ QUANTIZE
→ EXECUTE
```

Manual intent remains primary, but not every repeated or conflicting signal must be executed.

## D5 v9 — FULLSCREEN AUTO CONDUCTOR

### Stage-first UI

- canvas now occupies the available viewport;
- PERFORM controls live in a compact bottom dock;
- a FULLSCREEN action uses the browser fullscreen API;
- EDIT / Arranger is an overlay rather than the main screen;
- PERFORM exposes only material pads plus six control categories: PLAY / AUTO / ENERGY / GROUND / FULLSCREEN / PANIC.

### Tempo

BPM increased from 128 to 140.

The goal is not simply speed. Short electronic phrases, AIR/HISS, metallic punctuation and stutter gestures read more coherently at the faster pulse.

### Signal guard

Implemented safeguards:

```text
per-material debounce
same-clip duplicate rejection
MAX 5 active clips
role occupancy caps
LOW max 1
MID max 2
HIGH max 2
FX max 2
AMBIENT max 1
1/8 quantization
manual priority window over AUTO
```

Filtered input is observable in STATUS / HUD instead of failing silently.

### AUTO control

Three modes:

```text
OFF
ASSIST
DRIVE
```

ASSIST only adds compatible material when the texture is too empty.

DRIVE actively follows an internal:

```text
OPEN → BUILD → PEAK → BREAK
```

energy curve and selects from phase-specific material pools.

AUTO does not bypass the same compatibility guard used for manual input.

### ENERGY

One compact control cycles ENERGY 1 / 2 / 3.

This changes the desired concurrent material density rather than directly changing synth parameters.

### GROUND

GROUND cycles:

```text
AUTO
1
2
3
4
```

When GROUND AUTO is active, internal structural phase selects the backing variation.

### Manual priority

After a manual trigger, AUTO waits for a short guard window before adding material.

This prevents the automatic layer from immediately obscuring performer intent.

### Mix safety

Master gain now reduces progressively as active clip count increases, in addition to the dynamics compressor.

This is a coarse but useful first headroom controller for assembled material.

## CONTROL-THEORY READING

### Stability

Higher than v8 because invalid repeated / colliding signals can be suppressed.

### Controllability

Manual actions stay direct, but the system refuses some unsafe transitions.

### Observability

HUD exposes AUTO / phase / energy / ground / active-count / filtered-count.

### Robustness

Explicit MAX ACTIVE and role budgets protect against dense overlapping clips.

### Expressivity

16 materials remain directly accessible. The guard limits simultaneous activity, not the material library.

### Depth

Depth now comes from material composition + automatic orchestration rather than more visible sequencer controls.

3. Turn AUTO DRIVE on; stop touching controls for 20–40 seconds and judge whether OPEN/BUILD/PEAK/BREAK produces a more coherent assembled section.
4. Compare ENERGY 1 / 2 / 3.
5. Test GROUND AUTO versus fixed backing states.
6. Enter FULLSCREEN and judge whether the screen now reads as an instrument / stage instead of a demo page.
