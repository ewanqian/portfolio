# Performance Control Model — 2026-08-24 / Round 03

## ACTIVE RESEARCH TASK

Turn the earlier timing/state probes into a **playable, recordable performance fragment**, while keeping Vision Pro as an input adapter to the same prepared musical logic.

## USER FEEDBACK THAT TRIGGERED THIS ROUND

- D0 achieved the intended boring baseline but should no longer be treated as a main demo.
- D2 / D3 were technically explanatory but not musically interesting enough.
- the previous Vision Pro demo had static targets and insufficient movement semantics.
- the missing reference quality was the prepared 3–5 second audiovisual phrase: one input recalls a coherent musical and visual behaviour that is already compatible with the rest of the set.

## CHANGES IMPLEMENTED

### D2 v2 — 4-Layer Live Sequencer

- 122 BPM authoritative Web Audio clock;
- KICK / LOW / HIGH / TEXTURE continuous layers;
- 16-step A/B patterns;
- bar-quantized activation and variation changes;
- continuous density control;
- 40-second AUTO BUILD and explicit BREAK / RELEASE;
- persistent layer visualisation rather than one-shot flashes.

### D3 v2 — State Conductor

- one continuous sequencer remains active under all states;
- OPEN / BUILD / PEAK / BREAK change density, spectral behaviour, space, visual persistence and action semantics;
- ADD / HOLD / REMOVE / RELEASE are high-level actions;
- 48-second automatic performance path added for comparison with manual intervention.

### D5 — Prepared Capsule Live Set

New main desktop proof.

- 8 prepared audiovisual capsules;
- each capsule lasts about 3–4 seconds;
- all capsules share BPM, pitch palette and output budget;
- each capsule contains a short event sequence rather than a single note;
- each capsule has a named visual behaviour derived from the existing NFI vocabulary: ROUTE / FIELD / ORBIT / REWIND / CELLS / PARTITION plus SCAN / DROP;
- 1/8-note quantization;
- continuous backing ground;
- max voice budget;
- 36-second automatic set for recording;
- keyboard A S D F J K L ; for immediate performance.

This is a structural precedent study, not a copy of Touch:waves source or interface.

### D4 v2 — Vision Pro Moving Capsule Field

- automatically recenters the control field about 0.75 m in front of the current viewer pose;
- target spread reduced to an arm-reachable field;
- targets continuously drift rather than remaining static;
- hand velocity becomes continuous `MOVE` control;
- proximity to a target becomes a continuous amount before commitment;
- pinch commits a prepared 3–5 second capsule;
- two-hand distance becomes `SPACE`;
- both hands pinching together recenters the field;
- desktop buttons call the same capsule semantics.
