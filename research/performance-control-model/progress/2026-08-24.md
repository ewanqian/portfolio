**Date:** 2026-08-24

## ACTIVE RESEARCH TASK

### P0 — Prove quantized audiovisual capsules on one authoritative Web Audio transport

Goal:

Replace the current low-level `key → note/effect` interaction with a small set of short, musically coherent, quantized audiovisual capsules.

Minimum proof:

```text
4–8 capsules
+
one Web Audio transport
+
beat/bar quantization
+
attack / development / decay
+
shared event data for audio + visual
```

Success condition:

A user can trigger the capsules imperfectly in time, but the result still forms a musically stable 30–60 second performance fragment.

This task belongs to **R1 Runtime & Temporal Control**.

---

## WHY THIS IS ACTIVE NOW

Recent observations converge on the same problem:

1. Touch-oriented audiovisual instruments work well when each input recalls a prepared, coherent musical/visual behaviour rather than an isolated note.
2. Multi-sequencer live performance creates long-form structure by activating, removing and modulating already-prepared layers.
3. `No Further Input Required v0.7` already has a continuous musical ground, shared timing and sparse manual intervention, but its discrete keyboard events remain too low-level.
4. WebXR spatial control will only become artistically meaningful when it controls a musically reliable runtime underneath it.

Therefore the immediate dependency is musical/time structure, not additional input complexity.
