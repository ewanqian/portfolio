PERFORMANCE CONTROL MODEL / DAILY TEST ARCHIVE

2026-08-24 — Round 02 Demo Set

每个 Demo 独立运行、独立留档。建议按 D0 → D1 → D2 → D3 → D4 顺序测试。

D0 / BASELINE

Direct Trigger

4 个输入直接触发音/视觉。故意作为低层基线，测试为什么 20–30 秒后容易耗尽。

D1 / TIMING

Quantized Capsules

统一 Web Audio clock、pending queue、1/8 与 1/4 quantization。故意早按晚按。

D2 / LAYER

4-Layer Sequencer

KICK / LOW / HIGH / TEXTURE。Layer 开关在 bar boundary 生效，测试 0→1→2→4→2→1→0。

D3 / STATE

Shared State A/V

OPEN / BUILD / BREAK。相同 ADD 在不同状态有不同含义，声音与视觉共享状态但不做简单 1:1。

D4 / WEBXR

Vision Pro Adapter

桌面按钮与 Vision Pro pinch 调用同一 Layer 语义。真实设备未测前只算 IMPLEMENTED。

固定测试记录
WORKED：最成立的一件事
FAILED：最影响可玩的一个问题
NEXT CHANGE：下一轮只改一件事

录屏建议：D1 15 秒 + D2 20 秒 + D3 15 秒；Vision Pro 单独录 D4 的进入 XR、pinch、Layer 切换。
