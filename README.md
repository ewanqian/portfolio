## Source-of-Truth Rule

本仓库不再通过多份 Biography 重复维护同一事实。

```text
项目 / 节展 / 图片 / 视频 / 团队仓库
                 ↓
       Encyclopedia / Claims
                 ↓
     Structured JSON + Media Index
                 ↓
Portfolio / CV / Proposal / PPT / Agent
```

如果旧 README、历史 PR、项目汇总表与当前百科发生冲突，优先检查对应项目的原始 source、团队版本档案和 `docs/encyclopedia/` 中的状态记录。
