## Node Weaver

Node Weaver 是我当前用于整理作品线、公开节点、资产与关系结构的本地内容系统。它不是传统 CMS，而更像一套面向创作记忆、版本线索与未来复用的基础设施：不是只为了把内容存下来，而是为了把曾经脱链的作品、判断、方法和支线重新接回一个可进入的网络里。

它现在主要负责：

- 把作品、节点、资产和关系整理成更稳定的结构
- 清理命名重复、版本混层和归属混乱
- 给 portfolio、archive 与 agent 工作流提供 public-safe 的内容基础

它的独立公开说明目前也在同步整理中，会保持和这个 portfolio 里的主线、节点与方法表述一致。
