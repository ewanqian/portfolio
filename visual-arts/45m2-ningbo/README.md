# 余佳运「45㎡」演唱会视觉制作记录

## Overview

余佳运「45㎡」演唱会视觉制作与工程交付支持，主要记录宁波站现场语境，并整理 Opening、部分曲目视觉、地屏内容与多屏 PGM 输出。

## Public Display Structure

- Opening: 技术前奏、琥珀色阈值、橙色快闪、下落与标题收束。
- Song visuals: 防沉迷系统、触碰不到的你、尘埃、卸妆、千禧、夏夜入梦前。
- Surface map: PGM 主屏、地屏、地面 / 顶面方向内容。
- Video references: 上海 Opening 现场参考、宁波站全程跟拍参考。
