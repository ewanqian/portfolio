# Entropy → REACTOR → HERO DOME：作者口述续篇 / 2026-11-09

> **作者一手回忆 / Artist recollection；未经全部源工程核验。** 本文是 [TIMER → Drop Flow → SRE / Entropy 创作谱系](./2026-11-09-author-account-blender-to-runtime.md) 的续篇，保留技术决定、作品感受、探索和未完成之处。  
> 不作为已完成的新作品发布、商业交付确认或具体 Blender 节点链验证。作者的创作方法与合作项目完整署名需要分开记录。

## 1. 在 Entropy 之后，进入 REACTOR

Entropy 的太空终端、模型结构、线条生成和模型“从无到有”的出现动画，让我意识到：一种**先出现线，再显出结构**的方式有很强的科幻感。特别是环状机械结构、舱体、缓慢旋转的物体，在合适的构图与过渡中有很高的画面完成度。

到了 REACTOR，我第一次把一张高精度的托卡马克装置参考图交给 GPT 辅助三维建模。令我惊喜的是，只要结构本身有明确、可重复的几何逻辑，生成出来的结构就能够非常复杂、精细而且合理，特别适合线框呈现。不过这仅是**美术模型的视觉与结构表现**；并未以工程图或物理设计证明其符合真实托卡马克的机械精度。

这一轮不再只在网页里做线条动画，而是将 GPT 辅助生成的模型带到 Blender：让线条转成 **Curves**，再给曲线和材质接上 Shader、发光或光照变化，使线条逐段出现、局部高亮，直到完整结构被看见。作者又手动补光、调整材质、选取视角并决定最终渲染的质感。所谓“AI 做得很完整”，并不意味着渲染的艺术判断被交给 AI；这个生产环节仍由作者控制。

值得继承的是**一条清晰的制作链**：有结构规律的参考图 → 可重复的 3D 结构 → Wire/Curve 的可动画化线段 → 局部高亮与 Reveal → 摄像机/灯光/材质的手工选择 → 视觉完成度较高的离线素材。应找回 Entropy 的 Reveal 示例，与 REACTOR 的 Blender Curve 实现做对照；不应只凭“线框好看”把两者合成一种新算法。

## 2. HERO DOME 测试：将已有 Blender 世界放入超宽屏幕

作者回忆：HERO DOME 研究时，将前一阶段的 Blender 场景迁入超宽画幅进行适配，而不是完全重新建立一个新系统。最初按约四个暗—亮的视觉状态/阶段组织简单过渡曲线；具体四状态命名、关键帧和灯光值需在实际工程中复核，不应凭口述确定为四块物理屏幕。

更值得保存的是作者认真制作的一组材质与合成方式：

- **Wireframe + Wave**：把线框/结构与波浪形的空间变化结合；
- **ColorRamp**：对波形或空间分布进行阈值、渐变与亮度形状的控制；
- **Light / Emission**：结合光源和自发光，建立扫过结构的明暗变化；
- **Compositor 中的 Noise**：加入噪声质感以使画面不显得过分干净，也希望减轻色阶感。注意这属于作者制作目的与观感，技术上噪声并非自动修复所有色带量化问题；
- **多相机/旋转视角**：通过角度、镜头和运动的选择，从同一个模型取得不同视觉效果。

作者的评价是：此时画面同时具有某种近似真实光照的体积/材质质感，又有线框与扫描的人工科幻结构；甚至不需要大量调色，就已经很满意。

后续 Agent 最重要的不是重新做九种 Shader，而是**定位上述链路真实存在于哪个 Material、NodeTree、Object、Compositor 和 Action**，提取原始材质的可重用版，同时保留每一个需要作者审美判断的参数。

## 3. Ableton Live：声音制作质量成为下一道瓶颈

REACTOR 附近的制作阶段，作者开始尝试让 Agent 在本地 Ableton Live 中构建声音工程。在先前的 Tone.js / WebAudio / 网页生成试听中，音乐结构、节奏安排可能已经不错，也可能有 Groove，但在实际听感上，合成器、音源、混响及混音的质感经常不足。

当同样的结构进入本地 Ableton Live，并使用更合适的乐器、音色与效果器后，作者听到过一个完成度明显提升的版本，特别认可其空间感与混响等制作细节。这是一个需要保护和恢复的**真实听觉偏好样本**：以后不要只交 MIDI 和程序化 WAV，就把曲目宣布为完成；应当保存“哪一个实际听起来好”的音频版本、工程与音源/插件状态。

作者记得后续还进行过锅碗瓢盆/物件打击乐、相机快门/闪烁般短促节奏等变体实验，均应按实际工程和试听辨别版本，不能假设它们与最高完成度版本是同一个方案。

到后面曾产生空间音频的设想，例如声音从前到后的移动；但 HERO DOME 测试时间不足，不得写成完成了可交付的空间音频系统。

**近期进行中的音乐并行筛选**：作者称另一台 MacBook 正在跑约四种音乐方向、每个方向六个工程/曲目；这属于当日执行状态与初步试听回忆，未收到原始工程和运行清单。作者认为网络端试听 FLAC 可以有 Groove，但欠缺好的音源库；一部分本地工程调用优质音源并混音后，结果显著更好。音乐听感应保留人工 A/B 选择；不可因生成了 24 份文件就宣布其中 24 首合格。

已存档的 [Performable Music 研究](../../research/performable-music/README.md) 和 [REACTOR BPM System 文章](../../docs/journal/reactor-bpm-system-2026.md) 可作为背景，但它们不等于这些 Ableton 工程已经被找回。

## 4. 二砂点云影像：从后向前穿行的空间镜头

当 HERO DOME 的声音与视觉测试进入时间压力阶段，作者重新使用了旧的 **SYSTEM × ERSHA / 二砂工厂点云影像**：其中已有一条或多条沿空间纵深快速推进的镜头，从远处/后方朝前穿过厂房。它直接提供了强烈的运动和空间尺度感，能迅速进入新屏幕测试。

作者对这次再利用的价值判断很明确：即便不是为了当下重新制作的新工程，一条已经做好的镜头仍可以在新的屏幕与音乐情境中焕发价值。

作者同时回忆当时做过不少不同镜头，但部分 Blender 原工程、输出点云模型等似乎丢失或被覆盖/备份转移；尚无法判断真实丢失、改名、移动到 NAS 还是位于旧历史路径。应以**恢复优先、全程只读**的方式检索，不应因目前找不到就直接重跑 Metashape 或覆盖残存成果。

技术上值得恢复的部分：
- 从 **Agisoft Metashape** 输出的点云/网格及颜色属性；
- 在 Blender 中使用类似 vertex colors / Color Attribute 的属性驱动外观；作者口述称作 “primitives color”，实际属性名和 Shader 节点需要以源文件为准；
- 少量基础调色、镜头高速前进、点云/网格视觉与既有 Simulation Zone 特效叠加；
- 哪些可复用为通用的点云颜色 Shader，哪些是针对具体建筑、素材、镜头绑定的制作数据。

该项目的已有版权与署名边界在 [SYSTEM × ERSHA](../../projects/system-ersha-2026.md) 中明确列出；不能擅自公开全部原始扫描、影片片段与合作资产。

## 5. 近期的九组灯光与并行选择经验

作者回忆最近一次 Blender 场景测试，让 Agent 将光照探索成**约九组有实质差别的方案**：侧光、轮廓光、顶光、由下向上照等，再让自己横向比较。有一组值得保留的组合是**底光 + 轮廓光**；另一组入选方案的具体配置当时想不起来，不能由 Agent 编造补齐。

对作者而言，更重要的不是数字“9”，而是一种制作效率：与一次只生成一个方案再反复交谈相比，预先在同一测试场景/相机/基准材质上产生一组可比的差异，作者便能快速淘汰无效选择并进一步调比例、灯位和强弱。这相当于把生成阶段并行化，将人类精力集中在**比较与选择**上。

类似策略也适用于音乐：批量生成可听样本，但真正的选择标准不只是旋律/结构，还包含具体声音质量、空间、混响、演奏感、Groove 与混音完成度。必须让试听响度及对照条件尽可能一致，保留高质量母版和项目，不能只保留较差的线上 demo。

## 6. 与之前创作谱系的真正关系

这一阶段新增的不是一条简单替代 Drop Flow Simulation Zone 的路线，而是另一条并行的“制作质量与可控制性”路线：

1. **模拟/运行逻辑**：Drop Flow 的逐帧 Simulation Zone → 未来原生 GPU Runtime，重点是准确重现状态与运动；
2. **结构/画面成形**：Entropy 的模型 Reveal → REACTOR 的线框转 Curves、Shader 高亮 → HERO DOME 的场景重用、材质/合成与超宽屏；
3. **音乐/控制**：过去 Bake 音频曲线 → SRE 的 BPM/MIDI 连接 → REACTOR/Ableton 的可演奏/可编辑音乐 → 未来声音与空间场景的共同编排；
4. **旧资产重用**：二砂点云纵深镜头从其他制作语境进入新测试；需要把原工程、镜头与 shader 保存成可再次引用的资产；
5. **作者审阅成为生产瓶颈**：从 9 组灯光、10×多状态实时视觉、4×6 音乐候选中，真正的积累来自知道哪些方案值得保存、为什么选择、为什么其他版本不成立。
