## Why This Series Matters

这是我作品线中最能体现“时间结构”思考的一条主线。它不是单纯的音频可视化，而是在现场语境中持续测试：声音、节奏、频段、段落与空间感之间，如何形成更有判断力的图像组织方式。

如果你想最快理解我关于音画关系的工作方式，可以先从这一系列进入。

## Core Focus

- 时间结构 / Temporal Structure
- 音画关系 / Audiovisual Structure
- 感知节奏 / Perceptual Rhythm
- 现场状态切换 / States of Entry
- 声音如何成为图像内部的组织材料
