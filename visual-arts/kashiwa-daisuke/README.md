## 关于

与日本音乐人 Kashiwa Daisuke 合作的视觉艺术系列。该系列目前包括深圳 BO LIVE 专场与 CAN Festival 现场项目，涵盖现场视觉、音画结构、空间生成与氛围段落设计。

**核心关键词：**
- 视听表演 / Audiovisual Performance
- 现场视觉 / Live Visuals
- 时间结构 / Temporal Structure
- 空间生成 / Spatial Generation

## Collaboration Overview / 合作概览

该系列整理的是我与 KASHIWA Daisuke 及合作音乐人 Yuki Murata 的现场视觉合作档案。目前已公开的项目包括深圳 BO LIVE 专场《机械光合：TITAN 的全息声林》与舟山 CAN Festival 2025 pt.2。

这条合作线主要围绕：
- 现场视听结构
- 音乐驱动的视觉段落
- 空间生成与氛围控制
- 舞台语境中的视觉协作

## Acknowledgement / 致谢

特别感谢策展人张秋童 Vickie 促成这次合作，也感谢 KASHIWA Daisuke、Yuki Murata 与所有相关工作人员对现场工作的支持与信任。

这段合作的重要性不仅在于完成具体演出，也在于让我进一步理解现场工作的方法、视觉与音乐之间的关系，以及跨团队协作中视觉系统应该承担的边界。

## Credits Structure / 合作结构

该系列项目通常由以下层级共同构成：
- 音乐演出：KASHIWA Daisuke、Yuki Murata 及相关现场音乐人
- 视觉创作 / 现场视觉：Ewan Qian
- 现场制作系统：策划、统筹、技术、灯光、声音、舞台与场地团队共同完成

具体 credit 以各项目页和公开资料为准。
