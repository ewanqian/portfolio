# 虚拟航线 / VAOE — 艺术作品系列

《虚拟航线》2023 年在上海南昌路 312 号举办的个人展，包含 **四组影像作品** 和 **通过扫描二维码进入的 AR 增强现实项目**。早期数据库曾笼统称为“叙事型虚拟空间体验”，现以实际展出媒介结构为准。
