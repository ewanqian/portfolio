## Use This Folder Like This / 这个目录怎么读

如果你是第一次接触合作说明，建议按这个顺序阅读：

1. [Collaboration Overview](./collaboration-overview.md)
说明我更适合什么类型的合作、我实际会帮你解决什么、应该怎么开始沟通。

2. [Service Categories](./project-types.md)
用于判断你的项目大概属于哪类服务。

3. [Pricing Policy](./pricing-policy.md)
用于理解为什么不同项目的报价差异会很大，以及我通常如何判断报价。

4. [Case Notes](./case-notes.md)
用于理解一些关键判断，比如为什么 opening visual 更贵、为什么 XR 要先做测试。

5. [FAQ](./faq.md)
用于处理常见问题，减少重复沟通。

6. [Inquiry](./inquiry.md)
用于准备第一次联系时应该提供什么。
