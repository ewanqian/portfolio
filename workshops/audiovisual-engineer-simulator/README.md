# 视听工程师模拟器
## Audiovisual Engineer Simulator

**项目类型：** 公众工作坊 / Live Audiovisual / Visual Engineering / Stage Previsualization  
**发起人 / 主讲：** 钱誉文 Ewan Qian  
**当前状态：** 2026-09-29 课程体系确认，MANA 推文与现场执行准备中

> 从“做出一个系统”继续向现场推进：先学会控制时间，再学会组织空间。

## 项目定位

《视听工程师模拟器》延续 2026 年 MANA《极简输入：构建视听系统》的方法。上一期从最简单的输入开始，让参与者把声音、图像与规则组织成可以运行、可以演奏、可以继续修改的实时视听原型。

新的课程把问题推进到真正的演出现场：

1. **科目一｜一键控场**：音乐开始以后，怎样听、判断、同步、控制，并把一套现场工程稳定地跑下来。
2. **科目二｜舞台预演**：内容做好以后，怎样读懂场地、组织屏幕与视觉工程，并在真正进场以前完成一次空间预演。

课程会使用 Resolume Arena、Blender、网页实时程序、Processing、MIDI 控制器与 Agent 等工具，把时间、状态、层次、Mapping、屏幕关系、交付和恢复整理成可以迁移到不同项目里的方法。

## 课程结构

### 前序｜极简输入
**Minimal Input — Building an Audiovisual System**

从一个按钮开始，把声音、图像与状态组织成一个可以演奏、可以分享的实时视听系统。

### 科目一｜一键控场
**One-Button Show Control**  
**视听工程师模拟器 · 科目一｜现场控制系统**  
**Audiovisual Engineer Simulator · Module 01｜Live Show Control System**

长标题：**从一个按钮开始，怎么控制一整场演出？**

核心路径：

```text
听音乐
↓
拿到时间参考
↓
Tap / Resync / BPM
↓
安全底层 / 节拍层 / Visual Clips / 强调层
↓
控制能量
↓
现场恢复
↓
DJ 场景模拟
```

课程结尾进行两段测试：

- **理论考｜听状态**：直接听音乐，判断保持、推进、爆发、拉掉、恢复。
- **路考｜DJ 现场模拟**：与一位 DJ 老师共同完成随机桥段组织，测试 BPM、节拍状态、能量控制、留白与恢复。

完整课程稿见：[科目一｜一键控场](./module-01-one-button-show-control.md)

### 科目二｜舞台预演
**Stage Previsualization**  
**视听工程师模拟器 · 科目二｜视觉工程、空间组织与现场预演**  
**Audiovisual Engineer Simulator · Module 02｜Visual Engineering, Spatial Organization & Live Previs**

长标题：**画面做好以后，放到真正的舞台上还成立吗？**

核心路径：

```text
读场
↓
组织屏幕与视觉工程
↓
确定音乐 / 视觉的结构关系
↓
建立时间状态
↓
放入预演程序
↓
从观看位置检查
↓
修改
↓
输出规格与场景资料
```

科目二不是“读屏幕尺寸”的教程。屏幕、Mapping 与预演只是工程基础；更重要的是决定主屏 / 副屏各自承担什么、内容是否连续、音乐还是视觉承担主要结构、哪些内容预渲染、哪些部分保留实时控制，以及如何让视觉工程真正可修改、可预演、可交付。

课程结尾进行：

- **理论考｜读场与组织**：面对陌生 Venue Brief，判断屏幕、角色、Mapping、内容结构与缺失信息。
- **路考｜舞台题目**：从超宽屏、主屏 + 天屏、曲面屏、多屏 / 异形屏等题型中抽取一种，完成读场、组织、Mapping、四状态、预演和规格说明。

完整课程稿见：[科目二｜舞台预演](./module-02-stage-previsualization.md)

## 共同方法

两科分别解决两种最基础的现场能力：

- **科目一：控制时间**
- **科目二：组织空间**

它们延续《极简输入》的“少量输入、清楚状态、可恢复系统”原则，同时把目标从网页原型推进到现场工程。
