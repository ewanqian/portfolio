# 视听工程师模拟器
## Audiovisual Engineer Simulator

**主讲：** 钱誉文 Ewan Qian  
**状态：** 2026-09-29 最终定稿

《视听工程师模拟器》从《极简输入》继续往真实现场推进。

- **科目一｜现场副驾 / Live Show Copilot**：在 AI Agent 的帮助下快速组织工程，并有意识地控制整个现场。
- **科目二｜舞台复刻 / Stage Replica**：从一张参考图、一段现场视频或一个虚拟世界开始，把自己的内容真正放进一个完整的现场。

最简单的区分：

- **现场副驾：我能演了。**
- **舞台复刻：我能搭了。**

## 01｜现场副驾
### Live Show Copilot

你看过很多场演出，但可能从来没真正站到过控制台后面。

课程直接从一套实际使用的 Resolume Arena 工程开始。爆闪层、固定 BPM 层和视觉片段分开组织，再通过脚踏、按键和推子去控制。

演出以前先确认 DJ 的 BPM、Beat Link 和波形；需要时用 Ableton Link 同步 BPM，拿不到自动同步也可以直接听，用 BPM 控制键重新跟上。

音乐比较低的时候，闪烁的亮度可以压得很低，只留下低频的频闪。DJ 开始重复、铺垫情绪，进入 Bridge，就可以切到更高的闪烁状态，再通过推子继续把亮度往上拉。到了冲击最强的时候，爆闪可以拉到最大。Drop 或高潮之后出现“气口”，画面可以直接按掉，再等下一段重新打开。

课程会准备三四种跟随 BPM 的状态，并通过实时动画曲线改变每一下闪烁的感觉。

AI / MCP 不替代人的判断，主要帮助更快把键盘、MIDI、脚踏、推子和工程接起来；如果本身会 Processing、网页或其他实时程序，也可以把同样的控制逻辑写进去，再通过 Syphon / Spout 接回现场。

最后进入 DJ 现场模拟，真正把一段现场跑下来。

## 02｜舞台复刻
### Stage Replica

这场工作坊从一张参考图、一段现场视频、一个游戏或电影里的虚拟世界，或者已经做好的视觉开始。

先看这个现场是怎么被组织出来的：视觉中心在哪里，主屏在做什么，其他屏幕怎么配合，人物、灯光、声音和画面是什么关系。再把最重要的部分重新搭出来。

接下来可以放进自己的视频、AI 素材、人物或舞者、3D 模型，重新安排灯光和声音，再让同一个舞台经历**铺垫、建立、爆发、收束**几种不同状态。

网页工具负责快速搭屏幕、放入内容、切换观看位置和预演；Blender / MCP 是扩展，不是门槛。

完成以后留下的不只是一个舞台模型，而是一套以后真正想做一个现场时，知道怎么拆、怎么搭、怎么编排的方法。

### Visual Audio｜Bonus

当一个现场已经有了自己的时间结构，可以进一步尝试让音乐跟着这套视觉编排长出来。基础版可以使用 Web Audio；使用 Ableton Live 时，也可以利用现有音乐库、MIDI 和编排，把视觉状态继续转换成音乐结构。
