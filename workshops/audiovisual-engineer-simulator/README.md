# 当前主推｜舞台复刻
## Stage Replica
### 拆一场喜欢的演出，再做成自己的现场

你可能看过一场特别喜欢的演出，也可能已经做过一些自己的视觉，只是从来没有真正把它放进一个完整的舞台里。

《舞台复刻》从一张参考图、一段现场视频、一个游戏 / 电影里的虚拟空间，或者已经做好的内容开始。先拆出这个现场最重要的屏幕、人物和空间关系，再把自己的视频、AI 素材、人物、舞者或 3D 模型放进去。

同一个舞台先用四个最小状态组织：

**铺垫 → 建立 → 爆发 → 收束**

最后在网页里真正跑起来：切换观看位置、替换内容、继续修改；上一期的音画同源 / WebGL 面板也可以作为实时 screen source 接进舞台。

当前反馈比较一致：《舞台复刻》更容易让初次参与者理解“这跟我有什么关系”，也更容易预期最后会做成什么样；《现场副驾》更适合作为后续进阶。

# 后续｜现场副驾
## Live Show Copilot

这场工作坊继续保留，但不作为当前 31 号主推内容。

它从一套实际使用的 Resolume Arena 工程开始，把爆闪、固定 BPM、视觉片段、脚踏、按键和推子组织成一个真正能演的现场系统。AI / MCP 帮助更快准备工程，真正开始以后，仍由人去听、看、判断和控制现场。

核心不是一直切素材，而是知道什么时候压低、什么时候推进、什么时候爆闪、什么时候收掉。
