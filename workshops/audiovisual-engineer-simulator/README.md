# 视听工程师模拟器
## Audiovisual Engineer Simulator

**主讲：** 钱誉文 Ewan Qian

《视听工程师模拟器》从《极简输入》继续往真实现场推进。科目一解决“我能演了”，科目二解决“我能搭了”。

《现场副驾》打开 Ewan 自己演出时使用的 Resolume Arena 工程，学习怎样组织爆闪、节拍与控制层，准备时间参考，再进入 DJ 现场模拟。

《舞台复刻》从参考图、现场视频、虚拟世界或自己的视觉作品开始，学习观察、解构、组织和重构，让同一个舞台拥有不同状态，最后通过网页预演和分享。

AI / MCP 辅助整理控制与空间；参与者练习现场判断和创作编排。

## 科目一 现场副驾
### Live Show Copilot
**把现场演出的节奏，整理成一套真正能操作的控制系统**

**如果音乐已经开始，只给你几个按钮和几层视觉，你能不能把现场的节奏真正控制起来？**

这场工作坊会直接打开我自己演出时使用的 Resolume Arena 工程，拆解我平时怎样组织几套不同频率、不同密度的爆闪和节拍状态，再把它们整理成一套现场真正能用的控制系统。

演出开始以前，我们也会讨论怎么和 DJ 确认 BPM 与 Beat Link 信息、怎么看音乐波形和结构、什么时候需要用 Ableton Link 同步 BPM，以及怎样把这些时间信息真正接进自己的工程。

只有键盘也可以，有 MIDI、脚踏和推子也可以继续扩展。AI / MCP 会帮助大家更快整理这些控制关系，但真正开始演出以后，什么时候保持、什么时候增加能量、什么时候改变爆闪方式、节奏跑掉以后怎么重新跟上，还是由你自己判断。

**最后，我们会把这套系统真正带进一次 DJ 现场模拟。**

[现场副驾 长版与课程安排](./module-01-one-button-show-control.md)

## 科目二 舞台复刻
### Stage Replica
**把一个喜欢的现场拆开、重组，再变成自己的舞台**

**你有没有看过一场特别喜欢的演出、一个游戏世界或者电影场景，想过：如果这个现场交给我，我会把它变成什么样？**

这场工作坊会从一张参考图、一段现场视频、一个虚拟世界，或者你自己已经做好的视觉开始。

我们会先把一个好的现场“拆开”：哪里是视觉中心，屏幕之间是什么关系，观众看到的空间是怎样被组织出来的。

然后重新搭一个自己的版本。

你可以换掉屏幕里的内容，加入自己的视频、3D 模型、人物或其他素材，也可以重新安排灯光、视觉和声音，让同一个舞台从安静的铺垫逐渐进入更强烈的状态。

最后通过网页直接预演和分享。

**你得到的不只是一个舞台模型，而是一套以后真正想搭一个现场时，可以重新使用的方法。**

[舞台复刻 长版与课程安排](./module-02-stage-previsualization.md)

## 两场差异

|  | 现场副驾 | 舞台复刻 |
|---|---|---|
| 完成后的实感 | 我能演了 | 我能搭了 |
| 核心方法 | 时间、节拍、状态、层次与恢复 | 观察、解构、屏幕角色、空间组织与编排 |
| 人的核心能力 | 现场判断 | 创作与组织 |
| AI / MCP 的作用 | 整理控制关系与 Mapping | 整理参考与场景，辅助重构 |
| 主要路径 | Arena 工程与键盘，可扩展 MIDI、脚踏、推子 | 网页预演与分享，可扩展 Blender / MCP |
| 最终练习 | DJ 现场模拟 | 同一舞台的四种状态 |
| 延伸 | 继续优化自己的控制系统 | Visual Audio 从视觉结构组织音乐 |

## Visual Audio Bonus

从已经完成的视觉编排反过来组织音乐。基础版使用 Web Audio；使用 Ableton Live 的参与者可利用现有音乐库、MIDI 和 Arrangement，把视觉阶段转换成音乐结构。
