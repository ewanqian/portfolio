# 科目一｜现场副驾
## Live Show Copilot
### AI-Assisted Show Control

**系列：** 视听工程师模拟器 / Audiovisual Engineer Simulator  
**长标题：** 如果一整套现场演出最后只能留几个按钮，你会留下什么？

> AI 帮你搭好控制，人负责真正的现场。

## 工作坊简介

上一期《极简输入：构建视听系统》从一个按钮开始，把最简单的输入变成可以演奏、可以分享的视听系统。

《现场副驾》继续把这个系统带进真实现场。

参与者会先让 AI / MCP 帮忙，把一个复杂的演出工程整理成少量、分层、可操作的控制：哪些按钮负责节拍，哪些负责爆发，哪些负责 BLACK / CLEAR，哪些负责恢复。

只有键盘也可以；有 MIDI、脚踏、旋钮或推子，也可以继续接进去。

真正演出开始以后，AI 不替你判断。你需要自己听 DJ、跟 BPM、Tap、Resync，在该推高的时候推高，该拉掉的时候拉掉，再在现场跑偏以后把它找回来。

最终得到的是一套属于自己的 **Show-Control Rig**。

## 3 小时结构

### 00:00–00:25｜从一个按钮开始
回顾“按下、持续、结束”，把已有输入整理成最小控制逻辑。

### 00:25–00:55｜AI 帮你整理控制
把键盘 / MIDI / 脚踏 / Fader 与现场状态交给 Agent，整理 Input → Mapping → Layer → State → Safety。

### 00:55–01:20｜BPM 与同步
练习 Tap、Resync；理解 Ableton Link 等同步方法解决什么问题。

### 01:20–02:00｜搭 Show-Control Rig
安全底层、BPM / Pulse、Visual Clips、Strobe / Accent、BLACK / CLEAR / Recover。

### 02:00–02:30｜现场能量
准备慢速 / 呼吸、稳定正拍、密集、切分 / 突发等不同节拍与能量状态。

### 02:30–03:00｜理论考 + DJ 现场模拟
先听状态，再进入随机桥段的现场测试。

### 3 小时后
自由测试、重复练习、继续优化自己的控制系统。

## 考核

### 理论考｜听状态

直接听音乐，在：

**保持 / 推进 / 爆发 / 拉掉 / 恢复**

之间做判断。

### 路考｜DJ 现场模拟

参与者和 DJ 老师共同完成一段现场。桥段不会按固定脚本提前公布，但会覆盖：

- 铺垫；
- 稳定节拍；
- 能量增加；
- Drop；
- 停顿 / 气口；
- 密集节拍；
- 收束。

最低检查：

- Tap / Resync 正常；
- 至少 3–4 种节拍 / 闪烁状态；
- 能量能升也能降；
- 会留白；
- 出错能恢复。

## 参与者准备

- 笔记本电脑；
- 耳机；
- 可选 MIDI 控制器、脚踏、键盘、Fader；
- 可选自己的 Arena、Processing、TouchDesigner、网页实时视觉或其他工程。

没有控制器、没参加上一期也可以参加。
