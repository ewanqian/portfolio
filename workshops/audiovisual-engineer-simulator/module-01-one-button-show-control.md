# 科目一｜一键控场
## One-Button Show Control

**系列：** 视听工程师模拟器 / Audiovisual Engineer Simulator  
**正式副题：** 科目一｜现场控制系统 / Module 01｜Live Show Control System  
**长标题：** 从一个按钮开始，怎么控制一整场演出？

> 用几个按钮、一套节拍和几层视觉，搭一套能跟、能停、能起来，也能收回来的现场工程。

## 工作坊简介

上一期《极简输入：构建视听系统》从一个按钮开始，把最简单的输入变成可以演奏、可以分享的视听系统。

《一键控场》继续向真实现场推进。问题不再是“还能增加什么效果”，而是音乐开始以后，你能不能听懂正在发生什么，并用尽可能少的控制把整场演出稳定地做下来。

课程从 **按下 → 持续 → 结束** 重新开始，进入 BPM、Tap、Resync、Ableton Link、脚踏、MIDI 控制器、推子和 Resolume Arena。课堂会拆开一套实际的现场工程：

```text
安全底层
↓
固定 BPM / 呼吸层
↓
Visual Clips
↓
爆闪 / 强调层
↓
BLACK / CLEAR / 恢复
```

## 现场思维

演出前先拿信息。

最基础的做法就是看 DJ、听音乐、看 BPM 和波形，理解下一段大概什么时候发生。条件允许时，可以继续了解 Pro DJ Link、Beat Link、Open Beat Control 等工具；有 Ableton Link 时，可以让兼容软件共享 BPM / 音乐时间。

课堂不把复杂网络配置作为目标。关键是形成一个习惯：

- 有自动同步就使用同步。
- 没有自动同步就 Tap。
- Tap 偏了会 Resync。
- 什么信息都拿不到时，仍然能靠耳朵和现场判断继续演。

## 四类基础节拍状态

参与者至少准备 3–4 种真正有区别的状态：

1. **慢速 / 呼吸**：铺垫、低能量和长段落。
2. **稳定正拍**：建立明确的节奏感。
3. **密集闪烁**：能量明显上升。
4. **切分 / 突发**：碎拍、Fill、Drop 或突然强调。

再通过不同 Envelope 把同一种节拍做成硬切、快速衰减、缓慢呼吸或断续状态。

素材不需要一直换。真正重要的是工程能不能把能量推起来，也能及时压下来。

## 三小时结构

### 00:00–00:25｜前情提要：一个按钮
快速回顾“按下、持续、结束”。没有参加上一期也可以直接进入。

### 00:25–00:55｜演出前先拿信息
看 DJ、听音乐、理解 BPM、波形、段落和现场设备。Pro DJ Link / Beat Link / Open Beat Control 作为后续技术地图点到为止。

### 00:55–01:20｜时间与同步
练习 Tap、Resync；介绍 Ableton Link 的最基本用途：让兼容软件共享 BPM / 时间。

### 01:20–02:00｜拆现场工程
安全底层、固定 BPM 层、Visual Clips、爆闪 / 强调层、总推子、BLACK / CLEAR / 恢复。

### 02:00–02:30｜四种节拍状态
慢速 / 呼吸、稳定正拍、密集、切分 / 突发；观察不同 Envelope 如何改变视觉质感。

### 02:30–03:00｜理论考 + 现场模拟
先做短音乐片段的状态判断，再进入 DJ 演出场景模拟。

### 3 小时后｜自由测试
继续上机、反复练同一首音乐、修改自己的按键和工程结构。

## 考核

### 理论考｜听状态
直接播放不同音乐片段。参与者使用已经准备好的状态判断：

**保持 / 推进 / 爆发 / 拉掉 / 恢复**

测试的不是软件菜单，而是有没有听懂当前音乐的能量和结构。

### 路考｜DJ 现场模拟
模拟有 DJ 演出的真实场景。参与者与一位 DJ 老师共同完成一段现场。桥段不会按照固定顺序提前公布，但会覆盖课堂已经练习过的铺垫、稳定节拍、Drop、突然停顿、密集节拍、高潮与收束。

最低通过条件：

- Tap / Resync 能够正常使用；
- 至少能调用 3–4 种节拍 / 闪烁状态；
- 能量能够升，也能够降；
- 知道气口和停顿什么时候应该拉掉或保持；
- 出错或节奏偏移以后能够回到安全状态继续演。

## 参与者准备

- 笔记本电脑和耳机。
- 欢迎携带 MIDI 控制器、脚踏、键盘等输入设备。
- 已有 Resolume Arena、Processing、TouchDesigner、网页实时视觉或自己的程序，可以直接带来。
- 没有控制器也可以参加。
- 没参加过上一期《极简输入》也可以参加。

## 课后练习

反复使用同一首音乐练习自己的工程：

- 什么时候进入；
- 什么时候保持；
- 什么时候闪；
- 什么时候拉掉；
- BPM 偏了以后怎么回来。

目标不是一次做得更复杂，而是让控制越来越可靠。
