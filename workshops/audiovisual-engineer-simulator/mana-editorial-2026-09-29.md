# 01｜一键控场
## One-Button Show Control
**视听工程师模拟器 · 科目一｜现场控制系统**  
**Audiovisual Engineer Simulator · Module 01｜Live Show Control System**

### 一句话
**从一个按钮开始，怎么控制一整场演出？**

### 简介
音乐开始以后，真正困难的并不是“还有多少视觉可以切”，而是你知不知道什么时候该动、什么时候该停。

《一键控场》从“按下、持续、结束”开始，进入 BPM、Tap、Resync、Ableton Link、脚踏、MIDI 控制器、推子和 Resolume Arena，并拆开一套现场工程：安全底层、固定节拍层、视觉 Clips、爆闪 / 强调层，以及随时可以拉掉和恢复的控制。

课程最后会模拟有 DJ 演出的场景。参与者与一位 DJ 老师共同完成一段现场，面对随机出现、但覆盖课堂重点能力的桥段：铺垫、Drop、停顿、密集节拍、高潮与收束。你需要判断什么时候保持、什么时候增加能量、什么时候拉掉，以及什么时候重新 Tap / Resync。

### 3 小时安排
- **前情提要**：一个按钮——按下、持续、结束。
- **演出前先拿信息**：看 DJ、听音乐、理解 BPM、波形和段落。
- **时间与同步**：Tap、Resync、Ableton Link。
- **现场工程**：安全层、BPM 层、Visual Clips、爆闪层、BLACK / CLEAR / 恢复。
- **节拍状态**：慢速、正拍、密集、切分 / 突发。
- **现场模拟**：理论考 + DJ 场景测试。

### 考核
**理论考：听状态。**  
直接听音乐，判断保持、推进、爆发、拉掉和恢复。

**路考：DJ 现场模拟。**  
检查 BPM、3–4 种节拍状态、能量升降、留白和现场恢复。

### 参与准备
笔记本电脑 + 耳机即可。欢迎携带 MIDI 控制器、脚踏或键盘；没有控制器也可以参加。没参加过上一期也可以直接加入。

### 素材建议
上一期返图 / 网页作品；Arena 分层工程；脚踏与 MIDI 控制器；Tap / Resync；不同闪烁状态；DJ + 操作者 + 屏幕同框短视频。

# 02｜舞台预演
## Stage Previsualization
**视听工程师模拟器 · 科目二｜视觉工程、空间组织与现场预演**  
**Audiovisual Engineer Simulator · Module 02｜Visual Engineering, Spatial Organization & Live Previs**

### 一句话
**画面做好以后，放到真正的舞台上还成立吗？**

### 简介
视觉进入真实舞台以后，会重新面对屏幕尺寸、观看距离、曲面、多屏、Mapping 和时间结构。

《舞台预演》从“读场”开始：整理屏幕、尺寸、分辨率和 Mapping，再决定主屏 / 副屏分别承担什么、内容是否连续、音乐还是视觉承担主要结构。课堂用“铺垫、建立、爆发、收束”四个状态建立最小时间结构，再通过预演程序把真正的视频放进数字舞台，从不同观看位置检查并继续修改。

Blender 用于进一步展示场景、相机、灯光、时间线、Mark、关键帧和输出；Agent 用于把零散场地资料整理成屏幕规格和可继续调用的场景描述。

课程会使用 ENTROPY Show 的实际准备作为案例：曲面主屏原生画幅 9600 × 3456（25:9），并与天屏共同工作。通过网页预演程序，可以在正式进场以前快速检查上下屏幕 Mapping 与不同观看位置的视觉效果。

### 3 小时安排
- **读场**：屏幕、尺寸、比例、Mapping、观看位置。
- **视觉工程组织**：主屏 / 副屏角色、Master Canvas、连续 / 独立内容。
- **时间结构**：音乐主导、视觉主导、共同结构。
- **Blender 示范**：模型、镜头、灯光、时间线、关键帧与输出。
- **Agent + 场景描述**：整理 Screen A / B 与规格信息。
- **网页预演**：视频 → Mapping → 数字舞台 → 观看位置。
- **舞台题测试**：快速完成读场、组织和预演。

### 考核
**理论考：读场与组织。**  
面对陌生 Venue Brief，判断屏幕、角色、Mapping 与内容结构。

**路考：舞台题目。**  
随机抽取超宽屏、主屏 + 天屏、曲面屏或多屏 / 异形屏，完成读场、Mapping、四状态、预演和规格说明。

### 最终成果
一份场景描述、一份屏幕规格说明、一个可运行预演，以及一个包含“铺垫 → 建立 → 爆发 → 收束”的最小视觉工程。

### 参与准备
笔记本电脑、鼠标、耳机。建议具备基础 Blender 使用经验；没有 Blender 基础也可以参加或旁听。

### 素材建议
ENTROPY Show 预演视频 / 截帧；曲面主屏 + 天屏；预演程序录屏；Blender 场景与时间线；Screen A / B 规格说明；“Venue Brief → Specification → Mapping → Preview”流程图。

## 可给联合推文使用的总引言

从采集声音，到控制现场，再到把舞台提前放进一个可以测试的空间：三场工作坊从不同入口进入同一个问题——怎样把声音、视觉、控制与空间组织成真正可以发生的现场实践。
