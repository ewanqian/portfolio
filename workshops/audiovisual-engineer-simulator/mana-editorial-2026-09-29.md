# 01｜现场副驾
## Live Show Copilot

**副标题：在 AI Agent 的帮助下快速组织工程，并有意识地控制整个现场。**

### 社交媒体短版

你看过很多场演出，但可能从来没真正站到过控制台后面。

真正开始操作以后，先要知道 DJ 现在的 BPM，能不能看到 Beat Link，波形走到哪里，要不要用 Ableton Link 让自己的工程跟住 BPM。拿不到自动同步，也可以直接听，用 BPM 控制键重新跟上。

音乐比较低的时候，可以把闪烁的亮度压得很低，只留下那种在空气里能捕捉到的低频频闪。DJ 开始不断重复、铺垫情绪，进入 Bridge，就可以切到更高的闪烁状态，比如 75%，再通过推子继续把亮度往上拉。到了冲击最强的时候，爆闪可以直接拉到最大，整个空间和烟雾一起闪起来。

Drop 之后马上要停的时候，画面也可以直接按掉。因为只有前面真的暗下来，后面重新亮起来的时候才会有力量。如果一直亮着，大家很快就累了。

这场工作坊会直接打开一套实际使用的 Resolume Arena 工程，看爆闪层、固定 BPM 层和视觉片段怎么组织，也会实际使用脚踏、按键和推子，练习几种不同的闪烁频率和实时动画曲线。

你可以带自己的 MIDI 控制器、脚踏，也可以直接使用电脑键盘。AI / MCP 会帮助你更快把这些控制接到自己的设备和工程里。真正开始以后，还是由你自己去听、去看、去判断，清晰、有意识地控制整个现场。

### 3 小时

**00:00–00:25** 打开一套真正的现场工程  
**00:25–00:55** BPM、Beat Link、波形、Ableton Link 与手动重新对齐  
**00:55–01:30** 三四种不同的闪烁状态与实时动画曲线  
**01:30–02:00** 键盘、MIDI、脚踏、推子  
**02:00–02:30** 跟着一段音乐练习强弱和收放  
**02:30–03:00** DJ 现场模拟

### 考核

**理论考｜听状态**：直接听音乐，使用已经准备好的几种状态去跟，检查 BPM、闪烁方式、亮度与强弱、气口和收放。  

**路考｜DJ 现场模拟**：模拟有 DJ 演出的场景，不提前把全部变化做成一条时间线，而是在现场听、看、判断和操作。

### 参与准备

笔记本电脑和耳机即可。可带 MIDI 控制器、脚踏、带推子的控制器，以及自己的 Arena / Processing / TouchDesigner / 网页实时视觉。

# 02｜舞台复刻
## Stage Replica

**副标题：从一张参考图、一段现场视频或一个虚拟世界开始，把自己的内容真正放进一个完整的现场。**

### 社交媒体短版

你可能已经做过一些自己的视觉，也可能看过一场特别喜欢的演出，脑子里想过它真正被展示出来会是什么样。

这场工作坊会从一张参考图、一段现场视频、一个游戏或电影里的虚拟世界，或者你已经做好的内容开始。

先看这个现场是怎么被组织出来的：视觉中心在哪里，主屏在做什么，其他屏幕怎么配合，人物、灯光、声音和画面是什么关系。然后把最重要的部分重新搭出来。

接下来就可以开始换成自己的东西：放进自己的视频，加入 AI 素材、人物或舞者、3D 模型，重新安排灯光和声音，再让同一个舞台经历铺垫、建立、爆发、收束几种不同的状态。

最后通过网页把这个现场真正跑起来，可以预演，也可以继续分享。

做完以后留下的不只是一个舞台模型，而是一套以后真正想做一个现场时，知道怎么拆、怎么搭、怎么编排的方法。

### 3 小时

**00:00–00:25** 选一张参考图、一段现场视频、一个虚拟世界或自己的视觉  
**00:25–00:55** 看视觉中心、主屏、其他屏幕、人物、灯光和空间关系  
**00:55–01:25** 保留最重要的关系，重新搭一个版本  
**01:25–01:55** 放入视频、AI 素材、人物 / 舞者、3D 模型和灯光  
**01:55–02:25** 做铺垫、建立、爆发、收束四种状态  
**02:25–02:45** 网页预演  
**02:45–03:00** Blender、MCP、Visual Audio 扩展

### 考核

**理论考｜看懂一个现场**：面对新的参考场景，找到视觉中心、主要屏幕、其他屏幕的作用、人物和空间的关系。  

**路考｜做一个自己的版本**：面对超宽屏、主屏 + 天屏、曲面屏或多块屏幕等组合，完成“看场景 → 搭主要屏幕 → 放自己的内容 → 做四种状态 → 网页预演”。

### Visual Audio｜Bonus

当一个舞台已经有了自己的时间结构，可以进一步尝试让音乐跟着视觉编排长出来。

基础版本可以使用 Web Audio；如果有 Ableton Live，也可以利用音乐库、MIDI 和编排，把视觉状态继续变成音乐结构。

### 参与准备

笔记本电脑、鼠标、耳机。可带参考图、现场录像、游戏 / 电影场景、自己的视频、3D 模型或 Blender 工程。没有 Blender 基础也可以参加。

## 编辑素材建议

### 现场副驾

Arena 工程截图与分层画面；不同闪烁状态的视频；脚踏实际操作；推子控制亮度与爆闪强度；DJ 的 BPM / 波形信息；操作者、控制台和屏幕同框；低频闪烁 → 高强度爆闪 → 画面拉掉的连续片段。

### 舞台复刻

ENTROPY Show 现场照片与预演视频；主屏 + 天屏等不同屏幕组合；参考场景 → 简化场景 → 换成自己的内容的对照；网页不同观看位置；Blender 场景 / 时间线；铺垫、建立、爆发、收束四种状态对照；Visual Audio 的视觉 / 声音对应录屏（如已有）。
