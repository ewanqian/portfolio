# 01｜现场副驾
## Live Show Copilot
**视听工程师模拟器 · 科目一｜AI-Assisted Show Control**

### 钩子
**如果一整套现场演出最后只能留几个按钮，你会留下什么？**

### 简介
这场工作坊会先让 AI / MCP 帮你把复杂的视觉工程整理成一套真正能上手的现场控制系统。

只有键盘也可以；有 MIDI、脚踏、旋钮和推子，也可以继续接进去。

你会准备几种不同的节拍、闪烁和能量状态，把 Tap、Resync、BLACK、恢复等关键动作放到最顺手的位置。

真正开始演出以后，AI 不替你判断。你需要自己听 DJ、跟住 BPM，在该推高的时候推高，该拉掉的时候拉掉，再在跑偏以后把现场找回来。

最后，你会带着自己搭好的 **Live Show Copilot**，进入一次随机桥段的 DJ 现场模拟。

### 3 小时
一个按钮 → AI 整理控制 → Tap / Resync → Show-Control Rig → 节拍 / 能量状态 → DJ 现场模拟

### 考核
**理论考：听状态**  
直接听音乐，在保持、推进、爆发、拉掉、恢复之间做判断。

**路考：DJ 现场模拟**  
与 DJ 老师共同完成随机桥段，检查 BPM、3–4 种节拍状态、能量升降、留白和恢复。

### 准备
笔记本电脑 + 耳机即可。欢迎自带 MIDI 控制器、脚踏、键盘或 Fader；没有控制器、没参加上一期也可以参加。

# 02｜舞台复刻
## Stage Replica
**视听工程师模拟器 · 科目二｜Build, Remix & Previsualize a Digital Stage**

### 钩子
**你有没有看过一场演唱会、一款游戏或者一个电影场景，想过：如果这个舞台是我的，我会在上面放什么？**

### 简介
这场工作坊会从一张参考图、一段现场视频或者一个你喜欢的虚拟世界开始，把它重新整理成一个可以播放自己内容的数字舞台。

你会找到里面最重要的屏幕和空间结构，把自己的视频 Mapping 进去，再从不同位置查看它真正出现在现场时是什么样。

你可以复刻一个巨型演唱会、游戏基地、科幻空间，也可以继续改造它：换掉屏幕、改变比例、加入自己的内容。

最后，你会得到一个属于自己的**舞台沙盘**。

主线使用网页工具，没有 Blender 基础也可以完成；会 Blender 的参与者可以继续通过 Blender / MCP 加入模型、相机、灯光和动画。

### 3 小时
选参考世界 → 拆出舞台 → 改成自己的 → Mapping 内容 → AI / MCP 辅助 → 网页预演 → 最终挑战

### 考核
**理论考：读场**  
快速找出主要屏幕、空间结构和内容关系。

**路考：舞台复刻**  
完成参考场景 → 屏幕结构 → Mapping → 自己的内容 → 四状态 → 预演，并检查远看、近看和跨屏关系。

### Bonus｜Visual Audio
如果不是音乐驱动画面，而是让画面反过来生成音乐呢？

课程会展示如何把视觉工程里的镜头、运动、关键帧和场景状态，通过 Agent / MCP 转换成音乐结构的输入。

### 准备
笔记本电脑、鼠标、耳机即可。可以自带一张参考图、一段现场视频，以及自己的视频 / 模型 / Blender 工程。
