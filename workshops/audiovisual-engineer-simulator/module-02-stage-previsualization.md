# 科目二｜舞台复刻
## Stage Replica
### 拆一场喜欢的演出，再做成自己的现场

**系列：** 视听工程师模拟器 / Audiovisual Engineer Simulator  
**当前状态：** 2026-10-14 主推版本

## 短版

你可能看过一场特别喜欢的演出，也可能已经做过一些自己的视觉，只是从来没有真正把它放进一个完整的舞台里。

《舞台复刻》会从一张参考图、一段现场视频、一个游戏或电影里的虚拟空间，或者你已经做好的内容开始。

先拆出这个现场最重要的屏幕、人物和空间关系，再把自己的视频、AI 素材、人物、舞者或 3D 模型放进去，让同一个舞台经历**铺垫、建立、爆发、收束**几种不同状态，最后在网页里真正跑起来。

做完以后留下来的不只是一个模型，而是一个可以继续修改、预演和分享的数字现场。

更重要的是，以后再看到一场喜欢的演出，会开始知道它是怎么拆、怎么搭、怎么重新编排的。

## 完整介绍

很多时候，真正的问题不是“会不会做一条视觉”，而是：

**这些内容最后会出现在哪？**

主屏在做什么？其他屏幕怎么配合？人物站在哪里？灯光什么时候只是辅助，什么时候真正改变整个空间？

《舞台复刻》不会先从学 Blender 开始，也不会要求一上来就把整个现场一比一复制。

第一步先看懂一个现场真正重要的关系。

### 先把喜欢的现场拆开

一个看起来很复杂的大型演出，真正开始拆以后，往往不需要把所有细节全部复制。

先找：

- 视觉中心在哪里
- 主屏承担什么
- 其他屏幕什么时候和主屏一起工作
- 人物和画面是什么关系
- 哪些东西一直存在
- 哪些东西只在某个状态出现
- 灯光什么时候开始真正改变空间

目的不是做一个完美复制品，而是以后再看到一个喜欢的现场时，开始知道：

> **这个东西到底是怎么成立的。**

### 再做成自己的版本

关系搭出来以后，开始替换内容。

可以：

- 放自己的视频
- 加入 AI 生成素材
- 加入人物 / 舞者
- 放入 3D 模型
- 改屏幕之间的关系
- 重新安排灯光

有时候主屏一直是视觉中心；有时候几块屏幕平时完全独立，到了最强的状态才第一次连在一起。

重点不是让所有屏幕从头到尾都有东西，而是：

> **什么时候让什么东西出现。**

### 同一个舞台做四种状态

课堂先用四种最小状态让场景真正开始有时间：

**铺垫 → 建立 → 爆发 → 收束**

这些状态可以通过视觉、人物、模型、灯光、速度、密度和屏幕关系发生变化。

### 通过网页进行预演

最后不会只停留在效果图。

我们会把主要屏幕和空间关系放进网页，再把真正要播放的内容放进去：

- 切换观看位置
- 替换内容
- 看几块屏幕怎么配合
- 做多机位 / Program 预览
- 继续修改

之前 ENTROPY 的 Stage Forge / 场景查看器可以作为这一条路线的前情：已经验证过浏览器里查看舞台和屏幕关系；这期继续推进到参考复刻、自己的内容、多机位与实时 screen source。

上一期音画同源 / WebGL 演出面板也可以直接成为这一期舞台屏幕里的实时内容源。

### Web / Realtime Source

网页中的屏幕统一支持：

- `file`：mp4 / webm / image
- `canvas`：Three.js / Shader / Visual Audio
- `capture`：`getDisplayMedia()` 捕获浏览器标签页 / 窗口
- `webrtc`：另一台电脑实时送入视频轨

第一版 WebRTC 的目标很简单：

> **把另一块正在运行的网页视觉，真正送进 Stage Replica 的舞台屏幕。**

### Blender 是扩展，不是门槛

会 Blender 的参与者可以继续扩展时间线、相机、灯光、模型、动画和 Blender MCP。

不会 Blender，也可以沿着网页主线完整完成。

## 3 小时安排

- **00:00–00:25｜选一个参考**：参考图、现场视频、游戏 / 电影空间或自己的视觉。
- **00:25–00:55｜拆现场**：找视觉中心、屏幕、人物、灯光和最重要的空间关系。
- **00:55–01:25｜搭第一版**：保留真正重要的结构，不追求一比一复制。
- **01:25–01:55｜换自己的内容**：视频、AI 素材、人物 / 舞者、3D 模型。
- **01:55–02:25｜做四种状态**：铺垫、建立、爆发、收束。
- **02:25–02:45｜网页预演**：把内容放进屏幕，切换观看位置，看第一版的问题。
- **02:45–03:00｜第二遍修改 / 扩展**：再改一遍，并展示 Blender、MCP、Visual Audio 等后续方向。

## 考核 / 最小闭环

不是只完成第一版。

最小闭环应该是：

**看场景 → 搭第一版 → 放自己的内容 → 做四种状态 → 预演 → 看出一个问题 → 再改一次**

只要第二版比第一版更明确，课堂就已经开始建立真正的空间判断。

## 参与准备

- 笔记本电脑、鼠标
- 可选：喜欢的现场参考图 / 演出录像 / 游戏或电影空间
- 可选：自己的视频 / AI 素材 / 3D 模型 / Blender 工程
- 没有 Blender 基础、没有自己的素材也可以参加
