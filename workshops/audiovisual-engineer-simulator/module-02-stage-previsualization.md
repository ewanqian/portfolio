# 科目二｜舞台复刻
## Stage Replica
### Build, Remix & Previsualize a Digital Stage

**系列：** 视听工程师模拟器 / Audiovisual Engineer Simulator  
**长标题：** 你有没有看过一场演唱会、一款游戏或者一个电影场景，想过：如果这个舞台是我的，我会在上面放什么？

> 复刻一个你喜欢的世界，再把它改造成自己的舞台。

## 工作坊简介

这场工作坊会从一张参考图、一段现场视频，或者一个你喜欢的虚拟世界开始，把它重新整理成一个可以播放自己内容的数字舞台。

你会找到里面最重要的屏幕和空间结构，把自己的视频 Mapping 进去，再从不同位置查看它真正出现在现场时是什么样。

你可以复刻一个巨型演唱会、游戏基地、科幻空间，也可以继续改造它：换掉屏幕、改变比例、加入自己的内容。

最后，你会得到一个属于自己的舞台沙盘。

主线以网页工具为主，没有 Blender 基础也可以完成。会 Blender 的参与者，可以继续通过 Blender / MCP 加入模型、相机、灯光、动画和更完整的空间结构。

## AI / MCP 在这里做什么

Agent 可以帮助：

- 从参考图、视频和场地资料里识别主要播放面；
- 整理 Screen A / B / C；
- 生成屏幕比例、尺寸、Mapping 与场景描述；
- 辅助生成或修改网页舞台；
- 会 Blender 时继续调用 Blender / MCP；
- 留下给人看的规格说明和机器可继续使用的场景数据。

## 3 小时结构

### 00:00–00:25｜选一个你想进入的世界
从演唱会、游戏、电影、虚拟空间或展览现场里选参考。

### 00:25–00:55｜拆出舞台
找到主要屏幕、空间结构和观看关系。

### 00:55–01:20｜把它改成自己的
决定主屏 / 副屏分别承担什么，内容是连续还是独立。

### 01:20–01:55｜放进自己的内容
建立 Mapping，并用“铺垫 → 建立 → 爆发 → 收束”做出最小时间结构。

### 01:55–02:25｜AI / MCP 辅助
整理 Screen / Stage Description；会 Blender 的参与者继续扩展模型、相机和灯光。

### 02:25–02:45｜网页舞台预演
视频 → Mapping → 数字舞台 → 不同观看位置。

### 02:45–03:00｜最终挑战
检查这个舞台远看、近看、跨屏以后是否成立。

### 3 小时后
继续预演、展示和修改个人舞台。

## 考核

### 理论考｜读场

拿到一个陌生场景，快速判断：

- 主要屏幕在哪里；
- 哪些空间值得保留；
- 哪些内容应该连续；
- 哪些内容应该独立；
- 自己的内容应该放在哪里。

### 路考｜舞台复刻

随机拿到：

- 超宽屏；
- 主屏 + 天屏；
- 曲面屏；
- 多屏 / 异形屏。

完成：

**参考场景 → 屏幕结构 → Mapping → 自己的内容 → 四状态 → 预演**

最终看三件事：

- 远处看成立吗？
- 近处看成立吗？
- 屏幕之间连得起来吗？

## 演出案例

课程会引用一次 **ENTROPY Show** 的实际准备作为案例。

现场使用曲面主屏与天屏，主屏原生画幅为 **9600 × 3456（25:9）**。通过网页预演程序，可以在真正进场以前先检查多屏 Mapping 和不同观看位置的效果。

## Visual Audio｜Bonus

课程还会展示一个正在发展的实验：

> **如果不是音乐驱动画面，而是让画面反过来生成音乐呢？**

视觉工程里的 Camera Move、Keyframe、Light、Object Motion 与 Scene State 可以通过 Agent / MCP 被整理成音乐结构的输入。

## 参与者准备

- 笔记本电脑；
- 鼠标；
- 耳机；
- 可选一张参考图、一段现场视频或一个喜欢的虚拟空间；
- 可选自己的视频、模型或 Blender 工程。

没有 Blender 基础也可以参加。
