# 科目二｜舞台复刻
## Stage Replica
### 从一张参考图、一段现场视频或一个虚拟世界开始，把自己的内容真正放进一个完整的现场

**系列：** 视听工程师模拟器 / Audiovisual Engineer Simulator

## 社交媒体短版

你可能已经做过一些自己的视觉，也可能看过一场特别喜欢的演出，脑子里想过它真正被展示出来会是什么样。

这场工作坊会从一张参考图、一段现场视频、一个游戏或电影里的虚拟世界，或者你已经做好的内容开始。

先看这个现场是怎么被组织出来的：视觉中心在哪里，主屏在做什么，其他屏幕怎么配合，人物、灯光、声音和画面是什么关系。然后把最重要的部分重新搭出来。

接下来就可以开始换成自己的东西：放进自己的视频，加入 AI 素材、人物或舞者、3D 模型，重新安排灯光和声音，再让同一个舞台经历铺垫、建立、爆发、收束几种不同的状态。

最后通过网页把这个现场真正跑起来，可以预演，也可以继续分享。

做完以后留下的不只是一个舞台模型，而是一套以后真正想做一个现场时，知道怎么拆、怎么搭、怎么编排的方法。

## 完整介绍

这场工作坊不会先从学 Blender 开始。

可以先拿一张参考图、一段现场视频、一个虚拟世界，或者自己已经做好的视觉来看。第一步是理解这个现场为什么成立，再把最重要的关系做出来。

### 先看一个现场怎么被组织出来

一个复杂的演出，可以先找到里面最重要的几个东西：

视觉中心在哪里，主屏承担什么，其他屏幕什么时候和主屏一起工作，人物和画面是什么关系，灯光什么时候只是辅助，什么时候开始改变整个空间，声音、视觉和空间是怎么一起推进的。

这一步不是一比一复制所有细节，而是先看懂它最重要的关系。以后再看到一场喜欢的演出，不只是觉得“很酷”，而是知道可以从哪里开始。

### 再重新做一个自己的版本

最重要的关系留下以后，就可以开始换成自己的内容。

可以放自己的视频，加入 AI 生成的素材，加入人物或舞者，放入 3D 模型，重新做灯光，也可以改变几块屏幕之间的关系。

有时候主屏一直是视觉中心；有时候几块屏幕平时完全独立，到了最强的状态才第一次连在一起。

重点不是让所有屏幕从头到尾都有东西，而是知道什么时候让什么东西出现。

### 同一个舞台做四种状态

课堂里会围绕同一个场景做大概四种状态：

**铺垫、建立、爆发、收束。**

状态可以通过视觉内容改变，也可以通过灯光、人物、模型运动、屏幕关系、速度和密度去改变。

这样一个舞台就不再是一张静态效果图，而是开始有时间、有视觉中心、有起伏。

### 通过网页进行预演

这部分会使用真实现场准备里的方法。

像 ENTROPY Show 这种同时有主屏和天屏的现场，可以先把主要屏幕和空间关系放进网页，再把真正要播放的内容放到对应屏幕里。

以前如果全部用 Blender、Unity 或 Arena 搭预演会比较重，现在可以先通过网页快速搭屏幕、放入内容、切换观看位置、看屏幕之间怎么配合，然后继续修改。

最后这个网页本身也可以继续分享。

### Blender 是扩展，不是门槛

会 Blender 的参与者可以继续看时间线、标记点、关键帧、动画曲线、灯光、相机、模型，以及 Blender MCP。

不会 Blender，也可以沿着网页主线完整完成这场工作坊。

## Visual Audio｜Bonus

当一个舞台已经有了铺垫、建立、爆发和收束，它其实已经有自己的时间结构。

这个时候可以反过来试一次：视觉已经做好了，音乐能不能跟着这套编排长出来？

基础版本可以用 Web Audio。如果有 Ableton Live，也可以利用现有的音乐库、MIDI 和编排，把已经完成的视觉状态变成音乐结构。

重点不是自动生成一首背景音乐，而是让声音和视觉继续使用同一套编排。

## 3 小时安排

- **00:00–00:25｜选一个参考**：一张参考图、一段现场视频、一个游戏 / 电影里的虚拟世界，或者自己的视觉。
- **00:25–00:55｜看这个现场怎么组织**：视觉中心、主屏、其他屏幕、人物、灯光和空间关系。
- **00:55–01:25｜重新搭一个版本**：保留最重要的关系，开始换成自己的现场。
- **01:25–01:55｜放自己的内容**：视频、AI 素材、人物 / 舞者、3D 模型和灯光。
- **01:55–02:25｜做四种状态**：铺垫、建立、爆发、收束。
- **02:25–02:45｜网页预演**：把内容放到对应屏幕，切换观看位置并继续修改。
- **02:45–03:00｜扩展演示**：Blender、MCP、Visual Audio，以及后续可以继续怎么做。
- **3 小时以后**：继续展示、修改和测试。

## 考核方式

### 理论考｜看懂一个现场

面对一个新的参考场景，找到视觉中心、主要屏幕、其他屏幕的作用、人物和空间的关系，以及哪些内容应该一起出现、哪些内容应该分开。

### 路考｜做一个自己的版本

面对超宽屏、主屏 + 天屏、曲面屏或多块屏幕等不同组合，完成：

**看场景 → 搭主要屏幕 → 放自己的内容 → 做四种状态 → 网页预演**

最后留下一个可以继续修改和分享的现场。

## 参与准备

- 可选：一张喜欢的现场参考图、一段演出录像、一个喜欢的游戏 / 电影场景。
- 可选：自己的视频、3D 模型或 Blender 工程。
- 没有 Blender 基础也可以参加。
