# 极简输入实验室
## Minimal Input Lab

**发起 / Initiated by:** Ewan Qian  
**形式 / Format:** Workshop Series · Practice Lab · Online Exercises · Live Tests  
**状态 / Status:** Active / 2026–

> 用尽可能少的输入建立一个可理解、可操作、可迭代的演出系统；先做出一个关系，再增加一层复杂度。

## 这是什么

「极简输入实验室 / Minimal Input Lab」不是某一个软件的培训，也不是单次工作坊的包装。

它把已经发生的「一键输入」「场景铸造」以及后续开发中的「演出 Copilot」整理成一个长期训练体系：从输入、状态、节拍和音画关系开始，逐步进入空间、预演、时间结构、跨工种协作与真实现场。

系列共同的问题是：

**如果只能先控制一件事，应该控制什么？**

我们不从“功能最多”开始，而从“关系最清楚”开始。

## 系列模块

### 01｜一键输入 / One-Button Input

从一个按钮、一个按键或一个动作开始。

```text
INPUT
→ STATE
→ CLOCK / BPM
→ SOUND + VISUAL
→ FEEDBACK
→ NEXT DECISION
```

训练：Mapping、状态、节拍、音画同源、演奏性、恢复逻辑。

### 02｜场景铸造 / Scene Forge

把作品放回空间里检查。

```text
REFERENCE / VENUE
→ GRAY BOX
→ STAGE RELATION
→ CONTENT / LIGHT / PERFORMER
→ PREVIS
→ REVIEW
→ REVISION
```

训练：空间关系、舞台草稿、内容草稿、多屏关系、Stage Plot、Storyboard、Cue、预演与版本修改。

### 03｜演出 Copilot / Show Copilot

把多个媒介和工种组织进同一条演出时间线。

方向包括：Cue、Timeline、Show Score、排练、状态切换、现场决策辅助、错误恢复与演后复盘。

> 该模块仍在开发，不作为已完成课程宣传。

## 共同能力地图

所有模块使用同一套成长逻辑：

### L1 · COPY / 跟做
完成一个明确的标准答案。

### L2 · MODIFY / 单变量修改
只改变一个变量，并能说明为什么。

### L3 · COMPOSE / 编排
把多个状态组织成一段 20–30 秒的结构。

### L4 · COLLAB / 协作
把声音、灯光、表演、屏幕、装置等关系放到同一张图与同一时间线里。

### L5 · PERFORM / 上台
进入真实场地运行、记录、复盘并形成下一版。

## 每个模块必须留下什么

每一期课程都必须至少包含：

1. Learning Outcomes / 学习结果
2. Standard Exercise / 标准答案
3. Step-by-Step / 跟做步骤
4. Checkpoints / 检查点
5. Remix / 自由改造
6. Assessment / 验收
7. Reflection / 复盘
8. Further Reading / 延伸阅读
9. Version / Changelog / Credits

## 线下与线上分工

### 线下

用于高密度示范、讨论、Jam、Critique、同伴交流和真实设备测试。

### 线上

用于重复练习、补课、版本保存、提交、验收、跳关与长期积累。

线下不是把所有知识一次讲完；线上也不是把现场录像重新放一遍。

二者共同组成：

```text
SEE
→ COPY
→ MODIFY
→ REVIEW
→ REPEAT
→ PERFORM
```
