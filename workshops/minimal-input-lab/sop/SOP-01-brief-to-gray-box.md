# SOP-01｜从 Brief 到 Gray Box

## 目的

把一句模糊的“我想做一场这样的演出”转换成一个团队可以共同查看、指出问题并继续修改的空间草稿。

这一步不负责把场景做漂亮，也不负责确定最终视觉风格。它只负责建立共同空间：观众在哪里、屏幕在哪里、人或装置在哪里、哪些关系已经确定、哪些仍是猜测。

## 适用情境

适合：

- 第一次收到一个演出、装置或舞台需求；
- 需要快速判断多屏、折屏、顶部屏、装置或人物关系；
- 场地资料不完整，但需要尽快开始讨论；
- 团队成员使用不同软件，需要一个共同预演层。

不适合：

- 项目只有一个固定正视角，现场照片已经足以完成合成；
- 当前问题只是单条视频内容本身，不涉及空间；
- 已经进入施工图、设备选型或精确灯位阶段，需要更专业的 CAD / 灯光工具。

## 输入

开始前尽可能收集：

- 场地 PDF / CAD / 屏幕规格；
- 现场照片或公开视频；
- 已知关键尺寸；
- 观众主要观看方向；
- 人物 / 装置 / 主体的大致尺寸；
- 项目 Brief 与必须保留的限制。

资料不完整可以开始，但所有估算必须标记。

## 输出

完成后必须留下：

1. 一个 Gray Box 场景；
2. 一张 Stage Plot / 顶视关系图；
3. 一张主观众视角截图；
4. 一份“已确认 / 待确认”列表；
5. 一个可继续修改的工程或 URL。

## Procedure

### Step 1｜把 Brief 改写成 5 个事实

不要先写风格词。先写：

- 场地是什么；
- 观众在哪里；
- 最重要的主体是什么；
- 必须使用哪些屏幕 / 装置；
- 当前最想验证的问题是什么。

**Gate 1**：如果最后一个问题回答不出来，不进入建模。先确认“为什么要做这个预演”。

### Step 2｜区分已知数据和推测

建立两列：

**Confirmed**：来自场地方、供应商、正式图纸或已确认信息。

**Estimated**：从照片、视频、已知物体比例或经验推测。

**Gate 2**：任何会影响施工、安全或最终输出规格的数据，不允许只依赖 Estimated。

### Step 3｜只搭五类对象

第一版最多只允许：

- Floor / Venue shell
- Main Screen / Secondary Screen
- Audience / Camera
- Performer / Object / Installation placeholder
- One key light or simple light placeholder

不要先做材质、烟雾、复杂反射、粒子和装饰结构。

**Gate 3**：截图转成黑白轮廓后，仍能看懂主要空间关系。

### Step 4｜画 Stage Plot

用二维顶视图标出：

- 观众方向；
- 屏幕；
- 主体；
- 装置；
- 主要灯光方向；
- 关键距离。

如果团队看不懂 Stage Plot，说明 Gray Box 也还没有真正讲清楚。

### Step 5｜固定三个检查视角

至少保存：

1. 主观众视角；
2. 侧面 / 斜侧检查视角；
3. 顶视 / 结构视角。

不要为了“展示效果”不断换镜头。固定视角才能比较版本。

### Step 6｜第一次评审只讨论空间

此时禁止讨论：

- 颜色好不好看；
- 粒子够不够酷；
- 字体；
- Bloom；
- 具体动画细节。

只回答：

- 比例成立吗；
- 有遮挡吗；
- 主体在哪里最清楚；
- 屏幕关系合理吗；
- 观众能看见吗；
- 哪个物理条件还没确认。

### Step 7｜保存 V1

保存工程、三张检查截图、Stage Plot 和已知/未知列表。

文件名必须包含版本，例如：

`project_graybox_v01_2026-11-02`

## 常见失败

### 失败 1｜一开始就做写实

症状：半小时都在调材质和反射，空间关系还没确定。

恢复：复制工程，删除所有非必要材质和后期，只留下 Gray Box。

### 失败 2｜场地尺寸来自猜测，但没人知道

症状：后面所有设计建立在一个“看起来差不多”的尺寸上。

恢复：把所有推测值统一标色 / 标记，列出需要向场地方确认的问题。

### 失败 3｜只保存一个漂亮机位

症状：正面看起来成立，侧面已经穿帮或遮挡。

恢复：强制检查主视角、侧视角、顶视角。

### 失败 4｜Gray Box 被当作最终方案

症状：团队因为第一版已经“能看”，开始过早锁定设计。

恢复：明确标注 V1 只解决空间问题，并要求至少提出两个替代布局后再定稿。

## 完成标准

这条 SOP 完成的标志不是“场景像现场”，而是任何一个没参与建模的人都能在三分钟内回答：

- 观众从哪里看；
- 主体在哪里；
- 屏幕和对象是什么关系；
- 当前正在验证什么；
- 哪些尺寸还不确定。
