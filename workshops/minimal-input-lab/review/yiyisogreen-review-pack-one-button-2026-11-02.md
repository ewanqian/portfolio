## 6. 下一期工作坊：先讨论，不急着定

目前有几条可能继续发展的路线。

### A. One-Button → Instrument

不再只证明“一个按钮能做很多东西”，而是让每个人把一个最小输入练成真正可以演奏 2–5 分钟的数字乐器。

重点：
- Mapping；
- State；
- Clock；
- Quiet / Active / Broken / Recovery；
- Blind Playtest；
- Rehearse → Perform。

### B. ERROR / BROKEN STATE

从你的实践继续展开：故障、错误和失控怎样成为一种有意识的表演材料，而不是简单 glitch aesthetic。

可以和第一期的 Reset / Panic / Recovery 正好形成一组关系。

### C. Shared Control / 双人视听系统

两个人共同控制一个系统：
- 一个人负责结构 / State；
- 一个人负责连续参数 / Gesture；
- 或 Sound / Visual 不再各管一边，而是共享同一套状态。

重点研究“控制权怎么分”。

### D. Workshop → Rehearsal → After Party

第一次做 V1；课后继续练；第二次带自己的系统回来排练；最后真的在大屏 / 扩声环境里演一次。

这一条更接近长期项目，而不是一次三小时活动。

这些都只是讨论草案，希望先听你的判断。
