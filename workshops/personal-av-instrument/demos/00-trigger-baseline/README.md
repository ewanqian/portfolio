# Starter 00 — Trigger Baseline

**Role:** deliberate baseline / BAD demo  
**Concept:** `Input → fixed Sound + Visual event`  
**Controls:** `Space` or click  
**Status:** source created 2026-08-23

This Starter is intentionally thin. Every input restarts the same short sound and visual event. It exists so a participant can feel why a one-shot mapping is immediately understandable but quickly exhausted.

## Teaching test

1. Enable audio.
2. Play it for 20–30 seconds.
3. Ask only: **when did it become predictable, and why?**
4. Then move to Starter 01 rather than adding more effects here.
