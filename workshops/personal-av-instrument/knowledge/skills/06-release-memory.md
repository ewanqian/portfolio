# Skill 06 — Release / Residue / Memory

**Use when:** 一松手画面和声音立刻死掉，系统只能靠不断狂按维持。

## 核心

一次输入应有完整生命周期：

```text
ENTER → DEVELOP → TRANSFORM → RELEASE → RESIDUE
```

Residue 让过去的动作继续影响现在，Memory 让同一个输入在不同历史下产生不同结果。

## Prompt Seed

```text
不要增加新的 trigger。
为现有 phrase 增加完整 release：
- Tap 后内容继续发展 1–4 秒；
- Hold 改变 sustain / accumulation；
- Release 不是直接 stop，而是进入 decay / collapse / tail；
- 上一次输入留下少量 residue，影响下一次视觉或声音；
- 2–4 秒无输入时系统仍然看起来是有意的。
```

## 验收

操作停止后系统仍保持连续；下一次输入能看见上一动作留下的痕迹，但不会无限累积。
