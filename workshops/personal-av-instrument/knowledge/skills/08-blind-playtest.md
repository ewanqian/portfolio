# Skill 08 — Blind Playtest

**Use when:** 作者觉得“已经很好用了”，但从未让第一次接触的人独立操作。

## 核心

测试时作者先不解释。

观察：

1. 对方第一眼会做什么；
2. 是否知道输入生效；
3. 是否愿意继续操作；
4. 哪一层关系完全没被发现；
5. 什么时候开始无聊；
6. 是否能主动形成自己的节奏或路径。

## Prompt Seed

```text
根据以下试玩记录，只找一个最大问题，不要提出十项新功能。
请判断问题更接近：
- Input 不可发现
- Feedback 太弱
- Mapping 太直接
- State 不可观察
- Depth 不足
- Density 失控
- Recovery 不清楚

然后提出一个最小 V2 修改，并说明为什么优先改它。
```

## 验收

V2 只解决一个关键问题；第二位测试者在更少解释下能更快开始，并更愿意继续玩。
