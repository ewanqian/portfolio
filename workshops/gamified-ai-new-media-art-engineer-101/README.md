## 这是什么

《游戏化 AI 新媒体艺术工程师 101》是一场面向初学者的新媒体创作先导工作坊。

它从两条长期项目——**《游戏化 AI 新媒体艺术工程师》**与**《音画同源乐器》**——中提取最基础的共同部分，压缩成一次三小时的完整体验。

课程不要求参与者具备编程、音乐或现场演出经验，也不会把三小时变成软件功能介绍。第一期只建立一条短而完整的路径：

**想法 → 框架 → 一个输入 → Sound + Visual Mapping → 测试 → Showcase**

目标不是学会最多的软件，而是第一次理解：**一个作品怎样从“我想做这个”变成“它现在真的能运行”。**

---

## 为什么从工程化开始

AI 已经可以快速生成网页、代码和视觉效果，但真正影响作品能不能完成的，往往不是生成速度，而是开发顺序。

课程会使用一个极简方法：

### FRAME → FILL → FINISH

- **FRAME / 框架：** 先确定作品怎样工作、有哪些输入、状态和反馈
- **FILL / 填充：** 再加入声音、图像、文字与个人材料
- **FINISH / 打磨：** 最后测试、删减、修正并准备展示

AI 可以帮助实现、修改和排错，但作品的目标、结构和判断仍然由人决定。

基础回路是：

**人决定 → AI 执行 → 人运行 → 人判断 → 再修改。**

## 14:30–15:30｜HOUR 2 / GUIDED BUILD
### 做出一个最小音画系统

参与者使用统一 Starter Kit 跟着完成一个最小系统。

先只保留一个输入：

- 鼠标
- 一个按键
- 一个按钮

然后让它产生多个结果：

```text
INPUT
  ↓
RULE / MAPPING
  ↓
SOUND + VISUAL + STATE
```

至少完成：

- 一个视觉事件
- 一个声音事件
- 一个状态变化

进度快的参与者可以继续尝试：

- Random
- Delay
- 连锁触发
- 按键速度 / 间隔
- Quiet / Active
- 简单物理或随机规则

**目标：每个人至少有一个能运行、能操作的 V1。**

---

## 15:30–16:30｜HOUR 3 / MAKE YOUR OWN
### 用自己的材料完成一个版本

参与者开始替换或增加自己的：

- 手机环境录音
- 人声 / 敲击 / 机械声
- 图片 / Logo / 纹理
- AI 图像
- Creative Coding / Generative Art

### 15:30–16:05｜自由制作 + 双导师答疑

要求不是功能越多越好，而是至少有一条自己设计的关系。

### 16:05–16:20｜交换试玩 / V2

- 作者先不解释
- 让别人直接操作
- 找到一个最大问题
- 修改
- 保存 V2 或下一版计划

### 16:20–16:30｜快速 Showcase

每人或每组用最短的方式展示：

- 一个最有意思的 Mapping
- 一个控制动作
- 一个状态变化
- 一段 30–60 秒短 Demo

大班人数较多时采用小组或精选展示。

## 第一场不会教什么

为了保证三个小时里真的做出东西，第一期不会同时要求全员掌握：

- Processing 独立工程
- Resolume / Arena
- NDI / Syphon / Spout
- MIDI Controller
- Strudel
- 完整 Tone.js 音频系统
- 复杂 Git
- 高级 Agent / API 自动化

这些内容会进入后续技能树。

参与者第一期只面对一条已经预先测试好的默认路径：

**Browser Starter Kit + AI Coding + Creative Coding / Audio + Keyboard / Mouse。**

Processing、游戏引擎、MIDI、物理系统等主要用于导师 Demo 与进阶案例。
