## 这是什么

《游戏化 AI 新媒体艺术工程师 101》是一场面向初学者的先导工作坊。

它把两项长期项目——**《游戏化 AI 新媒体艺术工程师》**与**《音画同源乐器》**——最基础、最需要先掌握的部分压缩进一次三小时体验。

课程不要求参与者具备编程、音乐或现场演出经验，也不会试图在三个小时里讲完复杂的软件与理论。第一期只建立一条最短但完整的路径：

**想法 → AI 协作 → 项目骨架 → 声音 / 图像 → Mapping → 测试 → 短演出**

这里的“101”表示基础入口。目标不是把参与者训练成程序员，而是让第一次接触这套方法的人，能够带着一个真实可运行的原型离开，并知道下一步可以怎样继续发展。

---

## 为什么从“工程化”开始

AI 已经可以很快生成网页、代码和视觉效果，但真正影响一个作品能不能完成的，往往不是生成速度，而是开发顺序。

工作坊会介绍一个非常简单的三阶段方法：

**FRAME → FILL → FINISH**

- **FRAME / 框架：** 先确定作品怎样工作、有哪些状态、观众或操作者能做什么
- **FILL / 填充：** 再加入声音、图片、文字、动画与个人材料
- **FINISH / 打磨：** 最后测试、删除多余部分、修复问题并准备公开展示

这也是 AI 最适合介入的位置：AI 可以协助执行、修改和排错，但作品的目标、结构与判断仍然由人决定。

工作坊不会把 Prompt 当成最终技能，而是把它放在一个更完整的 Human-in-the-loop 回路中：

**人决定 → AI 执行 → 人运行 → 人判断 → 再修改下一版。**

# 三小时课程

## 00:00–01:00｜01 / BUILD THE FRAME
### 先做出一件能运行的东西

第一小时建立最低必要的 AI 与工程化工作方式。

参与者会看到一个已经准备好的 Starter Kit，并通过 AI 辅助完成最基础的修改：

- 改一段文字或视觉参数
- 增加一个按键行为
- 保存第一版 V1
- 理解项目文件夹、README 与版本的意义

这一小时只讲少量必要概念：

- AI Coding / Agent 是什么
- FRAME → FILL → FINISH
- Human-in-the-loop
- V1 / V2 与最基础的版本意识

**第 60 分钟的目标：每个人已经有一个能运行、能响应操作的作品骨架。**

---

## 01:00–02:00｜02 / CONNECT SOUND + VISUAL
### 让声音和画面开始发生关系

第二小时进入新媒体与 Audio Visual 的部分。

参与者会快速理解三种最基础的 Mapping：

- **Trigger**：按一下，声音和画面同时发生
- **Continuous**：鼠标移动或持续操作，同时改变声音与视觉
- **State**：让作品从 Quiet 切换到 Active、Peak 或 Reset

现场会展示 Creative Coding / Processing、TouchWaves 和已有实时系统案例，但参与者不需要同时学习多套软件。

每个人可以使用：

- 自己录制的声音
- 手机中的照片、纹理或短视频
- AI 生成图像
- Creative Coding 生成画面

**第 120 分钟的目标：至少完成一组真正同时工作的 Sound + Visual Mapping。**

---

## 02:00–03:00｜03 / MAKE IT PLAYABLE
### 把 Demo 变成一个可以演奏的小系统

最后一小时不再增加大量功能，而是把已有内容组织成一个可以玩的结构。

参与者会完成：

- 给作品起一个名字
- 设计 3–6 个清楚的操作动作
- 至少建立 Quiet / Active 两个状态
- 与另一位参与者交换试玩
- 找到一个最明显的问题并修改
- 设计一段 30–60 秒 Micro Set

Micro Set 可以非常简单：

**进入 → 发展 → Peak → 收回 → 结束**

**第 180 分钟的目标：作品已经可以被自己或别人操作，并具备当天晚上展示的最低条件。**

---

# After Party / Micro Showcase

当天晚间设置一个轻量的 After Party / Showcase 环节。

它不是正式比赛，也不是要求每个人完成成熟作品，而是把“制作”真正推进到第一次公开使用。

参与者可以：

- 完成 30–90 秒短演出
- 两人临时 B2B
- 把作品放在开放试玩位让别人操作
- 继续修改下午完成的版本

对这门 101 课程来说，After Party 本身也是测试：

> **一个作品只有真正被操作、被观看、被别人误解或使用以后，下一版本才会开始出现。**

## 第一场不会教什么

为了保证三小时内真的做出东西，第一期不会同时要求所有人学习完整的：

- Processing 独立工程
- Resolume / Arena
- NDI / Syphon / Spout
- MIDI Controller
- Strudel
- 完整 Tone.js 音频系统
- 复杂 Git 命令
- 高级 Agent / API 自动化

这些会作为后续技能树继续开放。

第一期参与者只需要面对一条已经预先测试好的默认路径：

**Browser Starter Kit + AI Coding + Creative Coding / Audio + Keyboard / Mouse。**

MIDI、现场软件和更复杂的音画系统可以在后续正式工作坊中继续发展。
