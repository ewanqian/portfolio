01 / WHY

为什么“一个按钮”很快会无聊？

不是因为效果不够多，而是因为结果只由当下输入决定。课堂从这个失败版本开始。

Trigger toyResult = Input

A 永远是同一个声音和同一个视觉。第一次直接，30 秒以后结构耗尽。

State instrumentResult = Input + State

同一个 A 在 QUIET、BUILD、PEAK 中具有不同意义。按钮没变多，系统变深。

Performance systemResult = Input + State + History

当前段落、过去留下的痕迹、下一次 musical boundary 一起决定结果。

课堂问题：“现在系统在哪里？我这个动作准备把它带到哪里？”——比“这个按钮触发什么？”更重要。

02 / LOOP

音画同源控制模型

只讲一个公式，而且立刻翻译成人能操作的语言。

x(t+1) = F( x(t), u(t), d(t) )
x · state系统现在在哪里

SECTION / ENERGY / TENSION / DENSITY / SPACE / MEMORY / ACTIVE LAYERS / BAR

u · human人做什么结构判断

ENTER / HOLD / ADD / REMOVE / RELEASE / RECALL / ACCENT

d · disturbance现场永远不完美

早按、晚按、延迟、素材差异、设备状态、参与者差异。

Closed Loop / 反馈回路

人做判断 ↓ 系统改变状态 ↓ 音乐 / 视觉 / 灯光产生结果 ↓ 人听见、看见、感受到 ↓ 重新判断 ───────────────┐ └── 回到下一次输入

工作坊不追求“完全自由”。采用 Hybrid Control：系统负责容易出错的底层安全，人负责高价值的结构判断。

03 / SOURCE

“同源”不一定是同一个 Signal

更成熟的同源可以是 Shared State / Shared Intention：声音和视觉不需要每拍做同一件事，但它们在解释同一个结构状态。

STATE / INTENTION ↓ CONTROL MODEL ↓ ┌─────────────┼─────────────┐ ↓ ↓ ↓ MUSIC VISUAL LIGHT ↓ ↓ ↓ Arrangement Image Logic Space Logic
Music更快的时间尺度

rhythm / anticipation / withholding / build / drop / release

Visual更慢的持续结构

persistence / accumulation / transformation / memory / return

Light / Space现实空间的开合

reveal / hide / isolate / narrow / expand / blackout / open

例：PEAK 不必等于“三边一起更满”。Music 可以增加身体能量；Visual 可以删掉 70% 细节只留下主结构；Light 可以突然打开整个房间。

04 / SCORE

演出需要剧本，但不是写死时间线

参与者不需要懂复杂音乐理论。先用五个 Macro 状态写出一条最简单的演出曲线。

01GROUND低密度 / 大空间 / 让系统先成立
02BUILD增加 subdivision / accumulation / direction
03PEAK高能但有限制 / 主体明确 / 不是全部堆满
04BRIDGE抽离 / 延迟 / 重组 / 为下一次决定留空间
05RETURN回到空 / 召回旧材料 / 结束或重新开始
Macro整场 / Section

能量曲线、段落、高潮、转场、结束。

MesoPhrase / 4–16 bars

积累、等待、hold、break、return。

MicroEvent / Cell

一次 hit、一个视觉事件、一次短 phrase。

失败版本通常只有 Micro：每一个 beat 都有反应，却没有更长的结构。

05 / BUILD

Starter Ladder：用对比代替长理论

8.29 的 Starter 不是“一次把所有功能做完”，而是四个递进的小系统。任何未实际测试的版本都保持 NOT TESTED。

00Trigger Baseline故意做一个薄的一对一 Mapping：KEY → Sound Hit + Visual Hit。让大家亲自发现它为什么很快耗尽。
01State Instrument同一个 Input 在 QUIET / ACTIVE 中有不同结果。先不增加更多按钮。
02Safe Loop加入 BPM / transport / quantization / density protection。用户停手 2–4 秒系统仍然成立。
03Shared State A/VSound 与 Visual 读取同一个 State，但不做廉价 1:1 reactive mapping。可由 Golden Demo 展示，不要求全员从零实现。
GOLDMini Live System60–90 秒认真完成。AUTO 自己成立；PERFORM 只接管 HOLD / ADD / REMOVE / RELEASE 等结构判断。

范围控制：“叮咚鸡 / 大狗叫”继续承担 Personal Material、趣味性和即时可玩；不要强行让它承担完整长时 Live Set。

06 / RUN

8.29 · 三小时现场流程

当前仓库 source of truth：3 小时核心课程，建议 13:30–16:30。早期 13:30–17:30 记录属于旧窗口，不能再当课程正文。

13:30–13:40
PLAY BAD / PLAY BETTER

不先定义术语。先玩 Trigger Baseline，再玩 State / Live System；问“差别在哪里？”

13:40–14:00
Ewan｜控制模型 + 工程化

FRAME → FILL → FINISH；Result = Input + State + History；Closed Loop；Shared State；只用一张控制图。

14:00–14:25
yiyisogreen｜Mapping、限制与表演界面

一个按键 / 一个鼠标如何形成持续行为；操作 → 结果的因果可见性；限制为什么会形成表演语言。

14:25–14:30
Today’s Map

告诉参与者：今天不会“学完新媒体”，只做 00 → 01 → 02 → Personal Material → Test → Showcase。

14:30–15:00
GUIDED BUILD｜Starter 00 → 01

先做能跑的 Trigger，再增加 State。保存 V1，不装修。

15:00–15:30
GUIDED BUILD｜Starter 02

加入 Safe Loop / BPM / ADD-REMOVE / Reset；系统开始能够在用户停手时继续成立。

15:30–16:00
MAKE YOUR OWN

换入自己的声音 / 图片 / 文字 / AI 图像。只要求一条自己决定的关系。

16:00–16:18
BLIND TEST

作者不解释。别人直接玩 30–60 秒。只找一个最大问题，然后修。

16:18–16:30
MICRO PERFORMANCE / SHOWCASE

每人或小组 30–60 秒：一个控制动作、一个 State 变化、一个自己材料形成的结果。

完成标准：至少一个可运行 V1 + 明确 Input + Sound/Visual 关系 + State + 一次他人试玩 + V2 或下一版计划。不要承诺所有人完成专业 Live Set。

07 / TEACH

讲课时真正做的 8 个动作

理论不要独立占 40 分钟。每个概念都用“对比 → 运行 → 判断 → 修改”进入。

1先玩坏版本

让参与者自己感到“按一下、闪一下”的薄。

2再玩更好版本

同一个输入，在不同 State / History 下发生变化。

3只问一个问题

“刚才差别在哪里？”不要先给术语。

4画一张控制图

Input → State / Mapping → Sound + Visual → Feedback。

5让 AI 做候选

快速生成 2–3 个行为，不把第一个能跑的当答案。

6人做删减

Generate fast / Judge slowly。删掉最弱的变化。

7交换试玩

作者沉默；检查可观察性和因果是否清楚。

8演，不要介绍功能

最后展示“怎样演奏它”，不是“网页有多少功能”。

08 / MARKET internal

市场定位：不要再卖“技能信息差”

8 月 22 日后的研发记录已经把工作坊产品逻辑改得更清楚：公众价值应该优先是体验、完成感、个人材料和可分享结果。

不要主卖“来学一个软件 / AI 技能”

AI 已经压低信息门槛，参与者技能树差异也很大。工具名越多，越像一门短期过期的技能课。

优先主卖“三小时做出一个能玩的东西”

像陶艺 / 披萨 / 手作体验：完成一个有名字、有个人材料、能让别人玩、能录下来分享的 A/V Instrument。

传播钩子

一个按钮怎么玩一整场？

先证明一个简单输入能形成时间结构。

把自己的声音做成乐器

朋友语音、环境录音、已有歌曲、照片都能进入 Pack。

不用会钢琴也能控制演出

机器负责节拍、调性、密度安全；人负责进入、等待、增加、删减、释放。

市场上的关键证据不是文案：先让 20–30 秒 raw Screen + Sound 本身像一段 AV Performance，再做宣传剪辑。Promotion 是 Acceptance Test，不是包装。
