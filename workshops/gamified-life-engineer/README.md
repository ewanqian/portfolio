# 游戏化 AI 新媒体艺术工程师
## Gamified AI New Media Art Engineer

**项目类型：** 公众工作坊 / AI 协作 / 新媒体艺术入门 / 工程化创作  
**发起人：** 钱誉文 Ewan Qian  
**当前状态：** 2026 长期研发与场地方合作版本

> 从一个想法出发，先搭骨架、再填内容、最后测试；借助 AI，把个人经验逐步制造成可以运行、修改、发布，甚至进入现场演出的新媒体作品。

## 为什么改成这个名字

2025 年杭州中心美术馆《游戏化 AI 生活解构师》解决的是“第一次用 AI Agent 做出自己的模拟器”。

2026 年继续只教“AI 做网页”已经不够。真正需要补上的，是一套最基础但可长期复用的创作工程思维：

**想法 → 框架 → 最小版本 → 填充 → 测试 → 修正 → 发布 / 演出**

因此这一代工作坊把四件事合在一起：

- **游戏化**：把问题转成角色、规则、状态、反馈与循环
- **AI**：把 AI 当作执行、整理、调试与快速原型的协作者
- **新媒体艺术**：让声音、图像、网页、实时视觉、交互都成为可组合材料
- **工程师**：先保证系统能工作，再逐步增加复杂度，并通过测试持续修正

这里的“工程师”不是职业资格，而是一种工作方式：**不要从第一分钟就把细节做满，而是先制造一辆能跑的车。**

## 核心方法

工作坊使用一个最小开发循环：

```text
FRAME / 大框架
    ↓
SKELETON / 最小可运行版本
    ↓
FILL / 填充声音、图像与规则
    ↓
TEST / 真实测试
    ↓
REFINE / 修正
    ↓
PUBLISH / PERFORM
```

这套方法既可以用来做个人网页工具，也可以用来做生成视觉、音画系统、互动装置原型或 Live Set。

## AI 在哪里

AI 不负责替参与者决定作品是什么。

它主要帮助：

- 把模糊想法整理成任务
- 生成第一版代码
- 修改参数与结构
- 排查错误
- 处理重复工作
- 补充 README、版本记录与部署说明

参与者仍然负责：

- 选题
- 规则
- 审美判断
- 什么值得删掉
- 什么状态值得保留
- 测试是否真的成立
- 最后的表演与发布

这也是工作坊中 **Human-in-the-loop** 最简单的实际含义。

## 为什么它是《音画同源乐器》的前置层

《音画同源乐器》需要参与者开始处理 Mapping、实时状态、声音、视觉和演奏。

如果完全没有“项目怎么搭起来、怎么改、怎么保存、怎么测试”的基础，三小时会大量消耗在环境和错误上。

因此《游戏化 AI 新媒体艺术工程师》承担基础铺垫：

1. 建立 AI + Coding 的最低可用环境
2. 理解文件、项目、版本与发布
3. 学会“先骨架、后细节”的开发顺序
4. 做一个最简单的生成视觉 / 交互练习
5. 为后续声音、Mapping 和 Live Set 留出接口

长期版本可以独立成为完整工作坊；在 MANA 2026-08-29 的先导版中，它会被压缩成约 1 小时的“最低必要技能包”。

## 长期公众版结构

### 01｜FRAME
从一个个人问题或创作冲动开始，不先做 UI。

先回答：
- 我到底想让什么发生？
- 输入是什么？
- 哪个状态最重要？
- 人做什么？AI 做什么？
- 第一版怎样才算“已经能跑”？

### 02｜BUILD A SKELETON
第一版只保证一个最小闭环。

例如：
- 一个按键 → 一个视觉变化
- 一个输入 → 一个系统反馈
- 一个声音 → 一个图形响应

### 03｜FILL
骨架稳定后，再加入：
- 个人图片 / 视频
- 声音
- 字体 / 图形
- 状态
- 随机性
- 游戏化规则
- 更多控制参数

### 04｜TEST
让别人直接使用或演奏。

测试的不是“代码有没有报错”，还包括：
- 别人知道该怎么操作吗？
- 哪个动作最清楚？
- 哪个部分其实没必要？
- 系统失控时能恢复吗？

### 05｜VERSION
保留 V1、测试结果、修改决定和 V2。

Git / GitHub 在这里不是程序员仪式，而是让作品能长期继续开发的最基础版本记录。

## 参与者最终带走

长期完整版本至少形成：

- 一个可运行的新媒体原型
- 一个项目目录 / Repository
- 一个最基本的 README
- V1 → Test → V2 记录
- 可继续增加声音 / 图像 / Mapping 的结构
- 一个可以本地运行或在线发布的版本

## 技术原则

课程不绑定某一家 AI 厂商。正式场次会根据当期稳定性准备一个最低门槛默认路径，并保留进阶路线。

参与者只需要理解一条技能树：

```text
最基础：浏览器 / Starter Kit / AI 对话
        ↓
可修改：VS Code / Processing / Web Creative Coding
        ↓
可维护：Git / GitHub / README / Version
        ↓
可扩展：Coding Agent / API / 自动化
        ↓
可演出：Audio / Visual / Mapping / MIDI / Live Set
```
