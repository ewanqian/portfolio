# 游戏化生活工程师
## Gamified Life Engineer

**项目类型：** 公众工作坊 / AI 协作 / 个人工具设计  
**发起人：** 钱誉文 Ewan Qian  
**当前状态：** 2026 合作提案与长期研发中

> 从一个真实而细小的生活问题出发，把它重新设计成一套规则，再借助 AI 制作成一个只有你自己会这样设计的个人数字工具。

## 这是什么

今天，用 AI 生成一个网页已经不再困难。更重要的问题变成了：**当 AI 很会执行以后，人怎样设计一个值得执行、能够被测试并持续修改的系统？**

《游戏化生活工程师》面向没有编程基础的公众。参与者不会从复杂代码开始，而是先观察自己生活中反复发生的一件小事，把它拆成“输入、规则、状态、反馈与循环”，再借助 AI Agent 和预制 Starter Kit，把它制作成一个真正可以运行的个人网页工具。

这里的“游戏化”不是简单增加积分、签到和排行榜，而是借用游戏设计的思维重新理解日常问题：谁在参与？系统知道什么？什么条件会触发事件？什么叫成功或失败？为什么明天还值得再次打开？

最终，AI 负责辅助整理、实现和调试；参与者仍然负责提出问题、制定规则、判断结果和决定下一版本。工作坊会把 **Human-in-the-loop** 作为一个非常直观的实践原则：AI 不是替代人的自动按钮，而是进入一个由人持续判断和修正的工作回路。

## 参与者会做什么

工作坊以“先结构、后细节”为基本方法：

**观察生活问题 → 建立系统规则 → 制作最小 V1 → 加入个人材料 → 交换测试 → 根据反馈制作 V2**

可能出现的项目包括：

- 出门副本检查器
- 拖延 Boss 生成器
- 情绪天气台
- 随机散步导航
- 个人学习任务系统
- 物品告别仪式
- 家庭噪声裁判
- 猫咪犯罪档案

重点不是做出“最有效率”的 App，而是做出一件足够私人、准确，并且愿意继续使用的工具。

## 3 小时公众版

**00:00–00:20｜生活 Bug 与选题**  
从真实而细小的问题出发，缩小选题并确定核心目标。

**00:20–00:50｜把问题变成系统**  
用 System Card 建立输入、规则、状态、反馈与 Human / AI 分工。

**00:50–01:40｜制作 V1**  
使用统一 Starter Kit 与 AI Agent，先完成一个输入、一条核心规则和一个反馈。

**01:40–02:10｜个人化**  
加入自己的文字、图片、声音、角色与游戏化机制。

**02:10–02:35｜Silent Test**  
两人交换工具，作者不能解释，直接观察别人怎样理解和使用。

**02:35–03:00｜V2 与发布**  
根据测试结果修改，并用一分钟说明：它为谁服务、最重要的规则是什么、下一版本准备改什么。

## 参与者最终带走

每位参与者至少完成：

- 一个真正能够运行的个人网页工具
- 一张 System Card
- 一张 Human / AI Responsibility Map
- V1 与一次真实测试记录
- V2 或明确的下一版本计划
- Git Repository、项目包或可分享链接

工作坊不把“第一次生成成功”视为终点，而要求作品至少经历一次 **制作 → 使用 → 判断 → 修改** 的循环。

## 形式与条件

- **公众版：** 3 小时，建议 12–20 人
- **进阶版：** 6 小时，可加入 Git / GitHub、Context、版本管理、部署与更完整的 Agent 工作流
- **两阶段版：** 第一次制作后真实使用 7–14 天，再进行第二次复盘与 V2
- **参与门槛：** 不要求编程基础，自带笔记本电脑与手机
- **场地建议：** 投影、稳定 Wi-Fi、电源、适合电脑操作的桌椅

正式活动前，参与者会收到 Preflight Guide，提前完成账号、浏览器、Starter Kit 与基础环境测试，避免把正式课程消耗在软件安装上。

## 项目来源

本项目延续自 2025 年 7 月 12 日杭州中心美术馆「巴别瓶」公共活动中的 **《游戏化 AI 生活解构师 / Gamified AI Life Deconstructors》**。当时的工作坊已经尝试让零基础参与者借助 AI Agent，把个人生活经验转化成自己的模拟器。

2026 版本进一步从“第一次使用 AI 制造工具”推进到“怎样设计、控制、测试并长期维护一个 AI-assisted system”。因此，这不是旧课程改名，而是一次从 **AI Literacy** 向 **System Literacy** 的升级。

历史记录：[`202507-杭州中心-AI-Agent工作坊.md`](../202507-杭州中心-AI-Agent工作坊.md)

## 长期方向

本项目计划持续维护 Starter Kit、Participant Handbook、研究资料和不同场次的版本记录，并逐渐形成一个 **Personal Tool Archive**，记录参与者制造出来的各种私人数字工具。
