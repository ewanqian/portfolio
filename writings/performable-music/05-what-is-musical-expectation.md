# 音乐中的“期待”究竟是什么？
## 从可预测性、惊讶到一次可以被 Agent 执行的 32 小节实验

**钱誉文 / Ewan Qian · Performable Music / 作曲机制研究 · 2026 年 11 月**

在电子音乐中，“营造期待”经常被简化成一个公式：逐渐增加鼓组、滤波器打开、白噪声上升，然后在重拍加一个响亮的 Kick。这个办法偶尔有效，但重复使用，很快会暴露为可预见的声音模板。真正值得研究的是：听众的耳朵究竟**在等待什么事件**？

如果作品前十六小节一直在重复同一个低频音型，听众可能开始预期它的下一次出现；如果它在最后一拍突然停下，空白也可以成为一种强烈的音乐事件。相反，在一段没有建立任何规律的随机声音中，即便每秒都有意外，也可能没有可供违反的明确期待。

本文将“期待”作为一种**与学习、上下文、时间和风格经验相关的听觉预测**，而不是把它等同于音量曲线或固定的高潮时间码。

## 01｜期待的对象：不是“接下来会大声”，而是一个可以被预测的关系

音乐可以同时在不同时间尺度上建立期待：

| 尺度 | 听众可能预测的东西 | 制作中能操作的对象 |
| --- | --- | --- |
| 10–300 毫秒 | 下一次瞬态、起音、回声或音色改变 | attack、微小位移、Delay / transient |
| 一拍到一小节 | Kick、Bass、金属打击何时回答 | 节奏重音、空拍、切分、节拍网格 |
| 2–8 小节 | 乐句会不会重复、上行后怎样回答 | motif、register、旋律轮廓、变奏 |
| 8–32 小节 | 被承诺的主声部、低频或和声是否返回 | arrangement、dropout、cadence、段落 |
| 全曲 | 开头留下的问题是否真正解决 | reprise、form、new context、final release |

这些尺度只是**工作上有用的划分**，不是脑科学规定的固定阈值。听众会因音乐经验、风格、听音环境和注意力而不同。

例如，“听到第四次就知道第五次会来”并不等于在任何情况下第五次都应该缺席。**重复负责建立模型，变化负责让这个模型拥有意义。**

## 02｜惊讶可以计算，但“好听”不能直接计算

音乐认知研究把下一次音乐事件的条件概率记作：

`P(event | context)`

一个常用的惊讶度或信息量定义是：

`I(event) = -log₂ P(event | context)`

如果模型认为某次低频回归的概率是 0.8，信息量约为 0.32 bit；如果概率只有 0.1，信息量约为 3.32 bit。这里的数字只是**说明公式的假设示例**，不是对任何一首真实音乐的测量。

不确定性则可由模型对各种可能事件的分布估算：

`H(context) = -Σ p(event|context) log₂ p(event|context)`

两者区别在于：
- **Surprise / 信息量**：已经发生的这个事件，在模型看来有多意外？
- **Uncertainty / 不确定性**：在事件发生之前，模型对接下来会发生什么有多不确定？

高惊讶度不等于高级、好听、震撼或应当被保留。一串完全随机的高频点击也可能具有高信息量，却没有可感知的段落功能。

Marcus Pearce 的 **IDyOM**（Information Dynamics of Music）系统正是沿着统计学习和可变阶 Markov 模型估算符号音乐中的音符预测与信息量。相关实验也提醒我们：音乐愉悦与不确定性、预测是否成功之间有条件关系，不能简化成“意外越多越愉快”。

参考：[IDyOM 官方项目](https://www.marcus-pearce.com/idyom/)；[2019 年《The Journal of Neuroscience》研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6867811/)。

## 03｜用于作曲的五类“期待操作”

### A. 建立一个可识别的惯例 / Establish

用两小节内可以被辨认的事件关系作为基础。例如每个四拍循环中：低频在第 1 拍进入，高频金属声在第 3 拍后半回答，末尾留空四分之一拍。连续出现两三次，让这个关系建立身份。

如果音色和时间每次都完全不一样，听众就很难学到这个惯例。

### B. 延迟兑现 / Delay

当听众已经习惯一个事件会在第 1 拍出现时，把它延迟到第 1 拍后半，或者先让一个较弱的声音占据原来的位置。**被延迟的必须是已经可以期待的事件**。没有建立惯例时，延迟不一定能被识别为延迟。

### C. 撤除承诺 / Omit

让某个原本每四小节都出现的低频在下一次完全缺席，但保留其它声部或节奏提示。这种方法可以比“加入更重的鼓”产生更高张力，因为缺失本身具有结构意义。

### D. 改变归来时的身份 / Transform

一段先前很干燥、短促的打击动机可以在四十秒后重新出现，但这一次通过共振变成一条带有音高的长音。听者仍能感到材料来自同一个物体，然而其音乐功能已经改变。

### E. 兑现并重新解释 / Fulfil and Reframe

结尾让开头的动机回来，并不总意味着原样重复。可以改变和声、重音、寄存器和空间，使第一次听起来像“提问”的声音最后成为“回答”。此时音乐期待的处理同时包含重复与新的上下文。

## 04｜32 小节可执行作曲实验：同一个动机，A/B 两种不同期待

**目标：** 128 BPM / 4/4 / 32 小节，恰好 60 秒。初始声音材料限定为四个角色：弹性 FM 低频、金属共振、短促空间脉冲、远处的背景纹理。

**建立惯例：** 2 小节作为主要动机，保留一个可识别的“低频提出问题 → 金属打击回答”的时间关系。声音的精细 MIDI 编排交由音乐制作端完成，工程不得简单复制同一两小节 16 次。

| 小节 | A：延期回归 | B：改写规律 | 希望听见的结果 |
| --- | --- | --- | --- |
| 1–8 | 低频与金属固定对答，8 小节有一次明确答句 | 同样建立原始对答，结尾留下一个未完成的金属尾音 | 听众第一次理解规则 |
| 9–16 | 让期待的 Kick 提前的打击变弱，保留低频位置 | 维持 Kick，但使回答金属声的时值翻倍 | 同一规律开始出现歧义 |
| 17–24 | 在预期的低频回归点撤掉低频，只留下节奏暗示 | 在预期的回答位置替换为共振音色，重新解释相同节奏 | A 让听众等待；B 让听众重新理解 |
| 25–32 | 在第 25 小节给出原低频的强回归，随后收束 | 让金属共振承担主旋律，低频在末尾短暂返回 | 两首使用同一材料，形成不同故事 |

上表的“希望听见”是创作假设，必须通过真正的试听而不是模型评分确认。

### 工程中的最低限制

- 每版都至少有**一次能够清楚指出原因的撤除和一次回归**。
- 三次回归不能全靠大音量；至少一次要靠音高、节奏位置或声音身份变化。
- 不得仅修改音符数量和混响深度来制造 A/B 差异。
- 先用干声比较，确认结构成立，再加入短反射、长尾和空间位移。
- 完整保留 `motif_id`、`expected_event_id`、`actual_event_id` 与发生小节，便于回放。

## 05｜Agent 语法应该明确“承诺和后果”

一句“Build tension in a sophisticated IDM style”无法告诉编曲器该保持什么和改变什么。更有效的是一个可以执行的语义操作：

```yaml
musical_hypothesis: "观众已经学会低频每四小节回到第一拍"
establish:
  motif_id: rubber-metal-01
  repetitions: 3
expectation:
  target_event: bass-return
  expected_at_bar: 17
operation:
  type: OMIT
  bars: [17, 24]
  preserve: [metal-reply, pulse-grid]
payoff:
  type: RETURN_TRANSFORMED
  bar: 25
  change: [register, attack, harmonic_color]
invariants: [tempo, motif_identity, peak_ceiling]
```

它描述的是音乐中的**结构关系**，不是某个合成器的直接参数。生成 MIDI 的 Agent 可以把该操作翻译为音符、音量与节奏安排，音色 Agent 可以解释“RETURN_TRANSFORMED”，DAW Agent 才执行轨道与效果器修改。每一层都能检查自己是否遵守意图。

真正的演出里，`bar: 25` 也可以被一个安全、量化的 FOOT 事件替代；此时系统必须保存原来的承诺并能让演奏者决定何时兑现。

## 06｜如何验证一段音乐真的建立了期待？

**测试一：预测点测试。** 给三位或更多不需要听技术说明的听众播放第 1–16 小节，在第 17 小节前停住，询问他们预期哪个声部出现，或请他们轻敲预测的拍点。人数只是低成本的试点，不代表统计显著性。

**测试二：A/B 盲听。** 让参与者听 A、B 两版 60 秒，以相近响度播放；除了“喜欢哪版”，也问“哪一个消失或回归改变了你的感受？”没有答案不意味着失败，但意味着预设的因果机制未被充分听见。

**测试三：删减对照。** 去掉第 17 小节的撤除，将其它条件保持相近，观察第 25 小节回归是否仍显得重要。这个实验特别适合发现“仅靠音量堆积”的假高潮。

**测试四：真实音源验证。** 最后用实际 DAW 音色、延迟和混响重做 A/B。低音、金属和短反射之间的相位、声音距离与瞬态可能改变听者的预测；纯 MIDI 通过并不意味着实际音频通过。

计算模型可以辅助定位重复与异常；最终音乐选择仍应由耳朵与上下文决定。不要把单一信息量分数当作歌曲质量分数。

## 07｜从期待到现场控制

对 Performable Music，最有用的参数不是“高潮音量”，而是：

- **Commitment / 承诺**：系统明确记住了哪个被建立的音乐事件。
- **Delay / 延期**：事件最多允许被延迟多长时间，超过边界如何返回安全状态。
- **Mutation / 变形**：兑现时哪些音色或节奏维度可以改变。
- **Release / 释放**：人决定何时结束等待并进入新的段落。

如果一个脚踏让声场突然坍缩，而后一段低频的重新进入同时使空间几何体重构，那么现场动作就不只是给音乐添加特效，而是**改变听众等待的结果**。这一因果关系应当由同一份 Show Score 事件驱动音乐与视觉。
