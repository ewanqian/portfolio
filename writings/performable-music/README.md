# Performable Music — Writing / 研究专题

**Ewan Qian · 修订日期 2026-11-05**

本专题包含 **八篇可独立阅读**的文章：电子音乐史与艺术家谱系、作曲研究、音乐认知、Agent 可执行语法、2026 年真实工具评估。研究的共同问题是：**哪些音乐关系值得被保留，怎样使它们能够被人演奏、修改与再次验证？**

1. [从声音物件到可编程音乐](01-from-tape-to-programmable-music.md) — 历史上的声音表示与控制方式；这六种变化不是线性进化树。

3. [八件乐器，十六首作品](03-eight-instruments-sixteen-works.md) — F01–F08 原创专辑的设计规格，区分 SPECIFIED / RENDERED / AUDITIONED。
4. [一间由 Agent 协助的电子音乐工作室](04-human-agent-studio-reader.md) — 创作、真实制作、回滚、混音与现场验收的练习流程。
