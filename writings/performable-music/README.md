# Performable Music — Writing / 研究专题

**Ewan Qian · 2026-11-05**

这个专题讨论：当声音、事件、程序和现场控制逐渐结合，什么样的音乐真正值得被演奏？它从电子音乐史的技术转向出发，进入艺术家方法比较、十六首原创作品的设计，再回到使用 Agent 的工作室 SOP。

四篇文章都可以独立阅读，也建议按以下顺序：

1. [从声音物件到可编程音乐：电子音乐的六次控制权转移](01-from-tape-to-programmable-music.md) — 声音、合成、MIDI、实时编程与 Agent 的关系；区分 Programmable Music 和 Performable Music。
2. [七条声音谱系：从微声到空间表演](02-seven-audiovisual-lineages.md) — Ikeda、Kurokawa、Byetone、Alva Noto、Amon Tobin、KASHIWA、Daito，各自的时期、问题和可借鉴机制。
3. [八件乐器，十六首作品](03-eight-instruments-sixteen-works.md) — F01–F08 的创作架构、两种独立曲式、音色机制和现场控制。
4. [一间由 Agent 协助的电子音乐工作室](04-human-agent-studio-reader.md) — 从聆听、删减、音色、Delay/混响、DAW 制作到可回放表演的学习流程。

## 阅读与工程的边界

- 本目录是独立可读的**公开研究与写作**。事实尽量标明原始文献；方法归纳是作者的工作假设。
- 实验源码、MIDI、Max/Pd/SuperCollider、DAW 文件与可重建测试归 [performable-music 仓库](https://github.com/ewanqian/performable-music)。
- 16 首是项目的研究与作曲规划，不等于 16 首音频已经完成或得到审美验收。
- 书籍、唱片、音乐人与合作关系被作为研究素材时，不意味着该项目获得对其录音、代码或视觉资产的复制许可。
