# 声音的组织：从聆听到实时演奏

一本关于音乐如何形成、又如何在现场继续发生的数字读物。以艺术家的经历、声音材料、编排与时间组织为线索，连接创作、制作与实时演出。

[阅读完整数字版](https://ewanqian.site/sound-organization/) · [历史知识地图](https://ewanqian.site/sound-organization/knowledge.html) · [声音工作台](https://ewanqian.site/sound-organization/labs.html)

六组24章：进入声音的世界、在作品中听见选择、用 Live 塑造材料、把材料写成音乐、让音乐发生在现场、形成持续的创作实践。这里的 Live 是具体教学工作台，而不是全部创作方法的边界。

作者：Ewan Qian。数字读本 1.0，2026年11月。章节内提供来源与作品入口。声音工作台的示例来自原创合成练习，不是所研究艺术家的原始工程。
