EXERCISE 01 · MINIMAL INPUT

一个按钮，
三种状态。

第一个练习只做一件事：让同一个输入在 Press、Hold、Release 三个时间阶段产生清楚而不同的声音与视觉行为。

PRESS → 约 0.12 秒的短促声音 + 明确视觉反馈 HOLD > 350ms → 进入与 BPM 同步的持续状态 → 每 1–2 小节只发生少量受约束变化 RELEASE → 停止新事件 → 声音尾巴 + 视觉 residue 在 1–3 秒内衰减

先记住这一点

整个练习只需要一个主按钮或 Space 键。声音和视觉共享同一个 BPM、beat、step、energy、holdDuration、releaseAmount。先把这条关系做清楚，再进入后面的 Sequencer、Graph、State 和更多输入。

四个可直接复制的方向

任选一个。第一次生成不要同时混合多个风格。

如果生成得太复杂

请缩减当前版本： - 只保留一个主按钮 / Space； - 只保留 Press / Hold / Release 三个状态； - 只使用一个共享 BPM / clock； - 最多 3 个同时发声 voice； - 删除说明文字、复杂控制面板和多余特效； - 保留 Reset； - 让我在 10 秒内看懂怎么操作。

如果声音不好听

不要增加更多声音。先统一 key / scale，减少高频，降低同时发声数量，重新做 gain staging；给 master 加 compressor + limiter。Press 要短，Hold 要稳定，Release 要有尾巴，而且三个状态听起来必须明显不同。

完成标准

Press / Hold / Release 三个状态都能被听见和看见。
Hold 可以持续至少 20 秒，不会马上听腻。
持续事件都共享同一个 BPM / clock。
Release 后仍有 1–3 秒的尾音或残影。
整个系统只有一个主要输入。
陌生人 10 秒内知道怎么操作。

建议工作方式：先复制一个 Prompt → 生成最小版本 → 运行 → 只改一个问题 → 再运行。不要在第一轮同时加入更多按钮、复杂 UI 和额外功能。
