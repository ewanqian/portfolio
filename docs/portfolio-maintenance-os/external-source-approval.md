# External Source Approval Workflow

Use this before adding web-found material into public portfolio pages.

## Intake

For each external source, record:

- project or topic
- source title
- source URL
- publisher
- date if available
- material type: fact, image, video, quote, method reference, event record
- proposed use

## Review

Check:

- relevance to Ewan Qian's project record
- source reliability
- whether the source is official, institutional, media, platform, or user upload
- copyright and reuse status
- credit and role risk
- whether the material needs user approval before public use

## Approval Status

Use one of:

- approved for facts
- approved for link only
- approved for image
- approved for paraphrased method reference
- permission needed
- reject

## Public Use Rule

Do not add external images, scraped text, or uncertain claims directly to public pages. First keep the finding in local review notes, then move only approved facts, links, or media into tracked public files.
