# Media Selection Template

## Selection Priority

1. Owned final frames
2. Approved production stills
3. Publicly shareable live screenshots
4. Cropped screen or surface details
5. Designed title cards
6. External images only when source and context are clear

## Avoid

- raw file browser screenshots
- low-resolution posters as hero images
- text-heavy thumbnails
- images that imply broader authorship than the actual role
- unapproved artist portraits as main proof of visual work
- rejected contact sheets on public pages

## Standard Sizes

| Use | Ratio | Notes |
| --- | --- | --- |
| Home cover | 16:9 or cinematic crop | Strong image, minimal text. |
| Project hero | Native project ratio preferred | Stage screens may use ultra-wide. |
| PGM frame | Wide / panoramic | Use `object-fit: contain` when aspect is extreme. |
| Floor LED | Square or top-down crop | Show surface logic clearly. |
| Archive row | 16:9 | Avoid black center-only images. |

## Media Status Labels

Use internally when reviewing:

- final
- usable
- needs replacement
- permission needed
- keep local

Do not show these labels on public pages.
