1. 在 GitHub Actions 新增 `scripts/audit-portfolio-browser.mjs` 与 `.github/workflows/portfolio-visual-qa.yml`，使用 Chromium 对 **1440×900 桌面和 390×844 手机**各执行六条路由（首页、Atlas、Cabinet、Timeline、CV、TIMER 项目永久页）测试，保存 12 张完整页面截图与 JSON 诊断报告。

3. TIMER 项目永久页的旧图片引用在 Chromium 桌面曾加载失败。改用其既有正式作品页 `/assets/home/archive-timer-clean.webp`，同步修改 `content/project-registry-2026-11.json` 和 `database/media-publication-register-2026-11.json`（登记尺寸 276830 bytes、Git blob SHA `e336564c8e52b19df4e26da15c911c95ff703aae`）；图片版权/摄影署名审核仍保留原状态，不因换封面自动获得许可。
4. 为避免原生 `loading=lazy` 图像的检测误差，先尝试 `img.decode()` 再检查加载结果。永久页允许带校验查询参数访问以减少旧 HTML 的 CDN 缓存干扰。
5. 本轮曾因错误 JSX 以及媒体登记表与新封面不一致导致 Actions 失败，均已根据实际日志定位并修复；不要以旧失败状态代表最终结果。
