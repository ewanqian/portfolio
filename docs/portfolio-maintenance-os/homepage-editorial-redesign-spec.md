# Homepage Editorial Redesign Spec

Status: active implementation
Date: 2026-11-02
Owner: Portfolio Editor / Quality Gatekeeper

## Goal

Make the homepage feel like Ewan Qian's edited artist portfolio rather than a generic portfolio/product website.

## Non-negotiables

- Work before taxonomy.
- Project facts before positioning language.
- Image before interface.
- Small type is allowed; low contrast is not.
- No repeated explanation of what belongs in Archive/Research.
- No full-screen hero unless it proves a work, not a brand treatment.
- No card UI whose primary purpose is to make the site feel designed.
- Homepage stays limited to four selected works.

## Homepage information architecture

1. Identity strip
2. Four selected works
3. Compact about / contact strip
4. Footer

Practice lines, workshop taxonomy, research frameworks and production systems remain reachable through navigation but are removed from the homepage.

## Quality review rubric

Score each revision 0–2 on:

- authorship: does this feel specific to Ewan?
- edit: is every visible sentence necessary?
- evidence: do images and facts carry the claim?
- hierarchy: can a visitor scan titles / role / context immediately?
- restraint: is UI chrome quieter than the work?
- typography: is small text crisp, high-contrast and readable?

Ship threshold: 10/12 minimum, with no zero in authorship, evidence or edit.
