## Finding 1 — ENTROPY is the fastest portfolio upgrade

The existing production issue already contains a substantial architecture, screen context, state/phrase language and live-system design. The problem is that it is still structured mainly as a **pre-show production plan**, including many unchecked tasks.

The event itself is already complete and the basic event/role facts are stable.

Therefore the next work is editorial and evidentiary, not feature development.

### Required conversion

Create one post-show package with:

- event title / date / venue;
- final credits;
- Ewan role;
- 3–8 selected live documentation items;
- one system diagram showing the actual live chain;
- one short “what shipped” section;
- one short “what changed after rehearsal / onsite” section;
- 150–250 word Chinese summary;
- 100–180 word English summary.

### PM rejection

Do not use the unfinished production checklist as the public case study structure.

Do not add new FIELD INDEX features to make the old checklist look complete.

## Finding 2 — Stage Casting has the only hard near-term deadline

Target date remains 2026-12-04.

The project should now be judged by one question:

> Can one spatial input reliably drive a coherent performance chain on real hardware?

### Acceptance test

```text
Vision Pro / WebXR input
→ semantic state / gesture
→ transport / bridge
→ OSC / control
→ Ableton / Max-Jitter / visual system
→ visible + audible performance response
```

Pass requires:

- real hardware;
- observed connection / latency behaviour;
- one fallback if network or device input fails;
- one rehearsal recording / log sufficient to reproduce the path.

### PM rejection

- no quota-driven demo expansion;
- no new control vocabulary until the existing path survives real use;
- no completed CV claim before 2026-12-04 actually occurs.
