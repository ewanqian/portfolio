**钱誉文 / Ewan Qian · Live Visual Field Notes · 2026**

**以 REACTOR Opening Day 的现场实践为例**

## 前言｜已经会做视频，为什么还需要一套演出工程？

会做漂亮的动画，不等于能在俱乐部里演好一场视觉。做好一段视频以后，你仍然需要解决几个现场问题：DJ 换了一首歌怎么办？音乐突然抽掉鼓点时，屏幕还要继续闪吗？一段画面想保留十分钟，但只让其中的线条跟着节奏运动，应该怎么操作？

很多人第一次接触 VJ 软件时，会把素材排成一排，听到强拍就切一次。这样的方式能快速上手，却很容易变成追着音乐点击。事实上，一个 Club Live Set 更需要两种能力：**看清音乐接下来要去哪儿，以及让已经准备好的视觉内容能够随时跟上或停下。**

这篇文章从 Resolume Arena 的 **BPM Sync** 开始。你不必先懂 MIDI、TouchDesigner，也不必购买控制器。只要有几段自己的视频和一台电脑，就可以完成第一次测试。REACTOR Opening 的现场截图则提供了更进一步的观察：当 VJ 能看到 DJ 播放器的时间信息时，视觉可以比听见重音后才反应多出一点提前量。

## 01｜先学会看音乐的时间线

在 DJ 台旁边，除了听见音乐，还能看到播放器上的 **Waveform（波形）**。它把一首歌的声音强弱与时间位置画成可以滚动的图像。DJ 会参考波形和节拍网格判断当前播放位置、下一段变化与可衔接的位置；VJ 同样可以利用这些信息准备下一次视觉动作。

看这张我在现场拍摄的 **Beat Link Trigger** 操作截图。这里最有用的并不是那些彩色条纹本身，而是它们告诉你：**现在播到哪里，接下来还有多远，以及哪个播放器正在运行。**

第一次看这样的界面，可以按下面的顺序阅读：

1. **当前播放位置**：播放头在整首歌的哪一段？左边已经播过，右边是即将到来的内容。
2. **BPM / Tempo**：现在每分钟有多少拍？如果播放器调整了 Pitch，有效速度也可能变化。
3. **Beat Grid（节拍网格）**：规律的小刻度代表拍子，较大的分隔通常帮助辨认小节；这比只看波形峰值更可靠。
4. **段落线索**：突然变稀疏、出现长空白、波形密度持续改变，可能意味着 Breakdown、Build 或过渡。它是观察线索，不是自动识别“高潮”的保证。
5. **其他播放器**：DJ 正在准备下一首歌吗？混音可能发生在你以为当前歌曲结束之前。

**关于颜色。** 不同的播放器和软件可以使用蓝色、RGB 或三频段波形；特定颜色在特定模式下可能表达不同频段的能量，但不能脱离显示模式就断言“红色一定是低音、蓝色一定没有低音”。看颜色之前，先确认使用的是哪一种波形显示方式。更关键的判断始终是**当前位置、节拍、能量变化和耳朵听见的音乐**。

我在 REACTOR 使用的这种观察方式，让屏幕前的操作不再只是等鼓点响起再点击。比如看到前方一段即将变稀疏，可以先把画面里最亮的元素收掉；当下一段开始建立能量，再逐渐放回运动。**你是在跟随整场音乐的结构，而不只是在追逐每一下鼓。**

## 02｜BPM Sync 到底同步了什么？

**BPM（Beats Per Minute）**就是每分钟的拍数。假设 DJ 正在播放 120 BPM 的音乐，每拍约半秒；四拍是一小节，四小节是八秒。如果一段四小节的动画希望每次循环都在音乐的相似位置发生，就要让它按拍子运行，而不是固定按原文件的秒数播放。

Arena 在这里有两个非常实用的控制位置：

**A. Clip 的播放时间（Transport → BPM Sync）。** 将一段视频的播放模式从 Timeline 切换为 BPM Sync，再设置它跨越多少 Beats。例如 16 Beats 表示四小节。全局 BPM 改变后，这段 Clip 的播放速度会随之改变。原素材可以是手工制作的循环、Render，也可以是结构清楚的抽象动画。重要的是**循环长度与音乐结构的关系**。

**B. Effect 或参数旁边的小齿轮（Parameter Animation → BPM Sync）。** 这里不是让整段视频加速，而是让某个数值按节拍重复变化。例如 Brightness 每四拍从低到高再回去；Transform 的旋转按小节推进；一条遮罩以固定的节拍显隐。通过 Envelope（变化曲线）还可以决定是突然闪一下，还是缓慢上升后快速落下。

| 模式 | 控制什么 | 适合的画面 |
|---|---|---|
| Timeline | 按秒播放或变化 | 不需要跟拍的环境、缓慢运动 |
| BPM Sync | 按拍数和小节重复 | 脉冲、闪光、循环结构、节拍性特效 |
| Manual Trigger | 人选择何时进入和退出 | 意外重音、临时停顿、转场和释放 |

这三种模式可以共存于同一个工程。**不是所有视频都需要 Beat Sync**；比如背景里的宇宙、雾气或一台缓慢旋转的机器可以自由运行，只让其中一部分线条跟拍闪烁。

还有一个容易忽略的区别：**速度一致不等于拍点对齐**。两个程序即使都显示 128 BPM，一个可能正在第一拍，另一个却在第三拍。没有对齐时，尝试在正确的第一拍重新触发 Clip，或使用 Arena 的 Resync 把相位对齐。最简单的现场测试就是看画面变化是否真的落在你想要的重拍上。

## 03｜怎样把自己的素材变成一个能用的 Arena 工程？

不用一上来就做六层、八层的复杂工程。先找三段现成素材，明确它们各自做什么：

- **持续内容**：一段不必跟拍的背景影像。打开后即使一分钟不碰电脑，画面仍然成立。
- **节奏内容**：一段可以循环的视频，或者一个使用 BPM Sync 的 Effect。让它按四拍、八拍或十六拍运行。
- **瞬时内容**：短促的闪光、扫描或过渡；需要时触发，不需要就停止。

在 Arena 的 Composition 中，把它们放在几条不同的 **Layer（图层）**上。一个 Layer 是一条独立的视频轨道，同一时间可以和其他轨道合成。每条 Layer 旁边都可以调节 **Opacity（透明度）**：从 0% 到 100%，逐步控制它在合成画面中出现多少。

最基础的练习是：背景保持，第二条节奏轨道慢慢出现，再用第三条做一下重音；随后把后两条收掉。**从空到满，再从满回到空**，就已经有了可以演奏的变化。实际工程可以只有两层，也可以十几层；轨道数不是目标，重要的是你能清楚知道每个操作会改变什么。

做完后，先按下面的方法检查：

- 调整全局 BPM，节奏层能否跟着变速？
- 背景是否不会被迫一起加速？
- 播放器的重拍发生时，画面变化是否对得上？
- 把节奏层的透明度降到零，画面能否自然地恢复？
- 即使播放了十几分钟，是否仍然能快速找到需要操作的那条轨道？

能答出这些问题，比先准备一百段不同的视频更重要。

## 04｜演出时怎样跟上 DJ：从人工 Tap 到网络同步

对于没有任何外部连接的场地，最直接的办法是**听音乐并点击 Tap**：连续敲击四拍、八拍，让 Arena 估算 BPM；等到新的乐句第一拍，再使用 Resync 校准位置。你也可以直接输入 BPM 数字。这个方案不需要额外设备，只需要演出者保持听觉判断。

当场地有兼容的 DJ 播放器和可用网络时，情况会更有趣。REACTOR 使用的 **Beat Link Trigger** 能在网络允许的条件下读取部分播放器状态，显示波形、播放位置、当前有效 Tempo、Master/Sync 状态等信息。这能帮助 VJ 提前判断**下一次要准备什么动作**。

但是要分清三件不同的事情：

- **看见 DJ 的进度**：通过 DJ 台或 Beat Link Trigger 观察波形与时间位置。
- **让 Arena 按 BPM 运动**：Arena 的视频、Effect 或参数设置为 BPM Sync，跟随 Arena 当前的全局 BPM。
- **让不同软件共享节拍**：可通过兼容的 **Ableton Link** 等方案同步 Tempo 与节拍位置，前提是参与设备确实支持且已完成连接。

**Beat Link Trigger 的 Player Status 窗口本身，不代表 Arena 已自动接收到同步信号。** 应当在现场分别验证是否能看到播放器、是否能获得 Tempo、是否真的能同步，以及失去网络后该如何回到手动 Tap。

第一次搭系统时，建议先保证完全离线也能演出。然后再增加外部同步；否则网络一断，整个视觉工程都变得无法使用。

[Resolume：Ableton Link](https://resolume.com/support/en/link) · [Beat Link Trigger 官方手册](https://blt-guide.deepsymmetry.org/beat-link-trigger/8.0.0/Players.html)

## 05｜选择外设：先有操作方法，再决定买什么

经过前面的步骤，你已经可以用**鼠标和键盘**完成一次完整的视觉演奏，因此不需要为了入门先买一台设备。

等到你发现要同时操作很多层，或者希望眼睛持续看着舞台而不是电脑屏幕时，再考虑外设：

**键盘 / 独立按钮**适合触发 Clip、切换状态、暂停和临时闪光；**推子（Fader）**适合连续改变透明度、效果强度和其他渐变参数；**旋钮（Knob）**适合控制速度、模糊半径、旋转或密度。推子越多，代表你可以用双手直接接触更多参数，但也可能增加记忆负担。选择自己熟悉、能在暗场中盲操作的布局，比追求设备数量更重要。

**脚踏板**也是输入设备，不是另一个独立的同步系统。例如把脚踏的 1／2／3／4 映射成键盘按键，再由 Arena 的 Keyboard Shortcuts 将它们绑定到 Tap、Trigger 或常用操作即可。它的价值是让双手保持自由。使用 MIDI 控制器时，则在 Shortcuts → Edit MIDI 中选中参数，再操作相应的推子或按钮完成映射。

同样，如果已有 TouchDesigner、OSC 或自制网页控制器，也可以让它们发送同样的参数。输入可以有很多种；**不需要每做一种控制都重新设计整个演出工程**。

## 06｜专业创作者怎么做：三个与现场控制有关的案例

**DJ KRUSH × Daito Manabe｜CONNECTED WORLD（2020）**

Rhizomatiks 的这个项目将 DJ 使用转盘和混音台的动作转成可驱动视觉的实时信息。它解决的不只是“音乐响了让图像变亮”，而是**能不能从音乐家的操作本身得到输入**。它对小型 Club 系统的启发是：当能拿到实际播放信息或操作事件时，不必把所有控制都建立在声音分析上。

[项目档案](https://rhizomatiks.com/en/work/connected-world/)

**Nosaj Thing × Daito Manabe｜NO REALITY TOUR（2016）**

这场演出尝试将实时 3D 扫描、图像处理与现场光线纳入音乐现场。这里更值得研究的是它所需要的工作分工：创意和技术导演负责整体关系，程序开发实现实时图像，技术人员维护输入与现场输出。**一项效果能够实时运行，并不等于它已经可以稳定地巡演**；输入、处理、输出和操作者之间必须有清楚的交接。

[Rhizomatiks 项目资料与署名](https://research.rhizomatiks.com/en/works/nosaj_thing_coachella.html)

**Comix｜实时演出与 Notch 工作流**

Comix 的案例更接近“内容做完以后如何交给现场操作员”。实时场景可以把强度、模糊、拖尾、粒子密度等参数留给操作，同时还要考虑摄像机、Timecode、灯光系统与硬件性能。与单纯交一个视频文件相比，**交付的还包括哪些参数能被调节、哪些效果必须稳定、出了问题怎么返回**。

[Comix 实时演出工作流程](https://www.thisiscomix.com/real-time)

这三个案例不等同于同一套技术，也不是每个 Club 都需要它们的规模。它们分别回答三个问题：**怎样获得音乐家的信息；怎样把实时内容做成可运行的现场系统；怎样将它交给操作者。** 这才是 BPM Sync 练习继续向专业演出工程发展的方向。

## 07｜从控制台回到整个空间

回看 REACTOR Opening 的舞台摄影：屏幕里的结构、激光、DJ 台和舞池中的人形成了不同的亮度与距离。控制台里调得很强的闪光，投到整个场地可能已经过量；有些画面单看很简单，却恰好能让舞台留出空间。

这也是视觉与灯光团队需要提前沟通的地方。**VJ** 负责屏幕里的内容、层次和视觉操作，**LD（Lighting Designer）**负责灯光设计及其现场控制；在大型制作里还会有不同的媒体服务器与视频工程角色。双方可以先约定什么地方是暗场、什么地方一起打开、什么地方屏幕让位给灯光，而不要求彼此都去操作对方的软件。

对于 DJ 不固定曲目的 Club，最有用的协作也许很简单：能否看到当前歌曲的进度？下一段是收还是放？重音发生时谁保持空间，谁来完成主要视觉动作？有时这比实现一套完全自动的 Timecode 系统更适合现场。

**一套好用的 Club 视觉工程，不是让每个鼓点都产生效果，而是让创作者看懂音乐往哪里走，并能用最少的动作把已经做好的内容带进去、留住，再收回来。**
