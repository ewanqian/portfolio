# 让作品再次发生｜从 TIMER 与 Drop Flow 到可演奏的实时视觉

**钱誉文 / Ewan Qian · Research in Progress · 2026.11.06**

过去几年，我一直在制作可以被观看的影像，也尝试让影像进入现场：从与音乐同步的屏幕内容，到身体表演、沉浸式空间和实时控制。某些版本本来就使用实时生成，另一些依赖固定镜头、特定舞台和播放结构。作品有了不同版本，却也产生一个新的问题：怎样把曾经成立的图像规则从具体工程和场地中提炼出来，使它们能在新的情境中继续发展？

现在我想研究的，不是把旧片段做得更清晰，也不只是为它换一套渲染器，而是**能否把已形成的视觉语言转译成可运行、可演奏、可移植的规则**。一件作品应该保留自己的历史与性格，同时允许它在不同的空间、设备和表演关系中再次发生。

## 01｜从已有作品出发，而不是从新工具出发

**TIMER / 控时者**从 2024 年的音画与时间结构实验发展而来，先后进入杭州国际电子音乐节与 UFO Terminal「加载…权限 2」的环形屏幕呈现。合作创作者的公开说明保留了 A–B–C–B′–A′ 的回旋式结构，以及金属、水声、电子声和发条声等声音材料；它原本就尝试通过有序、无序、暂停、加速与逆转组织时间感，而不只是让画面跟随节拍。

**Drop Flow / 滴流**在 2025 年持续经历实时音画现场、UFO Terminal 实验和杭州双年展等不同语境。早期 OSC、Blender Python 与 Geometry Nodes 已经验证声音脉冲怎样生成点线面阵列；UFO Terminal 的 12 分 14 秒现场也已有实时生成与现场控制。新的研究不是第一次让它“实时化”，而是把这些规则从原来的空间、系统和表演中提炼出来，与身体运动和持续残影建立新的关系。

这两条实践并非从同一个软件效果推导出来。TIMER 更关心时间的组织，Drop Flow 更关心连续运动怎样生成空间。后续的演出控制实验则让我开始理解，画面被制作出来之后，还可以由哪些规则决定它何时进入、何时变化、何时消失。

在与 Kashiwa Daisuke 的深圳现场视觉合作中，我曾通过连续的日常练习寻找镜头与空间段落，而不是先准备一套封闭的“最终效果库”。现在值得恢复的，恰恰是这种可以每天验证一个视觉判断的工作状态。这里描述的是个人工作经验，不是把合作音乐或整场演出视为可以任意重用的个人素材。

## 02｜保留视觉语言，重新编写发生机制

一个视觉效果可以被拆成四种不同的材料：

- **形态**：粒径、轮廓、空间尺度、颜色、光影和留白；
- **运动**：流向、速度、惯性、聚散、延迟和衰减；
- **时间**：触发、持续、循环、倒流、残留以及状态切换；
- **关系**：它如何响应身体、声音、表演者操作和观众的位置。

传统视频保存的是某一次变化的结果；实时系统除了结果，还必须描述**变化发生的条件**。若只是把一段影片换成实时播放，作品并没有因此成为生成艺术。更重要的是规则、输入、反馈和记忆是否真的改变了后续的图像。

我希望为每件作品保留一份相对稳定的“视觉语法”，而不是给所有作品套一层通用粒子特效。技术模块可以共享，形式判断不应该被抹平。

## 03｜Drop Flow：人体作为粒子场的起点

Drop Flow 的下一次研究希望重新引入人的运动：让身体不只是出现在屏幕上的形象，而成为流场的**发射源、扰动源与记忆载体**。

一个初始的动作可以生成粒子；手臂、躯干和重心改变粒子的运动方向；身体离开以后，轨迹仍暂时停留、衰变或与新的运动交叠。观众未必需要看到完整的人体，却能从粒子与残影辨认出“有人刚刚经过”。

杭州双年展版已经归档的 Blender 舞者工程与 BVH 动作提供了一个可核对的研究入口。舞台预演、原始动作和重新定时的 NLA 动作并不完全相同。后续必须先确认动作数据、表演者和再利用授权，再决定哪些可以进入新的公开版本。

比“让每个骨骼发射粒子”更有价值的，是测试几种截然不同的关系：只有手部发射、沿速度方向留下可持续的轨迹、由身体姿态改变流场，以及不再显示人体、只保留动作残迹。它们应当导向不同的观看体验，而不是四种风格滤镜。

## 04｜TIMER：时间倒流不应只是视频反放

TIMER 早期使用沙粒、沙漏、红色提示和强烈的节奏变化，试图把“指缝中流过的时间”转化为形象。回看这些材料，部分场景对时间倒流的表达仍然过于直接：镜头反放能够呈现逆向运动，却未必让人感到时间真的被改变。

下一次研究将把“时间”作为系统中的变量，而不只是时间轴上的播放方向。例如，沙粒可以被暂时召回，但它曾经经过的位置仍有痕迹；一个动作可以反转，声音与场景记忆却继续向前；某段过程可以被保存、重演，也可以在第二次发生时偏离第一次。

这种差异也可以进入沉浸式空间。观众不必只面对一个巨大的沙漏，而可能被包围在不同速度、不同历史的颗粒层之中。Apple Vision Pro、Meta Quest 或全景视频是候选呈现媒介；是否使用实时 WebXR，要由交互的必要性和实际设备表现决定。

如果去掉标题和说明，观众仍无法区分“流逝、停滞、逆转、残留”，说明作品只是换了新的图像材料，尚未解决它自己的问题。

## 05｜同一作品可以有不同演出形态

我希望逐渐建立三种互相联系、但不互相冒充的版本：

**镜头版 / Shot**：保留最强的构图、动作和短时段张力，用于作品集、短片、展览预告和研究比较。镜头不是技术落后的代名词，它常常最适合做形式判断。

**现场版 / Live Instrument**：将作品中的少数视觉机制转成可触发、可保持、可撤回、可与音乐段落协作的实时模块。它不一定重建整件旧作品，却应让熟悉作品的人看见可辨认的作者语言。

**空间版 / Spatial Study**：研究那些只有观看者进入空间才成立的关系，例如身体与粒子场的距离、时间颗粒的深度和环绕感。没有充分空间理由的效果，不必为了头显而制作头显版本。

因此，最终并不是“一个引擎输出所有内容”。更合理的是共享有限的作品语法与数据，再为每种媒介作具体的编排和性能取舍。作品可以被引用、改写和再演，但每一次重演都需要有新问题。

## 06｜音乐作为结构，而不只是驱动信号

音画互动容易把音乐简化成 BPM、峰值和频谱。它们能够帮助同步，却不足以说明乐句的意义。

下一步可以从有授权的音乐工程或采样出发，提取段落、动机、声部进入、密度变化、停顿和重复方式，再由人把这些观察转成 Show Score 这样的中间描述。TIMER 已记录的 A–B–C–B′–A′ 结构正好可以先用于比较：当音乐重现类似的段落，图像是简单回到原状，还是带着先前状态的痕迹再度出现？Agent 可以辅助分析与提出映射候选，但不能把推测结果当成作曲家意图；音乐作者应保留对素材、改编和公开使用范围的决定权。

声音的分析是理解与协作的工具，不是自动获得改编权的技术途径。无法获得授权时，应采用原创声音、明确许可素材或由合作者提供的可用 stems 进行验证。

## 07｜作品谱系，以及可以被识别的个人语言

我希望积累的不是越来越长的效果列表，而是一个能够追溯的作品谱系：哪一条线来自 TIMER，哪一种流动属于 Drop Flow，哪些镜头研究来自现场合作，哪些规则经过重新实验才真正成立。

稳定的形态与运动语言还可能继续进入印刷、服装、物件和更轻量的现场视觉。这样的延伸需要经过筛选：当一个图形离开舞台、音响和技术说明，仍能被辨认、仍有足够明确的节奏与造型，它才可能作为作品的延伸存在。

IP 化不意味着把每一张画面做成商品。更重要的是建立一套能在不同规模的媒介中保持识别度、同时允许继续变化的视觉语言。

## 08｜在下一次演出之前，只验证最重要的部分

这轮研究的第一阶段不应同时追求两件完整的头显作品、两个全新的渲染引擎和一整套音乐生成系统。更有意义的是先从既有工程中恢复材料，做少量相互可比的短镜头，再挑选能够进入现有 Stage Casting / 实时演出链路的一个现场模块。

对于 Drop Flow，先判断“人体运动留下的流动”是否足够独特。对于 TIMER，先判断“逆转与记忆”能否形成不依赖说明的感知差异。对于舞台系统，则检验这些变化是否能够由表演者可靠地触发、维持、撤回和重演。

在这些测试完成之前，WebGPU、WebXR、全景视频与其他引擎都只是候选手段。真正要留下的，是经过比较后仍值得继续创作的规则、短片段和作品判断。
