# 00｜游戏化 AI 新媒体艺术工程师 101
## Gamified AI New Media Art Engineer 101
### AI 协作、工程化创作与音画原型｜MANA 先导工作坊

> 三小时建立一套最低可用的新媒体创作方法，下午做出原型，晚上完成第一次公开试玩或短演出。

这不是两门长期课程的简单拼接，而是它们共同的基础入口。

参与者会经历：

- 用 AI 帮助开始一个项目
- 理解 FRAME → FILL → FINISH 的开发顺序
- 保存 V1，并建立最基础的版本意识
- 快速建立视觉与声音素材
- 完成至少一组 Sound + Visual Mapping
- 把作品整理成一个可以被操作的状态系统
- 准备一段 30–60 秒 Micro Set

当日晚间设置轻量 After Party / Micro Showcase，让参与者真正把下午做出的作品拿来玩、拿来演、拿来被别人测试。

# 01｜游戏化 AI 新媒体艺术工程师
## Gamified AI New Media Art Engineer

> 先制造一辆能跑的车，再决定给它加什么。

2025 杭州中心美术馆《游戏化 AI 生活解构师》的重点，是让零基础参与者第一次使用 AI Agent 制作自己的模拟器。

2026 版本继续往前一步：当 AI 已经越来越会执行以后，参与者更需要一套基础的工程化创作方法。

核心流程：

**FRAME → SKELETON → FILL → TEST → REFINE → PUBLISH / PERFORM**

工作坊会建立：

- AI Coding 的最低可用理解
- Human-in-the-loop
- 项目文件 / README / V1 / V2
- Git / GitHub 的基本意义
- “先框架、后细节”的开发顺序
- 新媒体作品怎样从 Demo 变成可以继续维护的项目

这项工作坊既可以独立举行，也可以作为《音画同源乐器》的基础层。

# 02｜音画同源乐器
## Personal A/V Instrument

> 把自己的声音、图像和动作制造成一件可以玩的数字乐器。

参与者从个人声音、照片、视频、扫描、文字或 Generative Art 出发，通过键盘、鼠标和可选 MIDI Controller 建立自己的声音—视觉 Mapping。

核心不是效果数量，而是：

- 一个动作控制什么
- 声音和图像为什么一起变化
- Quiet / Active / Peak 等状态怎样切换
- 别人第一次拿到作品时能不能直接玩
- 它是否值得继续练习并进入演出

已有实践包括 2026 年 Found Video VJ Battle Royale 第八轮中开发的 Found VJ Deck。

长期版本推荐采用：

**Build → 7–14 天继续修改 → Rehearse → After Party / Showcase**

[音画同源乐器｜详细介绍](../../workshops/personal-av-instrument/README.md)

## 三层之间的关系

《游戏化 AI 新媒体艺术工程师 101》解决的是：

> **我第一次进入这套方法，今天能不能真的做出一个可运行、可操作、可展示的原型？**

《游戏化 AI 新媒体艺术工程师》继续解决：

> **怎样把想法变成一个能够运行、修改、测试和长期维护的新媒体项目？**

《音画同源乐器》进一步解决：

> **怎样让这个项目拥有声音、图像、操作方式和演奏性？**

## 基本形式

- **MANA 101：** 3 小时 + 当日晚间 After Party / Micro Showcase
- **长期公众版：** 每个工作坊约 3 小时
- **完整版本：** 可扩展为 6 小时、两阶段项目或系列课程
- **建议人数：** 12–20 人
- **门槛：** 不要求编程或音乐基础
- **基本设备：** 参与者自带笔记本电脑；稳定网络、投影、电源、桌椅
- **音画项目：** 建议基础扩声；MIDI Controller 为增强项，不是门槛
