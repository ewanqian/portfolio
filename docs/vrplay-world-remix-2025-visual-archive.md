## 3. 2025 视觉元素拆解

### A. WORLD REMIX 字标

特点：

- 大字号粗体主题字标
- 白 / 黑主体
- 镭射、颗粒、色散边缘
- 可重复成圆环和 Ribbon

保留价值：高。

2026 用法：减少无意义重复；保留 Hero + Orbit 两级。

### B. Iridescent CD / Disc

特点：

- 青绿、荧光黄、紫色、粉色镭射渐变
- 强烈数字媒介和实体数据载体感
- 与 “Remix / Play / Read / Write” 逻辑天然一致

保留价值：高。

2026 用法：从背景装饰升级为 Remix Signal、空间轨道和内容激活状态。

### C. Tape / Game Package / Physical Media

特点：

- 磁带、盒装媒介、周边包装
- 数字世界被做成“可以拿在手里的载体”

保留价值：高。

2026 用法：媒体档案、项目卡、Sponsor 信息容器、Save Point。

### D. Code / Terminal

特点：

- 代码注释
- AR、WebRTC、点云、植物识别等技术词汇
- 中英文混排

保留价值：中高。

风险：使用过多会变成普通“黑客科技风”。

2026 用法：只放在测试、原型、后台、档案节点等局部语境。

### E. Coordinate / Wireframe

特点：

- 空间坐标轴
- 透视线
- Wireframe 盒体
- 参数化图形

保留价值：高。

2026 用法：直接与 Truss、脚手架、空间骨架合并，成为“正在搭建”的结构语言。

### F. Point Cloud / Gaussian Garden

特点：

- 植物和空间处于扫描 / 加载 / 失真之间
- 真实生态与数字模型同时存在

保留价值：高。

2026 用法：Living Archive、温室节点、作品档案、世界边缘，不铺满整个空间。

### G. Black Digital Void

特点：

- 黑底提供数字空间、无边界世界和高对比度
- 对镭射光盘、绿色植物、白色线框很友好

保留价值：中高。

2026 用法：保留为数字底层 / 夜间状态，不再让所有主场景都处于纯黑空间；增加真实尺度的温室、结构与植物。

## 4. 2025 → 2026 升级原则

### 2025 更像

- 一张强烈的数字海报进入空间
- CD + Logo + Code + Point Cloud 的视觉拼贴
- 黑色虚拟空间
- 强主题字标与强图形密度

### 2026 要变成

- 一个可持续扩展的数字世界母结构
- WORLD REMIX 视觉资产被“建筑化 / 游戏化 / 系统化”
- 温室和植物成为真实空间核心
- Truss / Scaffold / Frame 表现世界正在生成
- Sponsor、工作坊、舞台、档案都成为可插拔模块
- 平面、动态、网页、3D、线下空间共享同一套规则

核心变化不是换风格，而是：

> **从视觉拼贴升级成世界构造规则。**
