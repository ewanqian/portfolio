# Asset selection rule

For every Work-level project, the minimum media package is:

```text
1 × scale/context Hero
1 × recognisable project/site signal
2–4 × visual/detail frames
1 × audience/use/context frame where relevant
1 × process/system frame
1 × short motion sample where motion materially matters
```

Do **not** fill slots for symmetry. A project with four strong images is better than a project with twelve redundant screenshots.
