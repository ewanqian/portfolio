# VR Play Hackathon / WORLD REMIX — 视觉设定

> Work in Progress / 当前视觉母系统
>
> 核心状态：**生长中的数字世界**。不是一个已经完成的“未来空间”，而是一个在持续搭建、接入、试验、存档和生长的 XR 世界。

## 1. 品牌关系

- **VR Play Hackathon**：活动 / 主办品牌层。
- **WORLD REMIX**：延续 2025 的主题与视觉资产，作为本届核心传播标题和世界观入口。
- 当前工作不重新发明一个全新的品牌，而是在 2025 WORLD REMIX 的基础上升级为可持续使用的视觉—空间系统。

品牌出现规则：

- 每个主视角只保留 **1 个 Hero WORLD REMIX**。
- 可保留 **1 条 WORLD REMIX ribbon / orbit** 作为连续空间标识。
- VR Play Logo 作为主办标识出现，尺寸和权重低于主题标题。
- 避免 Logo、代码、CD、导视、施工牌同时以最高权重出现。

---

## 2. 2025 WORLD REMIX 可继承的视觉 DNA

2025 版本已经形成一组值得保留的元素，不需要全部推翻：

### DISC / 光盘

- 镭射 CD、光盘渐变、圆盘轨道。
- 代表 Remix、媒介、循环、读取与重新写入。
- 2026 不再把 CD 当作到处贴的装饰，而作为“激活 / Remix Signal”。

### TAPE / 媒体档案

- 磁带、VHS / 数据载体、游戏包装盒式物料。
- 代表可携带、可交换、可存档的数字文化。
- 可转化为媒体档案站、项目卡片、赞助商信息容器。

### CODE / 数据复古

- 代码片段、Terminal、扫描参数、WebRTC / AR / 植物识别等伪技术文本。
- 不是为了表现“科技感”，而是让 WORLD REMIX 保留创作者正在制作、调试和修改世界的状态。
- 代码只出现在局部信息层，不做全屏噪声。

### GRID / COORDINATE

- 坐标、线框、结构线、空间轴、Wireframe。
- 既是 2025 平面视觉语言，也可直接转化为 3D 空间骨架。

### POINT CLOUD / SCAN

- Gaussian Splatting、点云、扫描温室、植物数据。
- 保留“不完全加载”的空间质感，作为真实植物与数字世界之间的过渡层。

### LOGO RIBBON / ORBIT

- WORLD REMIX 的重复字带、圆环和运动轨迹。
- 2026 将其从背景纹理升级成真正的空间组织工具：轨道、边界、围挡、楼层线、舞台环带。

### BLACK VOID + IRIDESCENT SIGNAL

- 2025 的黑色数字空间与彩色镭射信号继续保留。
- 但 2026 增加更明确的温室、植物、结构和真实空间尺度，让视觉不只停留在黑色虚拟空间。

## 3. 2026 母概念：生长中的数字世界

WORLD REMIX 不被设定成一个完成的元宇宙展厅。

它是一套**持续搭建的数字生态**：

- 世界结构还在搭；
- 植物与档案继续生长；
- 参赛者、项目、工具和供应商不断接入；
- 活动举行时，世界本身仍处于测试和建设状态；
- 每届活动都留下新的空间节点和数字遗迹。

因此 “Work in Progress” 不是未完成的借口，而是品牌本身的时间状态。

建议内部概念句：

> **WORLD REMIX：一个持续生长、持续被重混的数字世界。**

可用于空间与传播的短句：

- 欢迎回到温室
- 世界还在长
- 正在搭建
- 先来逛逛
- 点子上桌
- 先试玩
- 媒体花园
- 温室档案
- 一起把世界搭起来
- 还在搭，但先开场

中文文案保持短、口语化、像游戏内部提示，不写企业展厅式正式文案。

## 4. 三个结构母题

所有平面、动态、网页和 3D 空间优先从以下三种结构生成，不继续无限增加视觉母题。

### A. GRID / FRAME — 正在建造

元素：

- Truss
- 脚手架
- 线框
- 坐标轴
- 模块钢架
- 临时平台
- 半透明布
- 施工围挡
- 设备箱 / Flight Case

原则：结构裸露是设计语言，不是“会展没搭完”。同一种结构需要重复、有尺度规则、有明确用途。

### B. DISC / ORBIT — 正在 Remix

元素：

- CD / 光盘
- 圆形舞台
- WORLD REMIX 字带
- 圆环导视
- 数据轨道
- 存档节点

原则：圆盘和轨道承担“读取 / 播放 / Remix / 聚集”的功能。

### C. GREENHOUSE / GROWTH — 正在生长

元素：

- 温室骨架
- 透明膜 / 玻璃 / 半透明板
- 绿色植物
- 点云植物
- 扫描残片
- Living Archive

原则：植物不是装饰绿化，而是世界进度和档案生长的可视化。

## 5. 核心空间结构

空间层级保持简单：

```text
WORLD REMIX ORBIT
        ↓
GREENHOUSE CORE / LIVING ARCHIVE
        ↓
PLUG-IN MODULES
供应商 / 工作坊 / 媒体 / 舞台 / 项目展示
```

### Greenhouse Core

- 永远是主要空间记忆点。
- 模型尽量使用圆柱、环、钢架、透明板和植物构成。
- 不依赖复杂曲面和大量细节，也能形成识别度。

### WORLD REMIX Orbit

- 环绕核心的主题字带 / 数据轨道。
- 可变成屏幕、灯带、导视、网页滚动元素和动态 Logo 系统。

### Plug-in Modules

- 所有功能区像插件一样接入母结构。
- 活动结束后允许替换内容，而不重新设计整个世界。

## 6. 视觉风格与建模原则

目标不是写实未来城市，也不是 Low Poly。

### 要

- 简洁几何
- 中等建模精度
- 扁平 / 半扁平渲染
- 大块材质
- 干净轮廓
- 清晰空间层级
- 可快速复制的模块
- 少量透明与镭射材质作为信号
- 植物形成局部复杂度
- 施工结构保留真实尺寸感

### 不要

- 超写实建筑效果图
- 无意义的全息屏幕海洋
- 每一块表面都有 UI
- 过多“AI 未来城市”细节
- 纯 Low Poly / Faceted 风格
- 赛博朋克霓虹堆叠
- 巨量 Logo 贴纸造成视觉噪声

判断标准：**一个普通的 Blender / Spline / Three.js 场景，用相对简单的模型也应当能够复现 70% 的视觉效果。**

## 7. 色彩系统

基础空间保持稳定：

- Black / Deep Charcoal
- Silver / Metal
- Off-white
- Green / Plant Green

Remix Signal 才使用高彩：

- Cyan
- Lime
- Violet
- Pink
- Iridescent CD Gradient

颜色不是平均铺满整个空间，而是作为“事件状态”：

- 导航被激活
- 项目正在运行
- Sponsor 节点被进入
- 内容发生 Remix
- 舞台 / 庆典开始

这样能同时继承 2025 的彩色光盘记忆，又避免整个画面一直处于最高饱和度。

## 8. 供应商 / 合作伙伴模块

供应商不各自建一套独立“元宇宙世界”，统一接入 WORLD REMIX 模块系统。

### S / Display

适合：Logo、文字、图片、小型产品 / 模型。

组成：

- 1 个标准 Frame
- 1 块品牌面板
- 1 个展示台
- 1 个资料入口

### M / Lab

适合：产品模型、技术 Demo、声音 / 影像 / AI / XR 工具展示。

增加：

- 交互屏 / Web Demo
- 简单模型
- 展示桌
- 可更换的背景布 / 半透明帘

### L / Garden

适合：重点赞助商、Workshop、小型发布 / 体验活动。

增加：

- 独立植物区
- 小型 Truss
- 展示 / 演示空间
- 更完整的品牌内容

建议供应商品牌色只占模块整体视觉的约 20–30%，其余保持 WORLD REMIX 母系统。

供应商基础素材清单：

- Logo（矢量）
- 品牌色
- 100–200 字介绍
- 产品图片
- 可选 3D 模型
- 视频 / Demo
- 技术资料或开发资源

## 9. 平面 / 动态 / 网页的统一生成规则

### 平面

由以下元素组合：

- WORLD REMIX Hero
- Disc / Orbit
- Grid / Coordinate
- 1 个媒介载体（CD / Tape / Archive Card）
- 1 个生长对象（植物 / 扫描植物 / 温室）

不要在一张海报里把所有素材同时使用。

### 动态

重点不是复杂 CG，而是规则化运动：

- Orbit 环绕
- Ribbon 滚动
- 扫描 / Load / Glitch
- Grid 对齐与解构
- 植物 / 档案节点逐步加载
- CD 旋转、读取、切换状态

### Web / Spatial Landing Page

优先路线：

1. Spline：验证空间比例、交互入口和 Sponsor 模块。
2. Three.js / React Three Fiber：需要更复杂的空间和自定义逻辑时再升级。
3. GSAP：滚动、镜头、UI 动效。
4. Gaussian Splatting：只在档案 / 扫描节点中使用，不让整个网站依赖高负载 GS。

网页像一个“游戏主菜单 + 可逛大厅”，不是完整多人元宇宙。

## 10. 设计参考：提取方法，不复制表面风格

### Otl Aicher

借：大型活动如何用色彩、图标、地图、导视和版式组成一个长期一致的系统。

用于：视觉规范、导视、信息层级、活动 PPT / 手册。

### The Designers Republic

借：音乐、游戏、数字文化、伪产品、电子媒介与品牌语言之间的混合。

用于：CD / Tape / Code / 游戏化文本，不让“数字复古”变成普通 Y2K 装饰。

### Experimental Jetset

借：少量文字、重复、尺度和位置就能形成强系统。

用于：降低 WORLD REMIX Logo 噪声，让字带真正变成空间结构。

### Studio Dumbar

借：动态身份、Creative Coding、声音与品牌系统的连续性。

用于：动态海报、直播包装、网页运动系统、实时屏幕。

### Cedric Price / Fun Palace

借：未固定、可插拔、持续变化的建筑和程序状态。

用于：把“搭建中”转化成 WORLD REMIX 的核心空间逻辑。

### Lacaton & Vassal

借：温室、钢结构、透明材料，以非常简单的建筑构造创造大空间和生长性。

用于：Greenhouse Core 和低成本 3D 建模策略。

### Centre Pompidou / Piano + Rogers

借：暴露结构、设备和色彩编码，使施工 / 工业构件成为清晰可读的建筑语言。

用于：Truss、架子、设备箱、线路如何“不显乱”。

## 11. AI / 概念图生成约束

后续生成图统一要求：

- stylized game environment
- flat / semi-flat shading
- concise geometry
- buildable modular architecture
- greenhouse + truss + archive media
- restrained retro-digital graphics
- controlled iridescent accent
- work-in-progress world
- Chinese wayfinding / informal copy

负面约束：

- no photorealistic luxury mall
- no generic metaverse showroom
- no excessive holographic UI
- no cyberpunk city
- no low-poly faceting
- no over-detailed AI concept-art texture
- no logo wallpaper

## 13. 视觉验收标准

一张图 / 一个空间在继续推进前，至少满足：

1. 第一眼能看到一个明确的视觉中心，而不是所有东西同时抢注意力。
2. 能识别 WORLD REMIX，但 Logo 不成为墙纸。
3. 能看到“正在搭建 / 生长”的状态。
4. 有植物，但不像商业综合体绿化。
5. 有数字复古媒介，但不是简单 Y2K 拼贴。
6. 3D 结构能被模块化、低成本复现。
7. 平面、动态、网页、舞台可以共享同一套元素。
8. 即使活动信息与供应商更换，母系统仍然成立。
