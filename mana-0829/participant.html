01 · CONTROL MODEL

继续沿着同一条控制链练习。

INPUT ↓ MAPPING ↓ STATE / CLOCK / MEMORY ↙ ↘ SOUND VISUAL ↓ FEEDBACK ↓ NEXT DECISION
02 · SMALL EXERCISES

一次增加一个关系。

01

Tap / Hold / Release

一个输入先获得时间结构：短按、按住、松开、空闲。

02

BPM / Quantize

加入唯一的 Transport，让声音和视觉进入共享节拍。

03

State

OPEN / BUILD / PEAK / BREAK，使同一输入在不同阶段承担不同作用。

04

Visual Variant

从 GRID / ORBIT / GLYPH / FIELD / GRAPH 中选择一种结构继续发展。

05

Keyboard Controller

用 Space、方向键、数字键、F 与 Esc 形成最小演奏界面。

06

External Input

鼠标、摄像头、手机陀螺仪或 MIDI 先转换成 0–1 参数，再进入 Mapping。

03 · VERSIONED AI DEVELOPMENT

把每一轮 AI 修改保存成版本。

聊天记录适合保存讨论，Git 适合保存项目状态。每次只解决一个明确问题，修改完成后先运行、查看差异，再决定保留或回退。

可运行版本 ↓ Git Commit ↓ 给 Agent 一个明确任务 ↓ 修改 ↓ 运行 / 试玩 / 查看 Diff ↓ 保留 → Commit 或 回退 → 下一轮
建议在第一次让 Agent 大改之前先保存 baseline。以后任何一个“这个版本还不错”的时刻都可以立即 commit。
04 · LOCAL GIT / GITHUB

本地 Git 和 GitHub 网页都可以开始。

LOCAL GIT

适合连续开发

使用 VS Code、Codex 或其他本地 Agent 时，可以直接查看 diff、创建分支、commit 和 revert。适合频繁修改多个文件。

GITHUB WEB

适合先理解版本

可以查看 Commits、History 和文件改动。先学会“一个版本对应一次明确修改”，再逐渐进入本地 Git。

推荐的版本命名： baseline: working starter feat: add shared BPM clock feat: add tap hold release states fix: stop voices on reset experiment: graph routing v1 refine: reduce peak density release: workshop demo v0.8
05 · AGENT ITERATION

每轮修改先限定范围。

先读取当前项目和 Git 历史。 这轮只解决：______。 开始前告诉我： 1. 准备修改哪些文件； 2. 哪些部分保持不动； 3. 最小验收方法是什么。 完成后： 1. 运行必要检查； 2. 总结 diff； 3. 说明已知限制； 4. 不继续追加无关功能； 5. 当前版本成立时创建一条能说明意图的 commit。 不要提交 token、密码、API key 或私人地址。
版本化 AI 开发 Skill
06 · FROM PROMPT TO SKILL

把反复出现的经验从 Prompt 中抽出来。

如果同一类提醒已经重复出现，并且有稳定的检查方法，可以把它整理成 Skill。项目文件结构、发布地址等信息留在项目自己的 README / AGENTS.md；跨项目仍然有效的方法单独保存。

PROJECT CONTEXT

项目规则

文件结构、运行方式、视觉语言、禁止改动区域、发布路径、项目专有命名。

REUSABLE SKILL

通用经验

Variant Design、Blind Playtest、Audio Voice Design、版本管理、参考视频分析等可跨项目复用的方法。

一次 Prompt ↓ 重复修正 ↓ 形成稳定判断 ↓ 写清步骤与验收 ↓ Skill ↓ 在下一项目再次调用
经验 → Skill
07 · SAVE + SHARE

稳定版本再发布。

01

保存版本

Commit 当前稳定状态，并记录这一版解决的问题。

02

整理入口

index.html 作为入口，图片、声音、CSS、JS 使用可发布路径。

03

发布

GitHub Pages 或 Cloudflare Pages 都可以把静态项目变成分享链接。

04

重新验证

用无痕窗口测试声音解锁、键盘、全屏、Reset 和资源路径。

发布后记录两样东西： URL: https://... Commit: abc123... 这样以后看到录屏或作品页面时，可以找到当时真实运行的代码版本。
08 · ADVANCED ROUTE

Phone / Sensor / MIDI ↓ Mapping / State / Clock ↓ Browser / Processing / TouchDesigner ↓ OSC / Syphon / Spout ↓ Stage Output
