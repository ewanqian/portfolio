# 《无需进一步输入 / No Further Input Required》

**钱誉文 / Ewan Qian · 2026**  
**单通道影像 / Single-channel moving image · 约 90 秒 / approx. 90 sec · 16:9 · loop**

## 当前公开说明

《无需进一步输入》由 AI 辅助编程与生成视觉实验发展而来。前期，钱誉文不断运行、预览、修改并筛选生成程序的结果；随着系统持续扩展，生成的增加并未自动带来作品的完整。最终影像保留程序自身的运动逻辑，而构图、密度、变化幅度、时间结构与剪辑仍由艺术家决定。

“无需进一步输入”并不是对自主智能的确认，而更像一个人为设下的停止点：当某个参与者停止继续输入，此前留下的代码、参数、文件与选择还能把作品带多远？

最终展览版本为约 90 秒的单通道影像，有明确的开始与结束，在现场循环播放；无现场 AI、观众交互或实时控制程序。

## Current public statement

*No Further Input Required* developed through AI-assisted coding and generative visual experiments. During development, Ewan Qian repeatedly ran, previewed, modified, selected and removed generated results. More generation did not automatically make the work more complete. The final moving image retains the program’s motion logic, while composition, density, range of change, temporal structure and editing remain artistic decisions.

The title does not declare an autonomous intelligence. It marks a chosen stopping point: when one participant stops providing further input, how far can the code, parameters, files and decisions already left behind continue to carry the work?

The exhibition version is an approximately 90-second, 16:9 single-channel moving image with a defined beginning and ending, presented on loop. It does not require live AI, audience interaction or a real-time control program.
