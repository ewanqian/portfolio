# NFI — 30s Processing Exhibition Candidate / R3

Date: 2026-08-25
Status: CURRENT WORKING MASTER

This brief supersedes the 180-second runtime duration for the current submission build. The final screen-recorded file may be approximately 3 minutes, but the generative system itself is a 30-second deterministic cycle repeated six times.

## Current source structures

Only three recovered 2026-08-16 structures are foregrounded:

```text
CONSTRAINT MECHANISM
INDEX FIELD
QUANTIZED MEMORY
```

They are no longer separate states. They share one hierarchical grid and coexist throughout the cycle.

## Spatial hierarchy

```text
12 × 7 major grid
  ↓
24 × 14 index grid
  ↓
72 × 42 memory micro-grid
```

Constraint geometry sits on the major grid.
Index marks occupy the first subdivision.
Memory dashes / squares occupy the micro-grid.
ASCII / Unicode glyph zones are addressed from the same coordinates.

## 30-second cycle

The loop is continuous rather than divided into visible scenes.

Internal overlapping phases:

```text
0–8s-ish      registration / sparse address
5–18s-ish     absorption / structural growth
14–25s-ish    recall / old pattern returns
21–30s        autonomy / remainder / return
```

The exact envelopes overlap and are cyclic. There is no hard cut at the 30-second boundary.

## Three refinement rounds

### R1 — ORDER

- strict hierarchical grid;
- Constraint + Index + Memory only;
- recover 08/16 visual DNA;
- establish negative space and alignment;
- no symbol layer.

### R2 — MECHANICAL LANGUAGE

- add ASCII / Unicode marks as addressed machine-state units;
- finite zones illuminate in timed patterns;
- no words and no labels;
- no random text rain;
- add segmented progress logic and persistent anchors.

### R3 — EXHIBITION CANDIDATE

- reduce visible grid scaffolding;
- memory surface becomes dominant during recall;
- glyph density reduced from R2;
- history can appear slightly before current addressing reaches it;
- one rare long calibration event;
- retain black as the main material.

## Glyph behaviour reference

The symbol layer borrows only behavioural principles from Nothing's Glyph Interface / Glyph Matrix:

```text
finite addressable zones
+ temporal light patterns
+ progress
+ persistence
```

It does not reproduce Nothing hardware geometry, icons, logos or notification semantics.

## Final visual rules
