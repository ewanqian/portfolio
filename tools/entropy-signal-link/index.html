01 / ROLE

Sender / 发送端
音乐电脑：选择 Audio / MIDI，然后发送。
Music computer: choose Audio / MIDI and send.

Receiver / 接收端
视觉电脑：加入同一 Room，接收分析数据或音频。
Visual computer: join the same Room.

02 / QUICK PAIR

如果配置了 signaling server，两边输入同一个 Room 即可自动匹配。
With a signaling server, both devices only need the same Room code.

没有 server 时也能用：Sender 点 CREATE OFFER → 发给 Receiver → Receiver 粘贴并 CREATE ANSWER → 再发回 Sender。
Without a server: Sender creates an offer, Receiver creates an answer, then sends it back.
