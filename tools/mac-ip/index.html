MAC LOCAL IP / QUICK CHECK
局域网 OSC · Ableton · ENTROPY Signal Link
ZH / EN
01 — FASTEST / 最快
打开 Terminal，复制这一行
Open Terminal and run:
ipconfig getifaddr en0
返回类似 192.168.1.23 的数字，就是你当前 Wi‑Fi 常用的局域网 IP。
The result, usually something like 192.168.1.23, is your local Wi‑Fi IP.
02 — SYSTEM SETTINGS
系统设置 → Wi‑Fi → 当前网络 → 详细信息 → TCP/IP

System Settings → Wi‑Fi → current network → Details → TCP/IP
03 — IF en0 IS EMPTY
如果上面的命令没有结果，先运行：
ifconfig | grep "inet "
找 192.168.x.x、10.x.x.x 或 172.16–31.x.x。不要用 127.0.0.1。
04 — FOR OSC RIGHT NOW / 现在给 OSC 用
把查到的 IP 填到对方 Ableton / Max for Live OSC sender 的 Host / Destination IP。端口先用 9000。
YOUR VISUAL MAC IP : 9000
Example: 192.168.1.23 : 9000
两台电脑必须在同一个 Wi‑Fi / LAN。Both computers must be on the same local network.
Tip: this page cannot reliably reveal your private LAN IP directly because modern browsers hide local interface addresses. Use the Terminal command above.
