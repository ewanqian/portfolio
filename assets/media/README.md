# VIRTURA media library

Stable, public-ready media for `ewanqian.site` and related VIRTURA pages.

Use the path in `manifest.json` directly from a website, for example:

`/assets/media/works/kashiwa-titan-2025/bo-live-01.jpg`

Store new work media under `works/<work-id>/`. Keep source masters and long video cuts outside this repository; add only approved, web-ready JPEG, PNG, GIF, or short optimized MP4 files here.

Every new item must have an entry in `manifest.json` with its project, credit, and intended public use.
