# SRE Realtime System Research Environment

## Overview

SRE is a realtime visual system archive based on Processing experiments. These prototypes are preserved as research assets for future web-based instruments and live performance systems.

## Core Assets

### Data Infographics Lab
- Category: Generative Data Visualization
- Status: Priority conversion
- Visual features: nodes, fields, information flow, particle networks
- Future: WebGL / p5.js interactive data field

### OSU Signal Game
- Category: Interactive Visual Instrument
- Status: Priority conversion
- Visual features: timing, signal, collision, feedback, performance interaction
- Future: browser-based playable visual instrument

### Stage Lights Motor
- Category: Realtime Stage Simulation
- Status: Priority conversion
- Visual features: beams, movement, rhythm, intensity, spatial lighting
- Future: Three.js stage lighting simulator

### MIDI Signal Monitor
- Category: Input Mapping Tool
- Visual features: realtime signal inspection and controller feedback

### Spatial / Interface Studies
- Index Disc Stage
- P3D Fog Scan Lab
- Wide GUI Study
- Wire Studies

## Conversion Pipeline

Processing → JavaScript → p5.js / Three.js → Pug.js embed → Portfolio Lab Archive
