# NFI Keyboard Liveset v0.2

《无需进一步输入 / No Further Input Required》与「音画同源乐器 / Personal A/V Instrument」工作坊下的键盘音画乐器原型。

## 本版变化

- 键盘按真实 **QWERTY** 三排布局显示，不再按 A–Z 字母表排序。
- 声音从用户提供的 `39929580155-1-192.mp4` 中提取原始音轨，并按短片段切分进入键盘。
- 当前只保留这一组核心词：**叮 / 咚 / 鸡 / 大 / 狗 / 叫**；不再出现“核酸”等无关占位文本。
- 视觉继续保持干净：一个键对应一个大字、一种纯色和一次很轻的缩放反馈。

## QWERTY 映射

```text
Q W E   R T Y   U I O P
叮咚鸡   叮咚鸡   大狗大狗

A S D   F G H   J K L
叫叫叫   叮咚鸡   叮咚鸡

Z X C V   B N M
大狗大狗   叫叫叫
```

这样从左到右扫键盘就能直接形成短语节奏，也更接近“把电脑键盘当成一件乐器来弹”的演奏方式。

## 音频来源

源文件：`39929580155-1-192.mp4`

文件转写中可以确认重复出现：

> 叮咚鸡，叮咚鸡，大狗大狗，叫叫叫……叮咚鸡，叮咚鸡，大狗大狗，叫叫叫……

当前 v0.2 只抽取这一组重复材料作为演奏素材，其他语句暂不进入乐器。
