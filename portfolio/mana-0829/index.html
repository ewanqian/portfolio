01 · 课程结构

一个输入怎样逐步变成一套系统。

INPUT ↓ MAPPING ↓ STATE / CLOCK / MEMORY ↙ ↘ SOUND VISUAL ↓ FEEDBACK ↓ TEST / MODIFY / SHARE

课堂先用简单 Demo 建立输入与反馈的关系，再加入 Tap / Hold / Release、BPM、Quantize、Shared State 与 Scene。最后把自己的声音和视觉材料放进系统，交给别人试玩并完成一次修改。

02 · 讲者内容

系统搭建与表演界面。

钱誉文 Ewan Qian

从一个输入出发组织网页音画系统；讨论 AI 辅助开发、FRAME → FILL → FINISH、BPM / State / Memory，以及如何把小型练习保存成可继续发展的演出模块。

03 · 课堂练习

从 V1 到 V2。

一个按钮

把 Tap、Hold、Release 和 Idle 做成不同时间状态。

放进节拍

使用 BPM / Transport / Quantize，让声音与视觉进入共同时间坐标。

增加状态

使用 OPEN / BUILD / PEAK / BREAK 等 Scene，让同一 Trigger 在不同阶段拥有不同意义。

交换试玩

作者先不解释，让另一位参与者直接操作；找到一个最明显的问题，再完成 V2。

04 · 课后继续

网页只是一个方便保存和分享的入口。

完成后的练习可以继续加入键盘控制、MIDI、手机传感器、OSC、Processing、TouchDesigner、Syphon / Spout 等。保持同一套 Input / Mapping / State / Feedback 结构，就可以从浏览器原型逐步进入更完整的现场系统。
