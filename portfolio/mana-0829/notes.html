01 · 课程从哪里开始

先确定输入，再搭系统。

工作坊把“一个按键、一段鼠标移动、一次触摸”当作最小输入。先观察它怎样改变声音、视觉和系统状态，再逐步加入节拍、记忆、场景和更多控制。

输入 Input ↓ 映射 Mapping ↓ 状态 State / 时间 Clock / 记忆 Memory ↙ ↘ 声音 Sound 视觉 Visual ↓ 反馈 Feedback ↓ 下一次操作

这个顺序的好处是，每次修改都能回答一个具体问题：输入是什么、系统如何解释它、结果是否清楚、下一次操作为什么还值得发生。

Audio Visual / Mapping / 表演界面

分享主要围绕 Mapping、限制和表演界面展开。一个鼠标或一个按键本身很简单，但它可以通过时间、速度、间隔、规则和当前状态转化为更连续的表现。

另一个重点是表演的可读性：观众需要感受到“操作正在改变系统”。控制关系过于直接会很快被看穿，完全不可读又会失去演奏感，因此需要在因果关系、限制和不完全控制之间寻找合适的深度。

03 · 共同讨论的几个问题

音画关系、控制深度和表演结构。

音画同源

课堂里的“音画同源”是一种工作方法：声音和视觉尽量从同一个输入、参数或状态中产生，而不是等声音完成之后再让画面追随。

一对一 Mapping 与更深的 Mapping

“按一下就响一下、闪一下”适合建立最初的因果关系。继续往下做时，可以让同一个输入同时影响多个变量，也可以让多个输入共同决定一个结果。Hold Duration、速度、重复频率、当前 Scene 都可以成为新的条件。

产品界面与表演界面

给别人使用的界面通常追求清楚和稳定；用于现场表演的界面还需要考虑身体动作、节奏、反馈速度以及观众能否看见控制正在发生。两者可以使用相同技术，但设计目标并不完全相同。

限制

限制输入数量、音色范围、可切换的状态和同时出现的元素，可以让系统更容易被演奏。控制的重点不是把所有参数都放在手上，而是决定哪些变化值得被保留。

04 · 课堂里的基本结构

从 Trigger 到可以持续演奏。

Tap / 短按一次明确的短事件。适合 transient、短视觉触发和节拍中的离散动作。
Hold / 按住把持续时间变成参数。可以进入 drone、loop、density 或 accumulation。
Release / 松开不是简单停止。可以进入 decay、reverb tail、residue 或新的 phrase。
Idle / 空闲系统没有输入时的状态。可以保留轻微 ambience、memory 或自动变化。
BPM / Clock声音和视觉共用的时间坐标。输入可以被放到 beat、1/8 note 或 bar。
Quantize / 量化人先表达意图，系统把正式事件放到稳定的时间位置。
State / 状态OPEN、BUILD、PEAK、BREAK 等状态让同一个 Trigger 在不同阶段拥有不同意义。
Memory / 记忆让前一次操作影响后一次结果，例如残影、能量累积、延迟或历史路径。
05 · 一套最小的演出结构

状态比效果列表更容易组织。

当视觉和声音逐渐增多，可以先把它们按功能组织成几个 Scene，而不是继续增加无编号的 Effect。

OPEN 少、慢、留白 BUILD 增加重复、方向和密度 PEAK 最明确的能量与层级 BRIDGE 改变路径，保留连接 RELEASE 回收材料，留下残余或结束

声音、视觉和灯光不需要复制同一件事。它们只需要共同解释当前状态。例如 BUILD 可以让声音增加 subdivision，让视觉提高 density，而空间仍然保持收窄。

06 · 课堂制作流程

做出 V1，再通过试玩修改。

试玩 Demo ↓ 选一个输入 ↓ 做出 Sound + Visual + State ↓ 得到 V1 ↓ 换自己的声音 / 图片 / 图形 ↓ 交给别人直接试玩 ↓ 只找一个最明显的问题 ↓ 修改为 V2

这里的测试很简单：作者先不解释，让另一位参与者直接操作。观察对方第一步会做什么、什么时候发现第二层行为、哪里完全没有反馈，以及什么时候开始觉得重复。

07 · 工具与延伸

网页、声音、现场和分享。

Web Audio API浏览器原生声音系统。适合 oscillator、sample、filter、delay、sequencer 和精确调度。
Tone.js基于 Web Audio 的音乐框架。Transport、Sequence、Loop、Synth、Sampler 更适合快速搭音乐结构。
Strudel浏览器里的 pattern / live coding 环境。适合继续研究节奏、pattern 与算法音乐。
WebGL / Canvas用于实时视觉。关键仍然是让视觉读取同一个 State / Clock，而不是单独堆效果。
Processing / OSC当项目需要外部控制器、手机传感器或多软件协同时，可以把同一套 Mapping 继续带到现场系统。
GitHub Pages把一个静态网页发布成可分享 URL。仓库同时保留源码、版本与说明。
