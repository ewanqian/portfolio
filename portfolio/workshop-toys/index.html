WORKSHOP TOYBOX · MINIMAL CONTROL STUDIES

把一个很简单的控制，
做得值得多玩几次。

这些不是完整作品，而是从工作坊开发过程里拆出来的六个小组件。每个只研究一件事：时间、量化、密度、路径、记忆或状态。可以直接玩，也适合复制给 Agent 继续改。

T01 · TEMPO LEVER

节拍器不是一个数字

用一个竖向滑块和 ± 按钮控制 BPM。观察速度变化怎样同时改变声音、视觉与身体预期。

120 BPM
T02 · QUANTIZE GATE

先表达意图，再落到节拍

随便点 TAP。输入会立即出现蓝色 pending，正式事件则落在下一格。它把“我要现在做”与“什么时候真正发生”分开。

WAITING
T03 · DENSITY FADER

一个滑块控制复杂度

不是增加更多按钮。只用 Density 决定单位时间里允许发生多少事件，同时保留上限。

35%
T04 · GRAPH ROUTER

把效果列表变成路径

同一个 NEXT 按钮沿 Graph 前进。重点从“选哪个效果”变成“系统现在在哪里、下一步去哪里”。

FIELD
T05 · RELEASE MEMORY

输入结束以后还发生什么

按一次 TRIGGER，系统会留下尾迹。Memory 决定过去保留多久；同一个输入因此拥有不同时间长度。

MEM 58
T06 · STATE LADDER

同一个输入，在不同状态里意义不同

只用 ↑ / ↓ 改变 OPEN、BUILD、PEAK、BREAK。中央 TRIGGER 完全相同，但声音、密度和反馈会随状态变化。

OPEN
sparse / soft / long
