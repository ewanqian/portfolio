# Yu Jiayun 45㎡ Visual Frames

Selected project images for the portfolio page.

## Folder Structure

| Folder | Use |
| --- | --- |
| `final-intro-wide/` | Final wide frames for the opening sequence. |
| `final-song-wide/` | Wide frames for selected song visuals. |
| `final-song-layers/` | PGM, floor, and surface-specific selected frames. |
| `gallery/` | Curated public gallery frames. |
| `candidates/` | Candidate frames for local review before final selection. |

## Public Use Rule

Use final output frames or selected gallery frames on the website. Keep raw project files, full render folders, and unclear source material out of public pages unless permission and context are confirmed.
