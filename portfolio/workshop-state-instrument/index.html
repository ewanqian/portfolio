01 · WHAT TO MODIFY

把练习继续长大。

每次只选择一层去改。保持其它部分不动，更容易知道自己到底改变了什么。

TIME

把 BPM 变成演奏参数

让 BPM 同时改变节拍、动画速度、delay time 或视觉网格密度。也可以改成 1/2x、1x、2x 三档，而不是任意数值。

STATE

增加一个新 Scene

例如 SUSPEND / DRIFT / COLLAPSE。先写清楚它如何改变 density、release、pitch range、brightness，再让 Agent 实现。

VISUAL

增加一个视觉变体

不要只换颜色。改变空间组织：点阵、轨道、路径、局部场、字符矩阵、残影、分区或拓扑连接。

MUSIC

加入音乐结构

从 Loop、Step Sequencer、Arpeggiator、Probability、Euclidean Rhythm 中选一个，不要一次全部加入。

MEMORY

让输入结束后继续

用 Release、Residue、Delay、Visual Trail 或 History Buffer，让系统保留刚才发生过的痕迹。

SHARE

把结果变成链接

保持单文件或清楚的静态目录结构，让 Agent 提交到 GitHub，然后用 GitHub Pages 发布。

02 · MUSIC WORDS

可以直接念给 AI 的音乐结构词。

CLOCK

BPM / Transport / Quantize

统一时间源。输入可以先产生轻微反馈，再把主事件放到下一 beat、1/8 note 或 bar。

PATTERN

Sequencer / Loop / Probability

让音乐重复但不完全重复。可以限制为 4 个 pattern variant，每 2 小节只改变 1 个参数。

VOICE

ADSR / Filter / Delay / Reverb

Tap 用短 transient，Hold 进入 sustain / drone，Release 留下 tail。多个声音同时存在时加入 gain staging 与 limiter。

做一个浏览器里的实验电子音画乐器。使用原生 Web Audio API 或 Tone.js，并建立唯一的共享 Transport。 交互： - Tap：0.12 秒左右的 transient； - Hold：超过 350ms 后进入持续的 drone / arpeggiator / loop； - Release：停止新增事件，并进入 1–3 秒 release / residue； - Idle：保留轻微 ambience，而不是立即归零。 音乐结构： - 140 BPM，可调整； - 量化到 1/8 note； - 每 2 小节只改变 1–2 个参数； - 音高来自固定 scale； - pattern 只从有限 variant 中变化； - 使用 gain staging / compressor / limiter，避免多层叠加爆音。 Audio 和 Visual 共同读取 BPM / beat / bar / scene / energy / holdDuration / releaseAmount。

04 · VIDEO STUDY WITH CODEX

把参考视频拆成可以研究的数据。

如果使用本地 Codex / Claude Code，可以把有权使用的参考视频放进项目，让 Agent 先分析，再决定要借鉴哪些结构。建议输出分析文件，不直接复制原视频素材。

读取 references/reference.mp4，先不要修改项目。 请建立 analysis/video-study/ 并完成： 1. 用 ffprobe 读取时长、帧率、分辨率、音频采样率； 2. 用 ffmpeg 每 2 秒提取一帧，并额外用 scene change threshold 提取明显切镜帧； 3. 生成 contact sheet，方便快速看整体视觉结构； 4. 抽取 mono WAV 音轨； 5. 如果环境允许，使用 Python + librosa 分析 estimated tempo、RMS、onset timestamps、spectral centroid；否则使用 ffmpeg 可用的音频统计完成基础分析； 6. 输出 analysis/video-study/structure.json，字段至少包括：time、sceneChange、visualDensity、brightnessEstimate、audioRMS、onset、sectionGuess； 7. 根据结果写一份 NOTES.md，只总结可迁移的结构：节奏密度、段落长度、视觉变化速度、声音/视觉是否同步、重复与变奏方式。 最后再提出 3 个“可以转化到当前网页乐器”的实验，不直接复制原视频画面。
